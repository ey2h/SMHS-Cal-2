## 三、每块面板的工序与先后顺序

**每屏统一走 9 道工序，顺序不可乱**（前面工序是后面工序的证据来源）：

| 序 | 工序 | 产出 | 门禁 |
|---|---|---|---|
| S1 | 实机 dump 控件表（构件式，非单元式）| `dump_<屏>.txt` | 控件坐标/启用态齐全 |
| S2 | 实机 dump 输出原文（多组参数）| `py_<屏>.txt` ×N | 输出可逐字对照 |
| S3 | 函数区定位（rtcRound 定稿点聚类 + Frida）| 函数地址区间 | 至少 1 个入口地址 |
| S4 | 反编译取公式（逐分支）| 公式表 + 代码地址 | **每条公式都有地址**，无"推测" |
| S5 | 引擎实现（`CwXXEngine`）| Calc 层类 | 编译通过 + 单构型能算 |
| S6 | 逐位对拍（≥3 组参数 × 每分支）| 对拍表 4 列 | **0 误差**，差异必须写"未定位" |
| S7 | ViewModel + 绑定 | VM 类 | 门禁（上游未算则禁用）|
| S8 | 视图 AXAML（按实机坐标）+ Figma 标注 | View + SVG | 截图与 V31 并排比对 |
| S9 | 测试固化 + memory + 提交 | 测试用例 | 全绿、无 InRange 放宽 |

**屏间顺序**：P1 → P2 → P3 → P4。
理由：连接屏算出的螺栓/角码反力是埋件屏的输入；埋件屏的焊缝与锚固结果进计算书；
胶类屏独立但共用面板 wk 口径，放 P3 可与 P2 并行收尾；P4 依赖前三屏全部闭合。

## 四、工时估算与角色分工

> 单位：**工作日**（1 个 AI 会话日 ≈ 6~8 轮深挖）。角色：
> **RE**=反编译取证（AI）｜**IMP**=引擎实现（AI）｜**UI**=视图/VM（AI）｜**CMP**=实机对拍（AI 驱动、用户在场）｜

## 七、整体时间安排与完成顺序建议

```
第 0 段（第 1–2.5 日）  收尾起点：T2 ComboBox 定位 → T1 多片夹层 →（可选 T3）
第 1 段（第 3–7 日）    P1 连接计算（S1→S9 全流程）
第 2 段（第 8–13.5 日） P2 埋件与焊缝（最大的一块，含锚固条文）
第 3 段（第 14–17 日）  P3 胶类伸缩紧固
第 4 段（第 18 日）     M4 主流程闭环联调（一键跑全 7 屏）
第 5 段（第 19–24 日）  P4 计算书生成（先数值对拍，后模板排版）
第 6 段（第 25 日）     M6 验收
并行轨：第 1–6 日 穿插 T4 立柱钢铝结合（与 P1 解耦）
```

**完成顺序建议（务必按此顺序，不要跳）**：

1. **T2 → T1**（同一面板内，先定位控件再补构型）
2. **P1 连接**（是 P2 的输入源，必须先做）
3. **P2 埋件焊缝**（工作量最大，尽早启动；其中锚固长度条文段落建议先做、与焊缝并行）
4. **P3 胶类**（可与 P2 后段并行）
5. **P4 计算书**（必须等前三屏全绿；否则反复返工）
6. **T4 立柱钢铝结合**（全程可并行，但要在 M4 前完成，否则计算书立柱章缺分支）

**不建议**：先做计算书模板（数值未定，模板会反复改）；
不建议并行 P1 与 P2（P2 依赖 P1 的反力数据，容易互相误导）。
