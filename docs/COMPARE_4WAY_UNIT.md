# 单元式幕墙｜四面对比（规范 ｜ V35 ｜ V31 ｜ 复刻）

> 2026-10-24 21:05。目标：把立柱屏「单元式幕墙」分支的四列填齐，
> 并解决长期挂着的 **「单元组合挠度 17.287 vs V31 17.279（差 0.046%）」**。
> 结论：**已闭合，9/9 逐位**；且查出复刻原先缺了一整个模型 —— 单元式是**左右两根框、两套型材**。

## 一、结论

1. **单元式 = 两根框 + 两套型材**。V31 立柱屏在单元式下把「立柱选料」**重建**成
   「单元立柱左框参数」和「单元立柱右框参数」两个 Frame，各带一个「快速查找型材」
   （`dump-col` 实测 `Frame(13,145)` / `Frame(13,292)`）。
   复刻原先只有一套型材、按 `I1=I2` 硬编码 `ratio=0.5`，这是模型级缺失。
2. **荷载先分配、先取整，再算内力**：
   `q_k左 = round3(q_k · I_1x/(I_1x+I_2x))`、`q_d左 = round3(q_d · I_1x/(I_1x+I_2x))`，
   然后用这个 `q_k左 / q_d左` 算挠度和弯矩。
   **0.046% 的差就出在取整位置**：以前写成 `5q_kL⁴/(384E(I1+I2))`（数学等价、取整不等价）。
3. 复刻改完后：同型材案 `17.279 / 79.975 / 5.855`、双型材案
   `12.659 / 73.691 / 58.578 / 5.941 / 4.289`，与 V31 **全部逐位相同**。

## 二、V35 计算书模板原文（代码级）

从 `unpacked_runtime.exe` 0xEC600–0xF4000 段按 UTF-16LE 解出的原文（`RVA = VA − 0x400000`）：

| 文案 | 用途 |
|---|---|
| 「单元幕墙立柱由两根框插接组成，计算荷载时需按**等刚度(EI)原理**进行比例分配。」 | 分配原则 |
| 「由于立柱轴力对计算影响很小，此处轴力分配按**均分**，水平荷载则按**等刚度原则**分配。」 | 轴力 vs 水平荷载 |
| `f_1左 = γ0·(N_1/2A_1n + M_1·(I_1x/(I_1x+I_2x))/γW_1nx)` | 左框抗弯 |
| `f_1右 = γ0·(N_1/2A_2n + M_1·(I_2x/(I_1x+I_2x))/γW_2nx)` | 右框抗弯 |
| 「由于采用等刚度原则计算，所以**挠度只须计算其中一根框即可**，此处计算左单元框。」 | 挠度取样 |
| `d_f1,mid = 5·q_k左·L_1⁴/(384·E·I_1x)·(1−2.4(a_1/L_1)²)` | 左框挠度（单跨 a=0 → 系数 1） |
| `τ_1左 = γ0·K_k·V·I_1x/(I_1x+I_2x)·S_1x/(I_1x·t_1)` | 左框抗剪 |

注意最后两行：**用的是 `q_k左` 和 `I_1x`**，不是 `q_k` 和 `I1+I2`。
数学上两式等价（`q_k左 = q_k·I1/(I1+I2)` 代入后 I1 约掉），但**取整点不同**，见 §四。

   将来库里只改其中一张时复刻要能跟着变。

## 四、0.046% 的真因：取整落在「分配之后」

### 4.1 旧写法（错）

```csharp
dfU = round3( 5·qk·L⁴ / (384·E·(I1+I2)) )        // 同型材：17.287（V31 17.279）
```

### 4.2 新写法（对）

```csharp
qkL = round3(qk × I1/(I1+I2));  qdL = round3(qd × I1/(I1+I2));
M1  = qdL × L²/8;
dfU = round3( 5·qkL·L⁴ / (384·E·I1) );
σ左 = round3( M1 / W1 );
```

### 4.3 逐案验算

**同型材（60/80 + 60/80，I1=I2=885950）**

| 量 | 代入 | 结果 | V31 |
|---|---|---|---|
| `qkL` | `round3(2.033 × 0.5)` | **1.016**（1.0165 银行家舍入取偶） | — |
| `qdL` | `round3(3.05 × 0.5)` | **1.525** | — |
| `M1` | `1.525 × 3000²/8` | 1 715 625 N·mm | — |
| `σ` | `1 715 625 / 21 452` | **79.975** | 79.975 ✅ |
| `τ` | `round3(2287.5 × 13606/(885950×6))` | **5.855** | 5.855 ✅ |
| `df` | `5×1.016×3000⁴/(384×70000×885950)` | **17.279** | 17.279 ✅ |

> ★ 关键就是 `1.0165 → 1.016`。旧写法绕过了这一步，等价式给出 `17.287` —— 差 0.046% 全在这里。

**双型材（左 60/100 + 右 60/80，ratio1 = 1532970/2418920 = 0.6337519）**

| 量 | 代入 | 结果 | V31 |
|---|---|---|---|
| `qkL` | `round3(2.033 × 0.6337519)` | 1.288 | — |
| `qdL` | `round3(3.05 × 0.6337519)` | **1.933** | — |
| `M1` | `1.933 × 3000²/8` | 2 174 625 | — |
| `σ左` | `2 174 625 / 29 510` | **73.691** | 73.691 ✅ |
| `qdR` | `round3(3.05 × 0.3662481)` | **1.117** | — |
| `M2` | `1.117 × 3000²/8` | 1 256 625 | — |
| `σ右` | `1 256 625 / 21 452` | **58.578** | 58.578 ✅ |
| `τ左` | `round3(4575×0.6337519×18846/(1532970×6))` | **5.941** | 5.941 ✅ |
| `τ右` | `round3(4575×0.3662481×13606/(885950×6))` | **4.289** | 4.289 ✅ |
| `df` | `5×1.288×3000⁴/(384×70000×1532970)` | **12.659** | 12.659 ✅ |

**9/9 逐位全中。**

### 6.1 反序自证（证明不是写死 1/2）

左右框对调后，复刻给出 `σ左 58.578 / σ右 73.691`、`τ左 4.289 / τ右 5.941` —— 与正序**完全互换**。
组合挠度从 12.659 变 12.670（不是同一个数），因为 V35 规定「只算左框」：
`df = 5·q_k左·L⁴/(384E·I_1x)`，换掉左框型材后 `round3(q_k·I1/(I1+I2))` 的取整点随之改变。
这正是忠实实现该公式的表现；若把 `ratio=0.5` 写死，两个方向会给出同一组数，这一条就会失败。
