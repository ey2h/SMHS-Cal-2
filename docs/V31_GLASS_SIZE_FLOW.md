## 二、流转关系（实测）

```
第一页 龙骨间距
  宽①1100  宽②1100        高①1380  高②1380
        │                        │
        └────────┬───────────────┘
                 ▼   2×2 全组合，外层高、内层宽（VB 双层 For：高在外）
      玻璃屏 分格尺寸下拉：['1100*1380','1100*1380','1100*1380','1100*1380']
                 │  选中项 sel=0（默认）
                 ▼
        短边 a = min(宽,高) = 1100    长边 b = max = 1380
                 ▼
      GlassEngine：σ=24.793  df=8.23  lim=a/60=18.333
                 ▼
        槽数组 0x1C911BC：slot[2]=a=1100  slot[3]=b=1380  slot[13]=a=1100
```

**传递是实时的**：把第一页 (122,205) 的 `1100` 改成 `900`，玻璃页下拉立刻变成
`['1100*1380', '900*1380', '1100*1380', '900*1380']` → 证明候选不是写死的，而是每次进屏按第一页现算。

**顺序规则**由这次实验定死：item[0]/[2] 用宽①，item[1]/[3] 用宽②；item[0]/[1] 用高①，item[2]/[3] 用高②。
（若顺序反过来，改宽② 会得到 [1100,1100,900,900]，实测是 [1100,900,1100,900]）

**两种模式互斥**：
- 「选择分格尺寸」→ 下拉 en=True，宽/高框 en=False
- 「自定义尺寸」→ 下拉 **en=False**，宽/高框 en=True（默认 1000 / 1280）

自定义实测：填 900×1600 → 槽 `a=900, b=1600`，`lim=15.0`（=900/60），`σ=25.472`，`df=5.912`。
⇒ **a 取短边**（900 是宽但比 1600 短），与下拉模式一致。

## 三、命名与单位核对

| 概念 | 第一页 | 玻璃页 | 引擎 | 单位 | 一致性 |
|---|---|---|---|---|---|
| 分格宽 | 龙骨间距·左列（无标签） | 下拉文本 `宽` | `aMm`/`bMm` 入参 | mm | ✅ 全 mm，无换算 |
| 分格高 | 龙骨间距·右列 | 下拉文本 `高` | 同上 | mm | ✅ |
| 自定义宽 | — | TextBox (87,110) | `aMm` | mm | ✅ 但**无单位提示** |
| 自定义高 | — | TextBox (87,134) | `bMm` | mm | ✅ 同上 |
| 短边/长边 | — | — | `a=min, b=max` | mm | ✅ 顺序无关 |
| 挠度容许 | — | `18.333mm` | `a/60` | mm | ✅ |

**命名不一致点**：第一页叫「龙骨间距」、玻璃页叫「分格尺寸」，指同一组数；引擎入参叫 `aMm/bMm` 而语义是短/长边，
建议复刻时统一为 `GlassSpanWidthMm` / `GlassSpanHeightMm` + 派生 `ShortSpanMm/LongSpanMm`。

## 四、默认值 / 校验 / 异常处理

### 4.1 默认值

| 项 | 第一页默认 | 玻璃页默认 | 备注 |
|---|---|---|---|
| 宽 | 1100 | 下拉 sel=0（=第一页宽① × 高①） | |
| 高 | 1380 | 同上 | |
| 自定义宽/高 | — | **1000 / 1280**（en=False 时的残留值） | ⚠ 与实算 1100/1380 不符 |
| 厚度 | — | 下拉 10 档 `3.2/4/5/6/8/10/12/15/19/20`，sel=3 → **6** | 本屏直接选 |
| 胶片厚度 | — | `0.38/0.76/1.14/1.52/2.28`，sel=1 → 0.76 | 夹层时才可用 |
| 胶片类型 | — | `PVB / SGP`，sel=0 | |

### 4.2 校验（自定义尺寸模式下实测）

| 输入 | 结果 |
|---|---|
| `0` | 弹「请您注意，玻璃尺寸参数有误」，中止预演（槽未更新） |
| `-100` | 同上 |
| `abc` | 同上，对话框文字**重复**：「请您注意，请您注意，玻璃尺寸参数有误」 |
| `99999` | **无任何提示**，直接参与计算（a=99999, b=1600）→ 上限缺失 |

- 非法输入后框回显仍是 `1000`（回滚到默认值，不是回滚到上一个合法值）。
- 拦的是「≤0 / 非数字」，**不拦超大值**，也不拦「宽 < 高」（交给 min/max 处理，算正常）。

## 五、疑点清单（按严重度）

| # | 疑点 | 性质 | 复刻处理建议 |
|---|---|---|---|
| 1 | 默认（下拉）模式下宽/高框回显 1000/1280，而实算用 1100/1380 | **误导性残留** | 框保持 en=False 且**灰显当前生效值**；或清空并在预演后回写 a/b |
| 2 | 下拉 4 项全是 `1100*1380`（宽②=宽①、高②=高①时不去重） | V31 缺陷 | 复刻按原样生成 4 项（保持逐位一致），但在 UI 上去重并保留原始索引映射 |
| 3 | 上限无校验（99999 直接算） | 校验缺失 | 补上限（建议 ≤ 6000mm，且面积 ≤ 允许最大面积）；**先登记差异再实施**，不要静默加 |
| 4 | 非数字提示文案重复「请您注意，请您注意」 | V31 文案 bug | 复刻写单次 |
| 5 | 非法输入回滚到 1000（默认）而非上一合法值 | 状态管理缺陷 | 复刻回滚到上一合法值 |
| 6 | 换第一页尺寸后下拉重建，但**选中索引不重置**（仍 sel=0） | 隐式漂移 | 复刻按「值」而非「索引」记忆选择，值不存在则回落 sel=0 |
| 7 | 中横两项 1350 恒 en=False → 不参与候选 | 联动 | 与「有中横结构」联动：勾选后才进候选 |
| 8 | 尺寸框无单位后缀，只有 Frame 标题括号里有 `mm*mm` | 易错 | UI 补 `mm` 后缀（不改数值） |

## 六、复刻实现要求（落到代码）

1. `CalcSession` 已有 `BeamLeftBayMm/BeamRightBayMm/BeamUpperGridHeightMm`（沿用第一页 4 个框），
   玻璃屏新增只读派生：
   - `GlassSizeCandidates` → `[(w,h) for h in {高①,高②} for w in {宽①,宽②}]`（**外层高**）
   - `GlassSpanMm`（下拉选择）或 `GlassCustomWidthMm/HeightMm`（自定义模式）
   - `GlassShortSpanMm = min(...)`、`GlassLongSpanMm = max(...)`
2. 模式互斥用两个 bool（`GlassUsePresetSize` / `GlassUseCustomSize`），切换时联动 en 状态。
3. 校验：`<=0` 或非数字 → 拒绝并提示；上限按疑点 #3 登记后加。
4. 单位一律 mm，不做换算；UI 文本补 `mm`。
