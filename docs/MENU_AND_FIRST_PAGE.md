# 菜单类型 → 第一页 → 计算链 映射（约束 C5）

> 规则来源：用户明确要求「所有都要从第一页来；第一页就是外框标题栏下拉每个幕墙类型点开的第一页；各类型有相同有不同」。
> 菜单树取自 `CalcMenuCatalog.cs`（从 V35 VB6 菜单记录提取，与 V31 菜单截图逐项一致）。
> 窗体尺寸取自 `hb_window_tree2.tsv`（V35 运行期控件树 4025 条）实测。

---

## C5 约束（硬性）

1. **任何计算只能由「某个具体子项」发起**：用户点 `顶级菜单 → 子项`（如 玻璃幕墙 → 全隐框），
   系统记住这条路径，第一页据此决定显示哪套参数。
2. **第一页是该子项的唯一入口**：不允许从菜单直接打开立柱/板块/横梁等"第二页以后"的屏去计算。
3. **第一页未完成 → 后续屏一律拒绝计算**（门禁 `WindStandardResolved` 等，见 C4）。
4. **各子项的第一页"有相同有不同"**：共用的参数（地区/重现期/地面类型/体型系数/风荷载取值/龙骨间距）
   来自同一套控件；差异项（玻璃配置 / 板材类型与厚度 / 点式驳接参数 / 采光顶几何 / 门窗系列 …）按子项切换。
5. 切换子项等价于**重置计算链**：门禁位清零，后续屏的旧结果清空。

## 四、第一页"相同部分"与"不同部分"

**相同（所有幕墙类型共用同一套控件与取数来源）**：

| 参数 | 来源 |
|---|---|
| 地区 / 重现期（50·100 年） | 参数库「地区参数」634 行 |
| 地面类型 A/B/C/D | V35 常量表 I10/α + μz 系数 |
| 计算标高 | 用户输入 → μz/βgz |
| 外部 / 内部局部体型系数 | 1.0 / 1.8 / 0.2·0.3·0.4·0.6 / 人工 |
| K1 地形修正 / K2 风向影响 | GB55001-2021 4.6.6 / 4.6.7 |
| 风荷载标准值取值 | 按规范(≥1KPa) / 按实际 / 人工 |
| 幕墙结构（构件式·单元式）/ 横框（有·无中横） | 界面 |
| 龙骨间距 6 项 | 界面（立柱左/右分格宽、横框上/下分格高、中横框上/下分格高） |
| 安全性能等级 → γ0 | 一级1.1 / 二级1.0 / 三级0.9 |
| 抗震设防分类 + 场地类型 | 设计院给，界面只选择 |

**不同（按子项切换）**：

| 子项族 | 第一页差异项 |
|---|---|
| 玻璃幕墙 | 玻璃配置 6 选 1（单片/中空/夹层/中空+夹层/双中空/双夹层-中空） |
| 金属板幕墙 | 板类型 + 板厚 + 加劲肋 |
| 天然石材 / 人造板材 / 背栓点挂 | 板材类型 + 厚度 + 挂件/背栓规格 |
| 点式玻璃幕墙 | 驳接爪/肋/拉索/钢管参数 |
| 采光顶 | 坡度/跨度/分格几何 |
| 门窗 | 系列 + 扇尺寸 |
| 雨篷 / 栏杆 / 吊顶 / 格栅 / 百叶 | 各自几何与龙骨选型 |
| 节能热工 | 传热系数/遮阳系数/体形系数等 |
