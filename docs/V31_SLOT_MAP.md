# V31「槽数组」是什么 —— 位置、结构、映射、读法

> 一句话：**槽数组 = V31 运行期的模块级变量表**（VB6 全局 VARIANT 区），
> 每槽 16 字节，既装数值也装字符串。它不是日志、不是调试信息，就是程序正在用的变量本体。
> 读它 = **直接看程序手里的数**，不需要反推、不需要猜。

---

## 一、位置与结构

| 项 | 值 |
|---|---|
| 基址指针所在全局变量 | V31：`ds:[0x1C91168]`（指令形如 `mov ecx, ds:[0x1C91168]`） |
| 槽数组实际地址 | 每次启动变，实测 `0x01FBDDA0`（本次会话）／历史 `0x20B5BF8` |
| 槽大小 | **16 字节 = VARIANT** |
| 字段 | `+0` VARTYPE(u16)　`+8` 值（R8/I4/I2/BSTR 指针） |
| 槽数量 | 实测非空 198 个，槽号上界约 0..100（扫 1024 槽足够） |
| V35 对应 | 同一套机制，V35 进程里槽数组在 `0x220D178` 一带 |

**读法必须先读指针再读数组**，地址写死无效：

```python
base = ReadProcessMemory(0x1C91168, 4)        # → 0x01FBDDA0
variant_i = ReadProcessMemory(base + i*16, 16)
vt        = u16(variant_i + 0)
value     = double(variant_i + 8)  # vt=5
ptr       = u32(variant_i + 8)     # vt=8 → BSTR，长度前缀在 ptr-4
```

## 二、槽映射表（实测对照，2026-10-24 21:35）

同一进程内切换输入做对照（构件式/单元式、封闭式/0.8μs1、全国/广东），
凡"值随某个输入变"的槽即可定语义。下表「证据」列写明是靠什么定下来的。

### 2.1 字符串槽（VT_BSTR）

| 槽 | 实测内容（上海 / B类 / 100m / 广东低矮） | 含义 | 证据 |
|---|---|---|---|
| `slot[1]` | `'上海'` | 地区名 | 改地区变 |
| `slot[2]` | `'B类地形'` | 地面粗糙度类别 | 改地形变 |
| `slot[3]` | `'地震基本烈度为：7度'` | 抗震文案 | 随设防烈度 |
| `slot[4]` | `'地震动峰值加速度为0.1g，…'` | 抗震说明文案 | 文案 |
| **`slot[7]`** | **`'1+2*3*0.14*(100/10)&-0.15&'`** | **βgz 的公式代入串** | **广东档 g=3，全国档是 `2*2.5`** |
| **`slot[9]`** | **`'1.000*(100/10)&0.30&'`** | **μz 的公式代入串** | 全国/广东相同（μz 与规范无关） |
| `slot[13]` | `'50'` | 重现期（50 年） | 切 100 年变 `'100'` |
| `slot[19]` | `'单元结构幕墙设计计算书'` | 报告标题 | 构件式时为 `'幕墙设计计算书'` |
| `slot[41]` | `'1.幕墙设计规范：\n《铝合金结构设计规范》…'` | 计算书规范清单 | 文案 |
| `slot[67]` | `'墙面大面位置'` | 外部体型系数部位 | 改部位变 |
| `slot[70]` | `'封闭式建筑内表面'` | 内部体型系数部位 | 改开洞率变 |
| `slot[72]` | `'Ⅱ类场地'` | 场地类别 | 改下拉变 |

**`&...&` 是上标标记**：`'(100/10)&-0.15&'` = `(z/10)^(−0.15)`，`'1.000*(100/10)&0.30&'` = `1.000×(z/10)^0.30`。
`~...~` 是下标。这套标记直接对应计算书里的富文本排版。

### 2.3 已排除的观察（避免重复踩）

- **单元式与构件式的槽完全相同** —— 立柱屏的中间量（qk、M、σ、τ、df、型材）**不在**这套槽里。
- 堆里只有计算书**输出文本**（如 `'    风荷载标准值为:2.146KPa'`），
  没有 `qk=…`／`σ=…` 这类下游代入串；下游量是数值变量，不是字符串。

## 三、这套槽能证明什么、不能证明什么

**能**：
1. 程序**实际用的** βgz / μz / ψ / μsi / g / wk —— 都是程序手里的数，不是推算；
2. 公式的**代入形式**：`slot[7]` 直接写着 `1+2*2.5*0.14*(100/10)^-0.15`，g/I10/α/z 全在串里；
3. 取整口径：`slot[15]=0.002146` 说明 wk 进 qk 链时**已经是 3 位取整值**（0.03% 误差的真因）。

**不能**：
- 不能给出下游中间量（qk/M/σ/τ/df）—— 它们不在这套槽里；
- 不能替代 V35 代码：槽只给"值"，不给"算法分支"（比如为什么取 24 而不是 12）。

## 四、工具

| 脚本 | 用途 |
|---|---|
| `local-data/recon/v31_slot_probe_v2.py` | **主工具**。扫 0..1023 槽、按 vt 正确解码、BSTR 长度读 `ptr-4`、`--csv` 落盘、`--diff a.csv b.csv` 求差 |

### 常用命令

```bash

# 在堆里搜某个公式串 / 某个数值
python local-data/recon/v31_heap_strings.py --grep "2.146" --min-len 4
```

## 五、本次对照实验记录（可复现）

| 时刻 | V31 状态 | `slot[7]`（βgz 公式串） | `slot[69]`（μsi） | `slot[76]`（g） | `slot[15]`（wk） |
|---|---|---|---|---|---|
| A | 构件式 · 全国 · 封闭式 · 100m | `1+2*2.5*0.14*(100/10)&-0.15&` | 0.2 | 2.5 | 0.001848 |
| B | 构件式 · 全国 · 0.8μs1 · 100m | 同 A | **0.8** | 2.5 | 0.002833 |
| C | **单元式** · 全国 · 封闭式 · 100m | 同 A | 0.2 | 2.5 | 0.001848 |
| D | 构件式 · **广东低矮** · 封闭式 · 100m | **`1+2*3*0.14*(100/10)&-0.15&`** | **0.3** | **3** | **0.002146** |

A vs C：槽**全同** → 单元式差异不在风荷载槽里。
A vs B：只有 `slot[69]` 与 wk 相关槽变 → μsi 是独立槽。
A vs D：`slot[7]` 的 g、`slot[69]`、`slot[76]` 同时变 → 广东规范两处改动在槽层面完全可见。
