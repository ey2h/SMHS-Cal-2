## 一、已确证：立柱挠度公式（含多跨外伸修正）

### 1.1 汇编原文（0x1D68158 – 0x1D68248）

```asm
01D68158  fld  qword ptr [0x404478]      ; = 4.0
01D68163  fld  qword ptr [ebp-0x2C8]     ; = L（跨度）
01D6816E  call __vbaPowerR8              ; L ^ 4
01D68173  fmul qword ptr [ebp-0x320]     ; × q（线荷载标准值）
01D68183  fstp qword ptr [ebp-0x1004]    ; t = q·L⁴

01D68189  fld  qword ptr [0x401E70]      ; = 2.0
01D68194  fld  qword ptr [ebp-0x3B0]     ; = a（外伸长度）
01D681A3  fdiv qword ptr [ebp-0x2C8]     ; a / L
01D681CB  call __vbaPowerR8              ; (a/L) ^ 2
01D681D0  fmul qword ptr [0x402EE8]      ; × 24.0
01D681D6  fsubr qword ptr [0x402A40]     ; 5.0 − 上面   ← fsubr：ST0 = mem − ST0
01D681DC  fmul qword ptr [ebp-0x1004]    ; × q·L⁴
01D681EB  fdiv qword ptr [0x4113C8]      ; ÷ 384
01D6820D  fdiv qword ptr [ebp-0x4F0]     ; ÷ E（弹性模量）
01D6822F  fdiv qword ptr [ebp-0x4B4]     ; ÷ I（惯性矩）
01D68258  mov  dword [ebp-0x518], 5      ; VT_R8
01D68262  push 3
01D68272  call rtcRound                  ; ★ 取 3 位
01D68283  fstp qword ptr [ebp-0xFC]      ; 挠度结果
```

常量实测值：

| 地址 | 值 | 含义 |
|---|---|---|
| `0x404478` | **4.0** | L 的指数 |
| `0x401E70` | **2.0** | (a/L) 的指数 |
| `0x402EE8` | **24.0** | 外伸修正系数 |
| `0x402A40` | **5.0** | 主系数 |
| `0x4113C8` | **384.0** | 分母常数 |

### 1.2 还原成公式

```
d_f = round3( [ 5 − 24·(a/L)² ] · q_k · L⁴ / (384 · E · I) )
```

单跨时 a = 0 → **`d_f = round3( 5·q_k·L⁴ / (384·E·I) )`**。

这条与 V35 计算书模板文字（0x4EC890 一带）的
`d_f1,mid = 5·q_k左·L_1⁴/(384·E·I_1x)·(1−2.4(a_1/L_1)²)` **不完全一致**：
模板写 `1−2.4(a/L)²`（等价 `5−12(a/L)²`），代码是 `5−24(a/L)²`（等价 `1−4.8(a/L)²`）。
**以代码为准**，模板文字只当注释看。单跨（a=0）两式相同，所以此前对拍没暴露。

### 1.3 与复刻/实测的对应

| 量 | 复刻实现 | 代码公式 | V31 实测 |
|---|---|---|---|
| 构件式 df | `5·qk·L⁴/(384·E·I)` | 同上（a=0） | 34.574 ✅ |
| 单元式 df（同型材） | `5·qk左·L⁴/(384·E·I1)` | 同上，I = I1、q_k = q_k左 | 17.279 ✅ |
| 单元式 df（双型材） | `5·qk左·L⁴/(384·E·I1)` | 同上 | 12.659 ✅ |

其中 `q_k左 = round3(q_k · I1/(I1+I2))` —— 这一步的**代码位置尚未定位**（见 §三）。
