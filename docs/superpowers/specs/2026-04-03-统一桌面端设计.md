# 统一桌面端设计 (Section 4) 

在 MAUI Blazor Desktop（Blazor Hybrid）框架下实现桌面端唯一 UI，统一网页端 UI，提供稳定的对外 API 入口，并以企业内网 MSIX 打包分发为优先策略。以下为实现草案的正式设计稿，供审阅后进入实现分解阶段。 

## 1. 概要
- 目标：桌面端统一 UI，UI 组件共用共享 UI 库 GlassManagement.Ui.Shared；对外提供稳定的 API；桌面端 MSIX 打包在企业内网分发。 
- MVP 重点：Phase 1-Phase 4 的 UI 页面迁移、API 契约、共享组件、桌面端骨架、云图数据结构、MSIX 打包配置、初步测试用例。 
- 受众：前端/桌面端开发、后端 API 团队、运维/安全人员。 

## 2. 总体架构（高层）
- UI 层
  - 共享 UI 库 GlassManagement.Ui.Shared：通用组件、设计 Token、主题管理、路由结构。 
  - 桌面端 MAUI Blazor Desktop：GlassManagement.Desktop.Blazor，Blazor Hybrid 形式，渲染统一 UI。 
  - 网页端 Blazor Web：继续使用现有 Blazor WebUI，引用同一共享 UI 库实现外观一致。 
- 业务与 API 层 
  - GlassManagement.Api：对外 API，提供/api/calculation/multi、/api/config、/api/calculation/validate 等端点。 
  - GlassCalculationEngine：对外 API 的后端调用入口，内部实现 MultiGlassCalc，支持多类型玻璃组合。 
  - CloudVizService/CloudVizPane：云图数据结构与可视化渲染入口。 
- 部署与发布 
  - 桌面端：MSIX 打包，企业内网分发。 
  - 数据访问：复用现有数据库数据源 SMHS_Glass.db、SMHS_Region.db、SMHS_Profile.db 等。 

## 3. 数据契约（核心模型）
- GlassInput
  - ProjectId, RegionId, GlobalSettings
  - Panels: GlassPanelInput[]
- GlassPanelInput
  - PanelId
  - Type: GlassPanelType（Single、Laminated、Insulating、LaminatedInsulating 等扩展）
  - Layers: GlassLayerInput[]
  - Width, Height, Thickness
  - EdgeTreatment, BorderOptions
- GlassLayerInput
  - MaterialId, Thickness, Interlayer, Laminate
- GlassOutput
  - PanelsResults: PanelResult[]
  - Summary
- PanelResult
  - PanelId, Type, Status
  - Metrics: Thickness, Deflection, MaxStress, EdgeEffect, SafetyFactors
- CloudVizData
  - GridPoints, ValuesByPoint, ColorMapInfo

## 4. API 契约（对外稳定入口，版本化）
- POST /api/calculation/multi
  - 输入：GlassInput JSON
  - 输出：GlassOutput + CloudVizData
- GET /api/config
  - 输入：无
  - 输出：API 版本、材料、参数元数据
- POST /api/calculation/validate
  - 输入：GlassInput JSON
  - 输出：是否通过校验
- 安全：初期 API Key；后续可扩展为 OAuth2/JWT；网关层统一鉴权与速率限制 
- 版本化：/api/v1/… 路径，提供变更日志和向后兼容策略 

## 5. UI 组件与设计系统
- GlassManagement.Ui.Shared：
  - AppShell、NavMenu、GlassCard、GlassForm、GlassDataTable、CloudVizPane、Toast/Dialog、HelpPopover、ThemeProvider
  - Apple Glass 风格 Tokens：颜色、透明度、模糊半径、圆角、阴影、字体尺度
- 视觉一致性
  - 桌面端 MAUI Blazor Desktop 与网页端共享组件，确保导航、表单、表格、云图控件在两端一致
- 主题
  - Apple Glass、Light、Dark 三种主题，桌面端默认 Apple Glass 风格 

## 6) 桌面端实现要点
- 桌面端项目：GlassManagement.Desktop.Blazor（MAUI + Blazor Hybrid）
- Shell 组织：统一导航、首页、输入页、结果页、云图页等，接入共享组件库
- 数据访问：通过 API 调用 GlassManagement.Api，桌面端可使用本地缓存提升离线体验 
- 云图数据：CloudVizPane 绑定 CloudVizData，提供缩放、提示、颜色映射等交互 
- 离线就绪：Phase 1 可实现对常用配置的本地缓存 
- 安全与合规：企业内网内署、MSIX 签名、内网更新通道 

## 7) MSIX 打包与分发（阶段性需求）
- 打包：MAUI 的 MSIX 打包配置，证书管理、版本号、安装路径 
- 分发：企业内网（Intune/SCCM / 自建分发）
- 更新：初期手动更新，后续引入自动更新能力 

## 8) 测试策略
- 单元测试：核心接口、UI 组件、CloudVizData 结构
- 集成测试：/api/calculation/multi 的端到端测试、Phase 1 的 UI 与后端对接
- UI 一致性测试：网页端 vs 桌面端的视觉对齐
- 性能与稳定性：并发请求、离线缓存的行为、MSIX 打包后的安装测试 

## 9) 风险与缓解
- MAUI 学习曲线与调试复杂性：分阶段实现、使用共享组件减少重复工作 
- UI 风格在桌面端的呈现差异：以 Tokens 为核心，统一资源 
- API 版本与兼容性：严格版本控制、文档化变更日志 
- 企业内网分发：确保离线更新、回滚策略、以及签名证书的管理
