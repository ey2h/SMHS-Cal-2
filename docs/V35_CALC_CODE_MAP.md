# V35 脱壳代码 → 计算代码定位图（2026-10-24）

目标文件：`local-data/recon/unpack/unpacked_runtime.exe`（ASPack 脱壳后，36040704 字节，32 位原生 x86）
IDA 库实例：`idalib`，1271 个已识别函数。

## 一、结论先说

- **能确证的**（直接从程序自己的常量/指令读出）：
  1. 挠度系数 **5/384** —— `0x1B65B75 fld ds:dbl_402A40(5.0)` → `0x1B65B84 fdiv ds:dbl_4113C8(384.0)`
  2. 挠度限值三段常量 **180 / 250 / 200 / +7** —— 常量表 `0x4026C8=180.0`、`0x4026D0=250.0`、`0x402F60=200.0`、`0x402E90=7.0`，并在两处函数里被引用
  3. `1/x` 形式的限值斜率：`0xAE4FB6 fdiv 180.0` 后 `0xAE4FCF fsubp`（1/÷ − 1/180）；`0xAE4A38 fdiv 250.0` 后 `0xAE4A51 fsubp`
- **静态取不到的**：`q / L / E / I` 这些量在公式里的位置。原因见第三节。

## 三、为什么静态拿不到完整公式（这是关键阻碍）

V35 是 **VB6 原生编译**（函数开头 `55 8B EC 51 51 68 ... 64 A1 00 00 00 00`，带 SEH 帧），它的变量全部放在
一个 **长度 271 的全局 VARIANT 数组** `dword_220D1B0` 里：

```
01B65A6A  mov     eax, [ebp-1B8h]      ; 槽位号
01B65A70  shl     eax, 4               ; ×16 字节 = VARIANT 大小
01B65A73  mov     ecx, dword_220D1B0   ; 全局 VARIANT 数组基址
01B65A79  add     ecx, eax             ; &var[slot]
01B65A7B  push    ecx
01B65A80  call    sub_419DF0           ; __vbaVarMul（VB 运行时 VARIANT 乘法）
```

槽位越界还有 VB 标准的 `cmp slot, 10Fh / jnb → Err` 检查（0x1B65BBF、0x1B65BF5 等）。

也就是说：公式被编译成 `__vbaVarMul / __vbaVarDiv` 的一串调用，**实参是 `var[122]`、`var[3]`、`var[21]` 这种槽位号，槽位没有名字**。
Hex-Rays 对这种 57 KB、SEH + VARIANT 辅助调用的函数直接返回空（已实测 `ida_hexrays.decompile` → None），
所以既没有伪代码，也没法从槽位号反推「哪个是 q、哪个是 L、哪个是 E/I」。

（补充：输出文字「第1跨立柱抗弯强度计算值为:」等字符串在文件里存在，但**没有任何 imm32 引用它**
—— 全镜像按 0/±4 偏移扫描均 0 命中，说明它们是通过运行时字符串池/索引表访问的，同样无法静态回溯调用点。）

## 四、要真正取出公式，只剩一条路

**动态取值**：在下列位置下断点，读 `dword_220D1B0` 那个 271 槽位数组的实际 VARIANT 值，即可标定每个槽位代表的物理量：

- `0x1B65B75`（5/384 之前）→ 读参与乘法的几个槽位，确定 q、L⁴、E、I 的槽位号
- `0xAE4FB6` / `0xAE4A38`（限值分段）→ 读参与比较的槽位，确定 calcSpan 与 4500 阈值的表达
- 再在「按规范不小于1KPa」分支上断一次 → 抓 μz / β / μs 的乘积，闭合 wk 链
