# V31 的 wk 不是全局唯一值 —— 按「计算对象」分两套口径

> 定案日期：2026-10-25　｜　取证方式：V31 实机六组参数 × 六屏扫描 + 文案常量池比对
> 结论级别：**实测 + 文案双重证据**，取代此前「玻璃漏乘 μs1·ψ 属 V31 缺陷」的误判。

## 一、结论

V31 的风荷载标准值 `wk` 按**计算对象**分成两套，`w0 / βgz / μz / 地形 / K1 / K2` 完全相同，
**只有体型系数项不同**：

```
支承结构口径（立柱 / 横梁 / 连接 / 埋件）
    wk = P · ( μs1 · ψ(A) + μs_int )      A = 分格面积，ψ(A) < 1  ⇒ 折减

面板口径（玻璃 / 胶类）
    wk = P · ( μsl     + μs_int )         μsl = 1.0，不折减     ⇒ 恒大于支承

其中 P = w0 · βgz(terrain,z) · μz(terrain,z) · K1 · K2
```

两口径都受「按规范不小于 1.0KPa」下限约束（`WindByCalcResult=false` 时取 `max(·, 1.0)`）。

三条规律，六组无一例外：

1. **立柱 = 横梁 = 连接 = 埋件**（支承结构四屏恒等）
2. **玻璃 = 胶类**（面板两屏恒等，G1 直接对上 1.598）
3. **面板 > 支承**，差值只随外部体型变化，**不随内压开孔变化**
   （G1/G5/G6 差值 0.084/0.085/0.084 基本恒定——正是 `P·(1 − μs1·ψ)` 与 `μs_int` 无关的指纹）

> G4 撞 1.0 下限，说明两口径共用同一条下限分支。

## 三、程序文案证据（设计上本来就分开）

字符串常量池（VA，UTF-16LE）中 `.rdata` 段并存多套文案：

| 地址 | 文案 | 归属 |
|---|---|---|
| `0x4D22D4` | `风荷载标准值为:` | 立柱屏（后接「抗弯…」） |
| `0x4D3FF4` | `玻璃部分风荷载标准值为:` | 玻璃屏（全镜像**唯一**一处「玻璃部分风荷载」） |
| `0x4D81B0` | `面板部分风荷载标准值为:` | 胶类屏（后接「按计算，玻璃与铝框间结构胶宽度最小值」） |
| `0x4E9FAC` | `风荷载标准值(计算玻璃时)为:` + `(计算珩架时)为:` | **同屏并列两个 wk** |
| `0x4F9EFA` | `计算支承结构时风荷载标准值为:` + `计算玻璃面板时风荷载标准值为:` | 钢结构屏，**支承/面板同屏并列** |
| `0x50238A` | `计算杆件时风荷载标准值为:` + `计算玻璃时风荷载标准值为:` | 另一结构屏，同样并列 |

`0x4E9FAC` 与 `0x4F9EFA` 在**同一屏里并排输出两个不同的 wk**，这是「wk 按对象取」最硬的证据：
若 wk 是全局唯一值，不可能同屏输出两个。

> 这些串位于连续常量池、无 BSTR 长度头，静态 `push offset` 型 xref 为 0，
> 因此归属是按「文案语义 + 实测值配对」确定的，不是靠 xref。

## 四、自洽校验

用旧对拍组（w0=0.45、C 类、z=100、μs1·ψ=0.926、μ_int=0.2）：

```
P           = 0.45 × 1.6929 × 1.4983        = 1.14141
支承 wk     = 1.14141 × (0.926 + 0.2)       = 1.2852  → round3 = 1.285 ✓
面板 wk     = 1.14141 × (1.000 + 0.2)       = 1.3697  → round3 = 1.370 ✓
比值        = 1.200 / 1.126                 = 1.0657  ≈ 实测 1.37/1.285 = 1.0661 ✓
```

G1 同法：`1.598/1.514 = 1.0555`，反解 `1.200/x = 1.0555 ⇒ x = 1.1369 = 0.9369 + 0.2`，
`μs1·ψ = 0.9369 < 1` 合理。G5/G6 同理（0.9462 / 0.9494），三组反解的 `μs1·ψ` 都落在 (0, 1) 内。

## 五、代码落地

### 5.1 代码级机制：同一槽位 slot[0x45]，两屏填不同值

`0xA7CE09` 是玻璃屏的风荷载函数入口，槽索引以立即数出现（反汇编自
`v31mem_clean/v31_mem_00401000.bin`，文件偏移 = VA − 0x400C00）：

```
0xA7CE38  mov [ebp-0xd8], 0x0B     ; 索引 slot[0x0b] = μs内压档
0xA7CE5F  mov [ebp-0xdc], 0x45     ; 索引 slot[0x45] = 体型系数项
0xA7CE86  mov [ebp-0xd4], 0x35     ; 索引 slot[0x35] = 结果
0xA7CED5  call 0x413552            ; __vbaVarAdd
          ⇒ slot[0x35] = slot[0x45] + slot[0x0b]
```

两侧都读**同一个** `slot[0x45]`（`ds:[0x1C91168]` + 索引<<4），差别只在谁往里写了什么：

| 屏 | slot[0x45] | 运行期直读 |
|---|---|---|
| 立柱 / 横梁 / 连接 / 埋件 | μs1·ψ(A) | 0.926 |
| 玻璃 / 胶类 | μsl = 1.0 | 1.0 |

所以是「**同一段乘数链 + 不同的体型系数输入**」，不是两套独立公式，也不是漏算。
（`0xA7CE09` 是带 prolog 的完整函数入口，自身不写 slot[0x45]，说明由调用方在进屏时置值；
具体写入地址尚未定位，记为待补。）

### 5.2 复刻侧改动

| 位置 | 改动 |
|---|---|
| `CalcSession.WindStandardKpa` | 语义明确为**支承结构口径**（立柱/横梁/连接/埋件） |
| `CalcSession.PanelWindKpa`（新） | **面板口径**（玻璃/胶类），由第一页写入 |
| `CalcSession.PanelWindRawKpa`（新） | 面板未取整值，留痕 |
| `CalcSession.PanelShapeCoef`（新常量） | `= 1.0`，即面板局部体型系数 μsl |
| `CalcSession.PanelWindResolved` | `PanelWindKpa > 0`，玻璃屏预演门禁 |
| `BasicParamsViewModel.ResolveWindStandard` | 同时算两套口径，人工给定分支两者取同值 |
| `GlassCalcViewModel` | 改用 `PanelWindKpa` / `PanelWindResolved` / `PanelWindSource` |

`μsl = 1.0` 且不折减的判定依据是**行为实验**（非数值反推）：改玻璃尺寸
1100×1380 → 1100×1500，屏上 wk 恒为 1.37 不变，说明面板口径与面板面积 A 无关。
