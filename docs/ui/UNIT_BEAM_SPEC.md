> **关于 Figma**：本机无 Figma 授权与 connector（工具检索无 figma 工具、子线程实测不可用）。
> 因此本屏按「既有设计规范 + 可直接编译的 XAML」交付，等价替代 Figma 稿：
> 布局/间距/配色/组件全部复用 `docs/ui/BEAM_UI_SPEC.md` 的同一套 token，不引入新视觉语言（逐项见第二节）。

## 一、本屏定位

V31 里「横梁计算」是**一个窗体、两套模板**，按第一页「幕墙结构」切换：

| 结构形式 | 模板 | 输出量 | 复刻状态 |
|---|---|---|---|
| 构件式（框架式） | 单根横梁 | 12 | ✅ 已闭合（`BeamCalcView`） |
| 单元式·无中横 | 上横框 + 下横框 | 17 | ✅ **本轮完成**（`UnitBeamCalcView`） |
| 单元式·有中横 | 上 + 下 + 中横框 | 27 | ⬜ 中横段未取证（+10 量） |

**关键实测**：有中横时前 17 个量与无中横**逐位相同** ⇒ 中横是独立追加段，不改变上下框。

## 四、算式与出处（全部已闭合，定稿点 `0xA05312–0xA0A2DB`）

```
qk = round3(min(B,H)·wk/1000)      qd = round3(qk×1.5)
gp = round3(min(B,H)·g·5αmax·1.4)/2    q_y = round3(qd+gp)
M_y = q_y·B²·(3−(r/B)²)/24             M_x = round3(H·g·1.3)·B²/8

上框 σ = (M_y/2)/Wy + M_x/Wx          下框 σ = (M_y/2)/Wy      ← 自重只进上框
V_h/2 = q_y·B/8                        V_v  = round3(H·g·1.3)·B/2
τx = V_h/2·Sy/(Iy·ty)                  τy = V_v·Sx/(Ix·tx)      （下框 τy ≡ 0）
df_v = 5(H·g)·B⁴/(384·E·Ix上)
df_h = qk·B⁴·(1/120)/(E·(Iy上+Iy下))   ← 组合挠度 = 两框惯性矩相加
lim_v = B/250                          lim_h = round3(B/180)
```

**实机对拍（`--selftest=unit-beam` 落盘）**：

| 输出 | V31 | 复刻 |
|---|---|---|
| 上框抗弯 | 42.417 | **42.417** |
| 下框抗弯 | 20.184 | **20.184** |
| 水平向挠度 / 允许 | 0.996 / 6.111 | **0.996 / 6.111** |
| 垂直向挠度 / 允许 | 0.974 / 4.4 | **0.974 / 4.4** |
| 上框 τx / τy | 3.03 / 1.53 | **3.03 / 1.53** |
| 下框 τx / τy | 3.03 / 0 | **3.03 / 0** |

## 五、本轮修复的问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | **V31 bug**：勾「计算中不考虑地震作用」后横梁输出一字未变 | 复刻版 `Session.IgnoreSeismic` → 引擎 `kq=0`，地震项消失只留风荷载（单元式与构件式都生效） |
| 2 | **V31 bug**：切结构形式后「按集中力模型」残留 chk=1（禁用却勾着） | `BeamCalcViewModel.ResetModeSwitches()`，切到单元式时主动复位并提示 |
| 3 | **本轮新发现（严重）**：单元横框表 13 列、横框表 14 列，解析器按 14 列取值 → `Sx/Sy/tx/ty` 全体错位，`ty` 读到「备注」→ 0 → **τx 除零得 ∞** | 按列数自适应取列位；补 IO 层守护单测（断言 `Sx=2994 / Ty=3`，错位必失败） |
| 4 | 分部方法参数名不一致（2 个编译警告） | 统一为 `value` |
| 5 | 静态字段初始化顺序隐患（`UnitSnapshot` 声明在使用之后，会拿到 null） | 声明前移 + 显式数组类型 |
