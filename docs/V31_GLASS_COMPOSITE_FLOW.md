# 复合玻璃（中空 + 夹胶）受力流程 —— 三级分配与胶片类型

> V31 玻璃屏第四段函数区 `0xA46000–0xA49B00`（17 个 rtcRound 定稿点）。
> 实测工况：1100×1380、三片均 6mm、wk=1.37kPa、αmax=0.16、PVB。
> 证据：`v31runs/glass_insullam_rounds.json` + Frida 抓的运算 DAG。

## 零、先说一个结论：三级分配在 V31 里是「合并成一级」

用户描述的流程是「总荷载 → 按中空各层刚度分到两侧夹胶 → 每侧再细分到每片」。
V31 实际写的是**一次按 t³ 分到每片**，分母直接用**全部玻璃片的 Σt³**：

```
侧份额  = S_side / S_all          S_side = 该侧各片 t³ 之和
片份额  = t_i³ / S_side
两者相乘 = t_i³ / S_all           ← 与 V31 的一次分配完全相同
```

实测分母 **648 = 3×216**（三片 6mm 全部计入，`0xA4608D`），证明 V31 用的是合并式。
⇒ **复刻时两种写法都行，结果逐位相同**；本实现按用户要求保留三级结构（便于逐级核对），
但每级都输出中间量，最终与 V31 的合并式对齐到同一位。

## 一、胶片类型的判定依据（必须先定，决定流程走向）

| 证据 | PVB | SGP |
|---|---|---|
| 本屏「夹层配置」下拉（**ctrl id=5**，项序 0/1） | `PVB(聚乙烯醇缩丁醛)` = 0 | `SGP(离子型间层)` = 1 |
| 胶片厚度下拉（ctrl id=3）可用性 | **en=False**（不参与，无需厚度） | **en=True**（必须输入） |
| 输出文案 | `外片玻璃强度计算值:…` | `1#玻璃(夹层偏室外侧)强度计算值:…` |
| 同工况 σ | 10.345MPa | **6.392MPa** |
| 等效厚度 | 0.95×(6³+6³+6³)^(1/3) = **8.221** | 0.95×(12³+6³)^(1/3) = **11.856** |

**判定链**：类型来自**本屏下拉**（不是第一页），选择后立即切换「厚度框 en 状态 + 输出文案 + 公式分支」。
id=5 的下拉项序就是 `InterlayerKind`：0=PVB、1=SGP。

> V31 的两套算法不是"同一个公式换个系数"，而是**两段独立函数**：
> PVB 在 `0xA46xxx–0xA49Axx`，SGP 在 `0xA52xxx–0xA54Axx`。

## 二、PVB 口径的三级流程（已完全闭合）

### 输入（全部来自上游 / 本屏）

| 名称 | 来源 | 单位 | 本次值 |
|---|---|---|---|
| wk | 第一页风荷载链（玻璃屏按本面板 μs 合重算） | N/mm² | 0.00137 |
| a / b | 第一页龙骨间距 → 本屏分格尺寸下拉（短边取 min） | mm | 1100 / 1380 |
| tᵢ（3 片） | 本屏「外片/中片/内片」厚度下拉 | mm | 6 / 6 / 6 |
| αmax | 参数库「地区参数」（北京 0.16） | — | 0.16 |
| 胶片类型 | 本屏「夹层配置」下拉 id=5 | 枚举 | PVB=0 |

### 常量

```
γ = 2.56e-5 N/mm³     E = 72000 N/mm²     12(1−ν²) = 11.52
m = 弯矩系数（a/b 插值，取 4 位）          μ = 挠度系数（取 5 位）
η = 折减系数（θ 分段线性插值，取 3 位）    Q系数 = 5αmax
```

### 第 0 步：荷载（与片数无关，只算一份）

| 变量 | 公式 | 本次值 | 定稿点 |
|---|---|---|---|
| qg | `round6(t₀·γ)` | 0.000154 | `0xA46476` |
| Q | `round6(5αmax·qg)` | 0.000123 | `0xA46599` |

> ⚠ 只取**首片**厚度算一份自重/地震（不是三片之和）。夹层玻璃（单片夹胶）在 `0xA2DB90` 用的是两片之和 —— 两者不一致，登记为疑点。

### 第 1 步（第一级）：总刚度

| 变量 | 公式 | 本次值 |
|---|---|---|
| S_side,outer | Σ tᵢ³（夹胶侧 2 片） | 432 |
| S_all | Σ tᵢ³（全部 3 片） | **648** |
| **输出** | `S_all` = 648 | |

### 第 2 步（第二级）：分到每片

| 变量 | 公式 | 本次值 | 定稿点 |
|---|---|---|---|
| w₀（最外片） | `round6(1.1·wk·t₀³/S_all)` | 0.000502 | `0xA4609A` |
| wᵢ（其余片） | `round6(wk·tᵢ³/S_all)` | 0.000457 | `0xA46CCB` / `0xA47471` |

**1.1 只加在最外侧那一片**（中空玻璃同理，见 9.1）。夹胶**内侧片不加**。

### 第 3 步（第三级）：逐片组合 → θ → η → σ

对每片 i：

| 变量 | 公式 | 外片 | 夹胶内侧片 | 室内单片 |
|---|---|---|---|---|
| W标准ᵢ | `round6(wᵢ + 0.5Q)` | 0.000564 | 0.000518 | 0.000518 |
| W强度ᵢ | `round6(1.5wᵢ + 0.7Q)` | 0.000839 | 0.000772 | 0.000772 |
| θᵢ | `round3(W标准ᵢ·a⁴/(E·tᵢ⁴))` | 8.849 | 8.128 | 8.128 |
| ηᵢ | η表(θᵢ)，3 位 | 0.969 | 0.975 | 0.975 |
| **σᵢ** | `round3(6·m·W强度ᵢ·a²·ηᵢ/tᵢ²)` | **10.345** | 9.578 | 9.578 |

> 夹胶两片同厚 ⇒ 同份额 ⇒ 同 σ；V31 屏上「外片玻璃强度计算值」出现两次同值就是这个原因。

### 第 4 步：挠度（不分片，用等效厚度）

| 变量 | 公式 | 本次值 | 定稿点 |
|---|---|---|---|
| t_e | `round3(0.95·(Σ tᵢ³)^(1/3))` | **8.221** | `0xA49449` |
| θ_δ | `round3(wk·a⁴/(E·t_e⁴))` | 6.099 | `0xA4976A` |
| η_δ | η表(θ_δ) | 0.991 | — |
| D | `round3(E·t_e³/11.52)` | 3,472,593.612 | `0xA495B1` |
| **df** | `round3(η_δ·μ·wk·a⁴/D)` | **3.469** | `0xA49A3B` |
| lim | `round3(a/60)` | 18.333 | `0xA49214` |

## 三、SGP 口径（**未闭合，不臆造**）

已实测到的部分：

| 项 | 值 | 依据 |
|---|---|---|
| 函数区 | `0xA52xxx–0xA54Axx` | 定稿点聚类 |
| 夹层侧合成厚度 | 12 = 6+6，`12³ = 1728` | `0xA543C1` |
| 总刚度 | `1728 + 216 = 1944` | `0xA543F4` |
| t_e | `0.95×1944^(1/3) = 11.8565` → **11.856** | `0xA54415` |
| D | `72000×11.856³/11.52 = 10415846.94` | `0xA54576` |
| θ_δ | 1.410 | `0xA5472F` |
| σ 计算式 | `6·m·W·a²·η/t²`，η=1，**t = 11.969** | `0xA534CF`/`0xA534DC` |
| σ 结果 | **6.392** | 屏上原文 |

**未定位**：σ 里的 `t = 11.969` 从哪来（11.969² = 143.257，不等于 t_e²；也不是 11.856 的任何整次幂）。
在它没拆出来之前，`ComputeComposite(..., InterlayerKind.Sgp, ...)` 显式抛 `NotSupportedException`，
不用「近似值凑 6.392」——那会污染后续所有 SGP 工况。

> 合理猜测（**未验证，不作数**）：SGP 参与受力后夹层等效为一整块，可能存在第二套「强度用等效厚度」
> 公式（与挠度用的 11.856 不同），需要再抓一次 `0xA53000–0xA53500` 的完整 DAG 才能定。

## 四、逐级衔接自检

| 衔接点 | 校验 | 结果 |
|---|---|---|
| 第1→2级 | Σ(tᵢ³/S_all) = 1.1·t₀³/S + Σ_{i>0} tᵢ³/S | ✅ 份额和 = 0.000502+0.000457×2 |
| 第2→3级 | θᵢ ∝ W标准ᵢ；σᵢ ∝ W强度ᵢ·ηᵢ | ✅ 8.849→10.345、8.128→9.578 单调对应 |
| 第3→4级 | 各片 σ 与 df 共用同一 m/μ/η 表与同一 E | ✅ 同一份 table 实例 |
| 挠度独立 | t_e 不参与 σ，σ 的 t 不用 t_e | ✅ 实测如此（PVB） |

## 五、疑点登记

1. **自重/地震只按首片厚度算一份**（0.000154），而「夹层玻璃」分支按两片之和（0.000307）—— 两条分支口径不一致。
2. **SGP 的 σ 用 t=11.969**，与 t_e=11.856 不符，公式未拆 → 已阻断实现，不做近似。
3. 夹胶内侧片**不加 1.1**，只有最外片加 —— 若中空两侧都是夹胶（双夹层-中空），1.1 加在哪一侧/哪一片未验证。
4. 「中空+夹层」默认三片同厚；不等厚时第 0 步的 qg 取哪片未验证。
5. 胶片厚度在 PVB 下 en=False，但下拉里仍有 5 个候选值（0.38~2.28）—— 该值是否被 PVB 公式读取未验证。
