**关键结论：汇宝计算书不只打印结果，而是把「公式 + 系数出处 + 代入 + 结果」都印出来**，例如：

```
wk=βK1K2μzμs1w0 ……4.6.1[GB55001-2021]
μz=0.544×(100/10)^0.44=1.4983
αmax=Fa×αmaxⅡ =1×0.16 =0.16
```

`1 规范依据 → 2 基本参数 → 3 荷载(3.1 风荷载方法/3.2 支承结构风荷载/3.3 面板风荷载/3.4 地震(垂直)/3.5 地震(平行集中力)/3.6 作用效应组合) → 4 立柱(4.1 选材/4.2 截面参数/4.3 截面特性/4.4 抗弯/4.5 挠度/4.6 抗剪) → 5 横梁(5.1–5.6 同构) → 6 玻璃(6.1 板块荷载/6.2 强度/6.3 挠度) → 7 连接(7.1 横梁–角码/7.2 角码–立柱/7.3 立柱–主体) → 8 埋件(8.1 荷载标准值与设计值/…)`

## 5. 本项目侧现状（`D:\Code\Glass`）

### 5.1 数据库（`src\GlassManagement.Api\Data\`，6 库 / 11 表）

| 库 | 表 | 行数 |
|---|---|---|
| SMHS_Region.db | Regions | 634 |
| SMHS_Profile.db | ProfileColumns / ProfileBeams | 95 / 67 |
| SMHS_Bolt.db | Bolts | 324 |
| SMHS_Material.db | PanelMaterials / CurtainWallWeights / AnchorMaterials | 26 / 17 / 48 |
| SMHS_Glass.db | GlassTypes | **0（空表）** |
| SMHS_User.db | Users / RevitSubmissions / UsageLogs | 5 / 0 / 0 |

已发现的数据质量问题（实测样本）：
- `ProfileColumns`：`RadiusOfGyrationX/Y = 0`；`ShearArea = 6`（对 60/80 系列不合理，语义应为"受剪腹板总宽度"）。
- `PanelMaterials`：铝单板行的 `Density/ElasticModulus/ThermalExpansion/PoissonRatio` 全为 null。
- 缺 `Wx2/Wy2`：汇宝按支座/跨中取不同截面模量，缺这列无法复刻其立柱验算。

### 5.2 代码结构

- `src\GlassManagement.Api`：**46 个 Controller**（`GlassCalculationController.cs` 44,752 B 最大）。
- `src\GlassManagement.Core`：**仅 6 个文件**（`Models\CalculationModels.cs` 61,755 B、`Data\GlassDbContext.cs` 等），**无计算代码**。
- 计算书链路：`tests\CalcBookTestHarness` → `calcbook_test_output_s1..s11.docx`；报告见 `docs\validation_report.md`；待办见 `docs\next_steps.md`（TOC、样式、四类图仍为占位）。

### 5.3 映射与缺口（详见 `param_library_gap.md` / `mdb_vs_smhs.md`）

已 1:1：`地区参数↔Regions`、`立柱↔ProfileColumns`、`横框↔ProfileBeams`、`螺栓1–7↔Bolts`、`后锚固材料参数↔AnchorMaterials`、`幕墙自重参数↔CurtainWallWeights`。

主要缺口：双抵抗矩 Wx2/Wy2、面积矩 S、受剪腹板总宽度、锚固 hef/孔径/性能等级、11 类板材（约 60 行）、20+ 张构件型材表（约 900 行）、热工 2 表 + 62 个 `.inx`、`GlassTypes` 空表。
