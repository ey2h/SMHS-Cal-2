## 一、连续梁（四点三跨）= 函数 `0xD42762`

边界 `0xD42762–0xD4DB91`（46,127B）。定位方法：挂 `rtcRound` 收返回地址，连续梁的定稿点
全落在 `0xD45xxx–0xD4Cxxx`；按 `55 8B EC` 扫函数头得 `0xD42762`。

### 公式（每条都有地址）

```
M      = round3( 0.1 · qd · L² )                    0xD475B6 Pow / 0xD475C3 Mul / 0xD475D7 Mul(0.1,…)
W_req  = M / [σ]                                    0xD47740
df     = qk · 0.00677 · L⁴ / E / I                  0xD4C777 Mul(1.414,0.00677) → 0xD4C7E8
I_req  = qk · 0.00677 · L⁴ / E / round3(lim)        0xD49EA6 … 0xD49F17
lim    = min(L/180, 20)                             0xD48151（16.667）
σ      = M / W                                      0xD4B3D7
V      = 0.6 · qk_raw · L · 1.5                     0xD4B8EC Mul(0.6,…) / 0xD4B9D1 Mul(…,1.5)
τ      = S · V / (I · t)                            0xD4BF00
```

关键系数（都是代码字面量）：弯矩 **0.1**、剪力 **0.6**、挠度 **0.00677**、分项 **1.5**。

**注意两个易错点**：
1. **剪力用未取整的 `qk_raw`**（= bay × wk(N/mm²) = 1100×0.001285 = 1.4135），乘 0.6 再乘 1.5；
   而弯矩用**取整后**的 `qd`（2.121）。两者取值不同。
2. 挠度用**取整后**的 `qk`（1.414），不是 qk_raw。

## 二、「其它材质」人工参数（V31 立柱屏）

点「其它材质」单选 `(359,140)` 后，参数框才启用。**探针实测归属**（填 111/222/333 反查输出）：

| 控件（相对坐标）| 含义 | 证据 |
|---|---|---|
| `(529,162)` | 抗弯强度设计值 [σ] | 填 222 → 输出「抗弯强度设计值:222」，且 `W_req = M/222` |
| `(529,185)` | 抗剪强度设计值 [τ] | 填 333 → 输出「抗剪强度设计值:333」 |
| `(529,140)` | 弹性模量 E，**禁用**（恒 70000）| 该模式 `en=False`，改动无效 |
| `(391,162)` | 非强度项（填 111 不影响任何输出）| 三组值互相独立验证 |

实测（双跨 3000/1500、E=70000、f=90、fv=55）：

| 项 | 内置 6063A-T5 | 自定义 90/55 |
|---|---|---|
| 抗弯预选 | 4418.756（=M/135）| **6628.134（=M/90）** |
| 惯性矩预选 | 66756.466 | 66756.466（不变）|
| 挠度 / 抗弯 / 抗剪 | 0.628 / 27.808 / 5.092 | 同（E 未变）|
| 抗弯/抗剪设计值 | 135 / 75 | **90 / 55** |

`--selftest=col-custom` 对拍 **11/11 一致**（含切回内置材质能复原）。
