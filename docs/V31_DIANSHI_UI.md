## 五、与全玻璃屏（FullGlassEngine）的关键差异

1. **四点驳接模型**：m/μ 查「支承点间距比」，m 随 r 增大（全玻璃四边支承 m=0.125 固定）；
2. **玻璃计算跨度 a = 板高支承点间距 1550**（非短边 1500，短边只用于肋公式）；
3. **玻璃挠度多 ηδ 折减**（θδ 查 η 表），全玻璃挠度无 ηδ；
4. **肋挠度用 wD=wk+0.5qd'**（全玻璃用 wk）；
5. **输出标签「玻璃肋实际选用宽度/计算宽度」**（全玻璃是「截面高度」）；
6. **无结构胶校核**；
7. 分隔符：39 星 + 19 em dash。
