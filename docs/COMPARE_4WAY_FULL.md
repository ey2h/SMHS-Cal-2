## 二、这一轮补齐/新确认的四条

1. **ψ 的规范出处定案**：GB50009-2012 **8.3.4 第 3 款** 的对数插值
   `μsl(A)=μsl(1)+[μsl(25)−μsl(1)]·lgA/lg25`。
   因墙面 `μsl(1)=1.0`、`μsl(25)=0.8`，代入即 `1−0.2·lgA/lg25` —— 与复刻实现**完全等价**，不是我方自拟公式。
   验算：A=3.3 → `1−0.2×0.5185/1.39794 = 0.92582`，与 V31 `slot[47]=1.126=0.92582+0.2` 吻合。
2. **规范条文号全部落位**（8.1.2 / 8.2.1 / 8.3.3+表8.3.3 / 8.3.4 / 8.3.5 / 8.6.1+表8.6.1 /
   GB55001 4.6.5-2 / 4.6.6 / 4.6.7 / GB50068 γ0）。
3. **V35 三处「未取证」的排除范围写死了**，并给出下一步该怎么找：
   - `ψ`：不在 `0xA62C07`–`0xA86FEE` 内（25.0 与 0.2 的引用点全部在外）→ 查调用链上的辅助函数
   - `μs1`：常量表无硬编码，`0xA74xxx` 段也无 → 查窗体单选按钮的 Click 事件写槽
   - `K1/K2`：`0.75` 的引用点是地震表 → 查窗体文本框的 Change 事件写槽
4. **V31 补上的硬证据**：`slot[47] = μs1·ψ + μsi` 在 8 种组合下逐条成立
   （1.126 / 1.496 / 1.589 / 1.326 / 1.526 / 1.726 / 1.101），这比"wk 对上了"强得多。
