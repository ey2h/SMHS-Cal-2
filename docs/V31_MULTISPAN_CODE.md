## 二、已闭合的公式（4 组实机样本 28/28 逐位一致）

现场：60/80 系列（I=885950, W=21452, Sx=13606, t=6），分格宽 1100，第一页默认（C 类地形 / 地区未选）。

| 量 | 公式 | 证据 |
|---|---|---|
| 有效跨 | `X = (L² − A²) / L` | `0xD5B301` Mul 用 `0.9506172839506173`（=77/81=1−(A/L)²，A/L=2/9 时精确）；`0xD5B315` ÷2 |
| 第1跨弯矩 | `M1 = qd · X² / 8` | `0xD5C126` Mul(L², qd) → `0xD5C13A` Mul(1−(A/L)²) → `0xD5C14E` ÷8 |
| 第1跨剪力 | `V1 = qd · X / 2` | `0xD5B301` → `0xD5B315` |
| 第2跨支座弯矩 | `M2 = qd · A(A + X) / 2` | `0xD5C84D` Mul(A²,qd) → `0xD5C861` ÷2；`0xD5C86E` Add(qd·A·X/2) |
| 第2跨支座剪力 | `V2 = V1 + qd·(A/2)·(2 + A/L)` | `0xD632BC` Mul(A,qd) → `0xD632D0` ÷2 → `0xD632E4` Mul(2+A/L) → `0xD632F1` Add(V1) |
| 抗弯强度 | `σ = M / W` | `0xD5D887` / `0xD5F583` / `0xD627B4` |
| 抗剪强度 | `τ = Sx · V / (I · t)` | `0xD5E365` Mul(13606,V) → `0xD5E384` ÷I → `0xD5E3A3` ÷t |
| 折算强度 | `σ_eq = √(σ² + τ²)`（**不是** √(σ²+3τ²)） | `0xD60E94` Pow(2,σ) + `0xD60EAF` Pow(2,τ) → Sqr |
| 挠度限值 | `lim = min((A₁ + L₁)/180, 20)` | `0xD48151`；上限常量 `dbl_4019E0 = 20` |
| 风荷载从属面积 | `A_trib = (A₁ + L₁) × 分格宽` | L=2400/A=600 时 A=3.3 → wk=1.285，与单跨 L=3000 同值 |

## 三、尚未闭合（只记录实测，不拟合）

### 3.1 第3跨（稳态跨）

`M3 = M1 − [FPU 累加项]`，`V3` 由 `0xD6049B Mul(13606, V3)` 进入抗剪。

| A | L | M3（由 σ3 反算） | V3（由 τ3 反算） |
|---|---|---|---|
| 600 | 2700 | 1,136,355 | 468.0 |
| 600 | 3000 | 1,480,553 | 484.1 |
| 600 | 2400 | 838,881 | 446.9 |
| 800 | 2700 | 929,215 | 539.9 |

FPU 累加项（`0xD5C45E – 0xD5C54E`，逐指令）：

```asm
fld  qword [eax+ecx*8]      ; eax = Form+84h 数组
fmul qword [edx+esi*8]      ; edx = Form+4Ch 数组
fstp qword [ebp-0B44h]      ; P = a1[i] · a2[j]
fld  qword [eax+ecx*8]      ; 另一个下标
fdiv qword [edx+esi*8]      ; (edx = Form+68h 数组)
fadd dbl_4019C0             ; +1
call sub_41376E             ; 取整/转换（IAT 0x401324，名称待解）
fdiv dbl_4018F8             ; ÷2
fsubr dbl_4019C0            ; = 1 − 上面
fld  qword [eax+ecx*8]
fdiv qword [edx+esi*8]
faddp st(1), st             ; 两项相加
fmul qword [ebp-0B44h]      ; × P
fstp qword [ebp-470h]       ; → 减数
```

常量：`dbl_4018F8 = 2`、`dbl_4019C0 = 1`。
⇒ 减数 `= P · ( 0.5 − (x₁/y₁)/2 + x₂/y₂ )`。
**还差**：`Form+84h / +4Ch / +68h` 三个数组各存什么（下标 `[ebp-5AC/5B0/5B4/5B8/5BC/5C0]`）。

### 3.2 两处挠度

`df1` 与 `df2` 都是**两项相加**：

| A | L | df1 = 项1 + 项2 | df2 = 项1 + 项2 |
|---|---|---|---|
| 600 | 2700 | 18.1775 = 4.3485 + 13.829 | 7.404 = 2.855 + 4.549 |
| 600 | 3000 | 25.8395 | 10.988 |
| 600 | 2400 | 12.5275 | 4.996 |
| 800 | 2700 | 23.692 | 9.7355 |

地址：`0xD662D2 Add`（第1跨）、`0xD6C513 Add`（第2跨后）。两项各自来源未拆。

## 四、这一轮修掉的一个工具级错误（影响历史结论）

之前 `v31_frida_ops.py` 的 helper 名字是**猜的**，本轮用
「运行期 IAT 指针 − msvbvm60 基址 0x734D0000」+ `msvbvm60.dll` 导出表精确解出：

| 地址 | 真名 | 旧误标 |
|---|---|---|
| 0x413552 | `__vbaVarAdd` | AddA ✓ |
| 0x41377A | **`__vbaVarSub`** | X377A（语义待定）✗ |
| 0x4136BA | **`__vbaFreeVarList`** | AddB ✗（根本不是加法，参数也是垃圾） |
| 0x4135BE | `__vbaVarCopy` | Un2 ✗ |
| 0x4137F2 / 0x4137FE / 0x4137F8 | `rtcCos` / `rtcAtn` / `rtcSqr` | 同 ✓ |
| 0x41371A | `rtcRound` | 同 ✓ |

语义统一为 **`out(dst=c0) = c2 op c1`**（Sub 也是 `c2 − c1`）。
`AddB` 那 209 条历史记录全是噪声，今后不再计入。
