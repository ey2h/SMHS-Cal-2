## 五、★ 关键坑（浮点顺序）

**N_v（每承重挂件自重）与自重 G 的乘法顺序不同**：

```
N_v 链（0xE41A3C–0xE41C84）：round6(γ/1e6 · t) × 短边 × 长边 / 承重挂件数
                             → round6(0.0005875)=0.000587 → 0.000587×800×900/2 = 211.32
自重 G 链（0xE40CBE–0xE40CF6）：(γ/1e6) · 短边 · 长边 · t → round3 = 423
```

若用 `G/承重挂件数 = 423/2 = 211.5` 反推 N_v，会得到 211.5，导致挂件抗弯 = 73.208 ≠ 73.149。
必须按 N_v 链独立计算（先 γ/1e6·t 取整，再乘边长），不能用 G 反推。
