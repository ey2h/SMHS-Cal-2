**读表要点**

1. **A 类 β 被下限接管**：`βgz=1.45515`，但 `1+0.7/√2.23134 = 1.46861 > βgz`，所以 `β=1.46861`。
   B/C/D 两类两式恰好相等或 βgz 更大，所以看不出差别 —— 这就是当初"只有 A 类差 0.93%"的全部原因。
2. **z=10 时两式相等**（(z/10)=1）：A 类 βgz=1.6000、下限 1.6178 → 下限胜；B 类两式都 1.7000。
3. **K1/K2 是纯线性乘子**：0.75 → 1.38579（=1.84772×0.75），1.2 → 2.21726，0.8 → 1.47817。
4. **人工给定绕过整条链**：`地形=人工给定`，其余过程参数全 0，`wk取用 = 0.5` 原样使用（不过 1.0 下限）。

### 三条由槽位数据直接证实的关系

1. **`slot[47] = μs1·ψ + μsi`**：
   基准 `1.126 = 1×0.92582 + 0.2`；墙角 `1.496 = 1.4×0.92582 + 0.2`；
   外部人工1.5 `1.589 = 1.5×0.92582 + 0.2`；内部三档 `1.326 / 1.526 / 1.726`
   —— 逐条对得上，**内部三档确实是加在 μs1·ψ 上的绝对值**（即 0.4/0.6/0.8 × μs1 已包含在乘法里）。
2. **`slot[42] = (左分格 + 右分格)/2`、`slot[44] = slot[42]×slot[43]`**：
   基准 1.1×3 = 3.3；把左分格改 2200 → `slot[42]=1.65`、`slot[44]=4.95`（不是 6.6）。
   同时 `slot[47]` 从 1.126 降到 1.101（ψ(4.95)=0.9006，`0.9006+0.2=1.1006`）——
   **A 变大 → ψ 变小 → μs 变小**，整条链一次自证。
3. **标高 150m 只动 β 与 μz**：`β 1.4956→1.4663`、`μz 1.9953→2.2533`，A 与 μs 不变。

### 一个必须记住的 V31 行为（本次踩坑）

**「外部局部体型系数 · 人工给定」输入框只要有值，就会盖过单选按钮。**
实测：选「墙面区」但框里填 0.5 → `slot[47]=0.663 = 0.5×0.92582+0.2`，wk 从 1.848 掉到 1.088。

后果：只要某一轮测试往这个框里写过值而没清掉，**后续所有批次都被它污染**，且数据"看起来仍然合理"。
这就是上一轮 36 个场景里一批值（1.088）的来源。
修正：三个批量动作的复位序列第一条固定为 `paste:258:110:1.0`（把外部框写死），
测试「墙角边区」时写 1.4、测「外部人工给定」时写 1.5 —— 让 μs1 只由这一个来源决定。
