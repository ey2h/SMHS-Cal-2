## 3) 你侧的数据异常（实测，需修）

- `SMHS_Glass.db / GlassTypes` **rows=0** —— 玻璃材料库是空表，玻璃强度只能靠硬编码常量。
- `ProfileColumns` 样本：`RadiusOfGyrationX=0, RadiusOfGyrationY=0`（回转半径全 0，未被填充）；`ShearArea=6` 对 60/80 系列型材明显不合理 —— 汇宝该列叫 **受剪腹板总宽度**，语义与"剪切面积"不同。
- 汇宝把抵抗矩分成 **Wx1 / Wx2（Wy1 / Wy2）** 两套值，你只有一套 `SectionModulusX/Y` —— 这正是连续梁/双跨模型在支座与跨中取不同截面模量的关键，缺这一列就无法复刻汇宝的立柱验算。
- 后锚固缺 **有效锚固深度 hef、钻孔直径、性能等级** 三列 —— JGJ 145-2004 的后锚固承载力计算必须有 hef 和孔径。
- 面板材料只收了铝单板 26 行，汇宝另有 11 类板材（搪瓷板/钢板/不锈钢/钛合金/铜/铝塑/蜂窝铝板/铝镁硅…）共 69 行；其中铝镁硅/钛/铜表还带 **弹性模量、泊松比、密度、热线膨胀系数**，而你的 `PanelMaterials` 这些字段是 null。
