## 二、输出行 ← 控件 的对应关系（扰动实验，逐条实测）

做法：`CB_SETCURSEL` 改一个下拉 → 点「预演」→ 对输出全文做行级 diff → 还原 → 再预演确认回原。

| 改动 | 输出变化 |
|---|---|
| (153,178) 06 → 07 | 「玻璃与铝框间实际结构胶**厚度**取:」6 → **7**；宽度不变 8 |
| (153,200) 08 → 09 | 「玻璃与铝框间实际结构胶**宽度**取:」8 → **9**；厚度不变 6 |
| (153,266) 0.1 → 0.12 | 「结构胶**厚度最小值**不小于:」5.475 → **4.974**；**宽度 6.121 不变** |

结论：
1. **实际宽/厚 = (153,200)/(153,178) 的选值**，与中空层那对（222/244，`en=0` 不可改）无关。
2. **位移能力只进厚度算式**，不进宽度算式。

## 三、厚度算式（含取整位置，已由轨迹坐实）

```
num = round3( (2 / 分格宽) × 层高 )        # 1100/1380 → 2.509（不是 2.5090909）
den = √( δ × (δ + 2) )                     # δ = 位移能力，默认 0.1 → 0.4582575695
t   = round3( num / den )                  # 5.475
```

**取整位置的证据**（`sealant_trace_vartrace.json`）：

```
#28 ra=0xC59177 Mul R8(0.0018181818181818182, 1380) -> 2.5090909090909093
#29 ra=0xC5941D Add I2(2, 0.1)                     -> 2.1
#30 ra=0xC5942A Mul R8(0.1, 2.1)                   -> 0.21000000000000002
#31 ra=0xC5943E Pow R8(0.21, 0.5)                  -> 0.45825756949558405
#32 ra=0xC5944B Div R8(2.509, 0.45825756949558405) -> 5.475086866021048
```

`#32` 的除法左操作数是 **2.509**，不是 2.5090909… ⇒ 分子在相除前已 `round3`。
δ=0.1 时两种口径都得 5.475（所以旧实现没暴露）；δ=0.12 时
`2.509/0.5043808085 = 4.97440 → 4.974`（V31 实测值），
若用未取整分子则 `2.5090909/0.5043808085 = 4.97460 → 4.975`，**差一个末位**。

⇒ `Engines/SealantEngine.cs` 已改为 `thickNum = R((2/BayWidth)*StoryHeight)`，
并新增测试 `位移能力改0_12_厚度4_974_宽度不变` 守护（195 条测试全绿）。
