# ④ 黑箱对照实验设计清单（本机不能运行汇宝，先出设计）

> 状态：设计完成、**未执行**。执行前提：在一台能正常打开并完成一个工况计算的正版机器上进行。
> 约束：只用正版软件自带的正常操作路径（菜单/输入/生成计算书）。不脱壳、不内存转储、不注入代码、不绕过注册或时限检测。
> 记录格式统一为：`实验ID | 输入(JSON/表单值) | 软件输出（含计算书里打印的每个中间系数）| 对照次数 | 判定的分支/规则 | 证据文件路径`
> 每组实验至少 2 次运行，且必须存在"改变一个输入 → 输出判据发生变化"的对照，否则该条分支不算被判定。

## E1 立柱：计算模型选择判据

目的：确定软件在什么条件下把立柱判为 简支 / 双跨 / 多跨连续 / 带悬挑，以及 `Wx1` 与 `Wx2` 分别在哪个环节被取用。

| 实验 | 变量 | 固定项 | 期望读出的输出 |
|---|---|---|---|
| E1-1 | 跨度 L 从 3.0 m 递增到 9.0 m（步长 0.3 m） | 截面、荷载、支承条件输入 | 计算书里"计算模型"名称随 L 的跳变点（写出跳变前后两个 L 值） |
| E1-2 | 层数/跨数 1→2→3→4（同跨度） | 截面、荷载 | 连续梁内力系数如何变化；是否引用"多跨1/多跨2"查表（参数库里这两张表就是候选表源） |
| E1-3 | 悬挑长度 0 → 0.2L → 0.5L | 主跨长度 | 悬挑段用什么模型、支座负弯矩取法 |
| E1-4 | 同一截面，分别按"支座"与"跨中"两种验算位置 | 其余全同 | 抗弯验算分别用 Wx1 还是 Wx2（参数库立柱表同时给 Wx1/Wx2，软件必然有取用规则） |
| E1-5 | 挠度限值改变（输入不同限值或不同构件类别） | 荷载、截面 | 限值来源是输入值还是内置常量；内置常量值 |

判定输出：`立柱模型选择判据表`（条件 → 模型 → 使用的截面特性列）。

## E6 荷载链：风压 → 高度系数 → 体型系数 → 组合

目的：把"软件内部的截断高度、梯度高度、分区取值"这套隐藏规则测出来。

| 实验 | 变量 | 期望读出 |
|---|---|---|
| E6-1 | 工程高度 H 从 10 m 到 200 m（步长 10 m，取 6–8 个点） | μz 的实际取法（梯度高度 α、修正系数）；截断高度在哪个 H 出现 |
| E6-2 | 地区切换（地区参数表挑 8 个代表：沿海/内陆/高原/严寒） | w0、雪压、αmax、极限温差的取数与计算书打印的一致性 |
| E6-3 | 体型系数：墙面 / 雨篷（−2.0） / 侧面 / 迎风背风组合 | K1/K2 的来源：内置常量还是输入 |
| E6-4 | 顺风向 vs 横风向（如有开关） | 是否引入 βz 与不同公式分支 |
| E6-5 | 地震作用：垂直 / 平行（集中力） 两条路径 | 两条路径的判据（何时启用集中力式地震作用），αmax 用法 |
| E6-6 | 作用效应组合（标准组合 / 基本组合） | 分项系数与组合系数的实际取值（计算书会打印代入过程） |

## E7 计算书章节 → 内部步骤映射（用于 ③ 版式对齐）

- 每次运行都生成计算书并保存为 PDF/DOC，抽取章节顺序与打印字段清单。
- 对照 `jss\模板.doc`（Word 模板）与本项目 `calcbook_test_output_s*.docx`：确认每个章节对应哪个计算步骤、每步打印哪些中间量。
- 输出：`calcbook_section_map.csv`（列：step_id, section_no, printed_fields, source_experiment）。

## E8 参数库 → 界面选项 的一致性核对

- 把 `hb_library.sqlite` 的 59 张表逐表挑 1 行，在界面上选到同一型材/材料，比对计算书里打印的截面特性数值。
- 判定点：哪些表在界面上出现、出现在哪个计算项目下（这直接给出**计算项目跳转结构**）。
- 输出：`table_to_ui_map.csv`（列：hb_table, ui_menu_path, calc_item, verified_by_experiment）。
