## 一、怎么进到横梁页（实机链路）

```
主界面菜单「玻璃幕墙 > 全隐框」          → 窗体「全隐框玻璃幕墙计算-基本参数输入」(0x212CD6)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-立柱计算」  (0x202D42)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-横梁计算」  (0x202EF2)
```

三个窗体**同时存在**，靠 `IsWindowVisible` 区分当前页；`FindForm` 必须按标题找，
不能只按 pid（同一进程里有 72 个 `ThunderRT6FormDC`）。

菜单命令：`PostMessage(mdiForm, WM_COMMAND, id, 0)`，「玻璃幕墙 > 全隐框」的 id = **2**。
主窗体是 `ThunderRT6MDIForm`（标题「汇宝幕墙门窗结构计算软件V31.0 (免费版)」）。

### 预选 Wx / Wy 的完整算式链（**已闭合两条链**，槽数组 + 实参双证）

**槽数组必须二次解引用**：`[0x1C911A0]` 里存的是数组指针（`mov ecx, dword ptr [0x1c911a0]`），
实测指向堆地址 `0x2067A90`。VARIANT 16B/槽，vt 在 +0、double 在 +8。

**横梁槽编号（实测）**：

| 槽 | 含义 | 单片 | 中空+夹层 |
|---|---|---|---|
| `[2]` | 分格宽 B | 1100 | 1100 |
| `[3]` | 分格高 H | 1380 | 1380 |
| `[6]` | wk（N/mm²） | 0.001285 | 0.001285 |
| `[7]` | qk | 1.414 | 1.414 |
| `[8]` | qd | 2.121 | 2.121 |
| `[9]` | 自重比例常量 | 0.16 | 0.16 |
| `[10]` | **自重面荷载 g（N/mm²）** | **0.0003** | **0.00055** |
| `[11]` | g × 0.8 | 0.00024 | 0.00044 |
| `[12]` | B × [11] | 0.264 | 0.484 |
| `[13]` | round3([12]×1.4) | 0.37 | 0.678 |
| `[14]` | qd + [13]/2 | 2.306 | 2.46 |
| `[16]` | M_y = [14]·B²/12 | 232521.667 | 248050 |
| `[18]` | 抗弯设计值 f | 90 | 90 |
| `[19]` | H × g | 0.414 | 0.759 |
| `[20]` | round3([19]×1.3) | 0.538 | 0.987 |
| `[21]` | M_x = [20]·B²/8 | 81372.5 | 149283.75 |
| `[22]` | **预选 Wx = [21]/f** | **904.139** | **1658.708** |
| `[23]` | **预选 Wy = [16]/f** | **2583.574** | **2756.111** |
| `[24]` | 弹性模量 E | 70000 | 70000 |

**公式**：

```
g    = 参数库「幕墙自重参数」→ 计算横梁时自重 / 1e6      # N/mm²
B    = 分格宽 (第一页)                        H = 分格高 (第一页)

# 竖向（绕 x 轴，简支 /8，用 Wx）
q_x  = round3( H × g × 1.3 )
M_x  = q_x × B² / 8
Wx预选 = M_x / f

# 水平向（绕 y 轴，固端 /12，用 Wy）
q_y  = qd + round3( B × g×0.8 × 1.4 ) / 2
M_y  = q_y × B² / 12
Wy预选 = M_y / f
```

**自重 g 的来源就是参数库表**（这正是「材质/自重从参数库拿」的落点）：
`幕墙自重参数.csv` 的「计算横梁时自重」列 —— 单片 300、中空或夹层 400、中空夹层或双中空 **550**、
双夹层中空 650（N/m²）。切成「中空+夹层」后槽 `[10]` 实测从 0.0003 变 0.00055，与表第 3 行 550 完全对应。

实参出处：`0x8AEF65`(×1.4) `0x8AF088`(×0.5) `0x8AF095`(+qd) `0x8AF23B`(×B²) `0x8AF24F`(/12)
`0x8AF9BF`(/f) `0x8AF353`(H×g) `0x8AF599`(×1.3) `0x8AF6D9`(×B²) `0x8AF6ED`(/8) `0x8AF856`(/f)。

### 抗弯强度：两个方向正应力**直接相加**（实参钉死）

| 地址 | 运算 | 实值 |
|---|---|---|
| `0x8B55CA` | M_x / 1 | 81372.5 |
| `0x8B55E9` | M_x / Wx_min(**3662**) | **22.220780994** |
| `0x8B560F` | M_y / 1 | 232521.667 |
| `0x8B562E` | M_y / Wy_min(**5763**) | **40.347330731** |
| `0x8B563B` | 相加 | **62.568111724** → 打印 62.568 |

即 `σ = M_x/Wx_min + M_y/Wy_min`（**不是** √(σx²+σy²)，也不是取大值）。
Wx_min / Wy_min 仍是双向各取 min（3662 = min(4100,3662)、5763 = min(5763,6639)）。

⚠ **对不上的一处**：预演输出打印的抗弯是 **62.201**，而 `0x8B563B` 算出来是 62.568
（差 0.367）。扫描全部 42 个定稿点里没有 62.201 这个数，说明打印前的最后一步另有一处处理，
**未定位，不凑**。

### 挠度允许值（实参钉死）

| 方向 | 实参地址 | 实参 | 结果 |
|---|---|---|---|
| 垂直向 | `0x8B1176` | Div(dst, **c1=250**, c2=1100) | **4.4** = B/250 |
| 水平向 | `0x8B0C5E` | Div(dst, **c1=180**, c2=1100) | **6.111111** = B/180 |

即两个方向都用**横梁跨度 B**（不是分格高 H）除各自的限值分母：竖向 250、水平 180。
注意水平那条的 dst 里残留 `232521.667`（=M_y），说明这个 dst 是被复用的局部 Variant，属正常复用不参与运算。

## 四之二、**第一页联动实测**（用户提示项，已验证）

### 玻璃配置（第一页 `Frame 玻璃配置 (648,193)`）

6 个单选：`单片(681,208)` / `中空(681,231)` / `夹层(681,255)` / `中空+夹层(773,208)` / `双中空(773,231)` / `双夹层-中空(773,255)`。

横梁页 `Frame 玻璃配置 (12,26)` 是两个厚度下拉（3.2/4/5/6/8/10/12/15/19/20），
默认 **sel=3 → 6mm**，两层的选项相同、随第一页玻璃类型启用情况联动。

实测对比（同一型材 40/60、其余不动，仅把第一页改成「中空+夹层」）：

| 量 | 单片（默认） | 中空+夹层 | 变化 |
|---|---|---|---|
| 预选 Wx | 904.139 | **1658.708** | +83% |
| 预选 Wy | 2560.046 | **2756.111** | +7.7% |
| 预选 Ix | 25624.721 | **46978.655** | +83% |
| 预选 Iy | 39930.726 | **40330.033** | +1.0% |
| 竖向挠度 | 0.974 | **1.785** | +83% |
| 水平挠度 | 1.973 | 1.993 | +1.0% |
| 抗弯 | 62.201 | **83.807** | +35% |
| 抗剪 tx / ty | 6.006 / 1.531 | **6.466 / 2.806** | +8% / +83% |
| 允许值 | 4.4 / 6.111 | 4.4 / 6.111 | 不变 |

**结论**：玻璃配置通过**自重**进入横梁竖向荷载，竖向一组量整体 +83%；
水平方向几乎不变（只随 wk 的 1% 级波动）。所以横梁取证**必须固定第一页的玻璃配置**，
否则同一段代码会算出两组数。

## 七、环境注意（本轮踩到的）

- Bash 沙箱里 `tasklist` 看不到 V31 → `find_pid` 改用 `EnumWindows` + 类名 `ThunderRT6*` + 标题含「汇宝」。
- PowerShell 工具禁止 `Add-Type`，纯 ctypes 的 python 脚本可以直接跑；但**内联 `-c` 脚本含 `%` 会被安全策略拦**，必须写成文件。
- V31 需要点过「试用软件」才会常驻，否则超时退出；用 `v31_keep.ps1`（需 `Set-ExecutionPolicy -Scope Process Bypass`）。
- Frida 附加后如果脚本被强杀，会连带杀掉 V31，重新走「启动 → 试用 → 菜单 → 第一页 → 下一步」要 2-3 分钟。
