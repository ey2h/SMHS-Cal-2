## 三、第3跨（稳态跨）已闭合

### 3.1 公式

记 `t = (1 − (A/L)²) / 2`（`0xD5C4CF` fadd 1 → `__vbaPowerR8` 平方 → `/2` → `1 − ·` → 再 `+ A/L`，
代数化简后**正好等于** `(1 − (A/L)²)/2`）：

| 量 | 公式 | 证据 |
|---|---|---|
| 中间量 S₃ | `S₃ = V1 − qd·A·t` | `0xD5B329` Sub(V1, qd·A·t) |
| 第3跨弯矩 | `M3 = M1 − S₃·A·t` | `0xD5C5B9` Sub(M1, S₃·A·t)；`0xD5C54E` 写减数 |
| 第3跨剪力 | `V3 = rtcRound(S₃·A/L, 0)` ← **0 位**取整 | `0xD5FFC7` fdiv → `0xD5FFFB/0xD60002` `push 0` + `rtcRound` |

**关键细节**：V3 的分母是 **L**、且 `rtcRound` 的位数是 **0**（整数），
所以 V3 永远是整数（468 / 540 / 484 / 447）。

### 3.2 那三个数组是什么（运行期直读，`v31_frida_arrays.py`）

| 偏移 | 内容 | 实测（A=800/L=2700） |
|---|---|---|
| `Form+0x84` | 各跨**剪力序列**（迭代收敛） | `0,0,2588.574,1821.589,2048.844,1981.509,…,1996.93` |
| `Form+0x4C` | 各跨悬挑 **A** | `0,800,800,…` |
| `Form+0x68` | 各跨跨长 **L** | `0,2700,2700,…` |

累加块 `0xD5C45E–0xD5C54E` 实参（`v31_frida_m3.py` 逐次抓）：
`P = arr84[i]·A`、`T1 = T2 = A/L` ⇒ 减数 `= P·(1 − (1+A/L)²/2 + A/L) = arr84[i]·A·t`，
实际取的是 **i=3**（`arr84[3] = S₃`），与式 3.1 一致。

## 三之二、两处挠度已闭合（8/8 逐位）

先记三组公共量（`r = A/L`）：

```
X  = (L² − A²)/L                     有效跨
V1 = qd·X/2                          第1跨剪力
t  = (1 − r²)/2                       → D = qd·A·t
S₃ = V1 − D                           arr84[3]
S₄ = V1 − D·(1 − r)                   arr84[4]
c₁ = 1 − 4r² − 3r³   c₂ = 1 + r
EI = E·I
```

**迭代规律（新发现，两组参数都验证）**：`d₁ = D`，`d_{k+1} = D − r·d_k`；
`arr84[k] = V1 − d_{k−1}`。不动点 `d∞ = D/(1+r)`（A=600 → 492.10、A=800 → 591.67，与实测收敛值一致）。

| 量 | 公式 |
|---|---|
| bracket₁ | `[(1+r)·A²·V1·L/3 − c₁·A·qk·L³/24] / EI` |
| bracket₂ | `[(1+r)·A²·S₄·L/3 − c₁·A·qk·L³/24] / EI` |
| df₂C | `5·qk·L⁴/(384EI)·(1 − 2.4r²)` |
| X₂ | `S₃·A·L²/16`（`0xD6B6FA` `fdiv dbl_402F88=16` 确认）|
| **df1** | `round3(bracket₁)/2 + round3(df₂C)` |
| **df2** | `round3(bracket₂)/2 + round3(df₂C − X₂/EI)` |

## 四、这一轮修掉的一个工具级错误（影响历史结论）

之前 `v31_frida_ops.py` 的 helper 名字是**猜的**，本轮用
「运行期 IAT 指针 − msvbvm60 基址 0x734D0000」+ `msvbvm60.dll` 导出表精确解出：

| 地址 | 真名 | 旧误标 |
|---|---|---|
| 0x413552 | `__vbaVarAdd` | AddA ✓ |
| 0x41377A | **`__vbaVarSub`** | X377A（语义待定）✗ |
| 0x4136BA | **`__vbaFreeVarList`** | AddB ✗（根本不是加法，参数也是垃圾） |
| 0x4135BE | `__vbaVarCopy` | Un2 ✗ |
| 0x4137F2 / 0x4137FE / 0x4137F8 | `rtcCos` / `rtcAtn` / `rtcSqr` | 同 ✓ |
| 0x41371A | `rtcRound` | 同 ✓ |

语义统一为 **`out(dst=c0) = c2 op c1`**（Sub 也是 `c2 − c1`）。
`AddB` 那 209 条历史记录全是噪声，今后不再计入。

## 4.2.3 已确认的算式（与静定同源）

| 量 | 公式 | 地址 |
|---|---|---|
| 抗弯强度 | `σ = M / W` | `0xD7E8E2` |
| 抗剪强度 | `τ = Sx·V/(I·t)` | `0xD7FAD4`(Sx·V) → `0xD7FAF3`(÷I) → `0xD7FB12`(÷t) |
| 折算强度 | `σ_eq = √(σ² + τ²)` | `0xD802F4`/`0xD80316` Pow(2) → `0xD80344` Pow(0.5) |
| 挠度限值 | `lim = (A₁ + L₁)/180`（同静定） | 2800+600 → 18.889 ✓ |
| 弯矩组成 | `M = qd·A²/2 + C`（C 来自求解器数组） | `0xD7BF3D`(A²·qd) → `0xD7BF51`(÷2) → `0xD7BF5E`(Add C) |
| 挠度组成 | `df = A − B/2`（第二项为负） | `0xD878A8`(÷2) → `0xD878BC`(Add) |

## 4.2.4 未解：C、V、df 两项来自一个迭代求解器

`0xD7C369 – 0xD7C95C` 是求解器主体，形如：

```
12.528 = qd × 6
277 720 704 000 = 22 168 000 000 × 12.528
/24 → 11 571 696 000
Add(−177 084 000) → 11 394 612 000
/2 → 5 697 306 000
/3400 → −1 675 678        (3400 = A + L)
```

即典型的三弯矩/弯矩分配迭代（含 `M_prev` 反馈与 `(A+L)` 归一化），
循环 10 次（`0xD7BC0E` 的 `Sub` 计数 1..9）。
收敛后把结果写进数组，`M / V / df` 都从数组取值。
