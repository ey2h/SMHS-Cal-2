## 4. 已闭合的算式（代码 + 实机双证）

### 4.1 抗承压能力 = 螺栓数 × 公称直径 × 被承压板厚 × 承压强度设计值

符号执行为四连乘（`__vbaVarMul` 链），以 `A95CE5 → A95D70` 为例：

```
A95CE5  push &slot[25] ; A95CF7 push &slot[29] ; A95D09..D10 __vbaVarMul  → slot[25]*slot[29]
A95D16  push &slot[26] ; A95D2F __vbaVarMul                               → ×slot[26]
A95D35  push &slot[28] ; A95D4E __vbaVarMul                               → ×slot[28]
A95D55  __vbaVarMove → [-B4h] ; A95D70 rtcRound ; A95D75 slot[30]=结果
```

| 输出 | 代码算式 | 代入 | 实机 | 扰动复核 |
|---|---|---|---|---|
| slot30 横梁壁 | slot[25]×slot[29]×slot[26]×slot[28] | 2×6×3×185 | **6660** ✓ | 改角码厚度不变 ✓ |
| slot45 立柱壁 | slot[42]×slot[44]×slot[43]×slot[77] | 2×6×3×185 | **6660** ✓ | 同上 ✓ |
| slot50 角码壁 | slot[42]×slot[44]×slot[10]×slot[49] | 2×6×5×185 | **11100** ✓ | 角码厚 5→7 ⇒ **15540** = 2×6×7×185 ✓ |
| slot68 立柱壁(主体) | slot[84]×slot[66]×slot[67]×slot[43]×slot[81] | 2×2×12×3×185 | **26640** ✓ | 改角码壁厚不变 ✓ |
| slot73 角码壁(主体) | slot[85]×slot[66]×slot[67]×slot[7]×slot[72] | 2×2×12×6×305 | **87840** ✓ | 单侧角码 ⇒ **43920** = 1×2×12×6×305 ✓；角码壁厚 6→8 ⇒ **117120** = 2×2×12×8×305 ✓ |

### 4.3 单栓承载力（π 取 3.14，这是最容易被"算不准"的一处）

数值轨迹（`--varhook 1`，`0xA93EE9–0xA93F29`）：

```
Pow(5.061833, 2)      = 25.622153319889      ; d_eff²（M6 有效直径）
Mul(3.14, 25.6222)    = 80.45356142445146    ; ★ π=3.14，不是 3.14159
Mul(80.45356, 190)    = 15286.176670645778   ; × f_v=190（slot21）
Div(15286.1767, 4)    = 3821.5441676614446   ; /4 → πd²/4
```

主体（M12，`0xA9D117–0xA9D17D`）：`Mul(2,3.14)=6.28 → Pow(10.35821,2)=107.2925
→ Mul=673.797 → ×190=128021.428 → /4=32005.357`

⇒ 横梁/立柱与角码：`单栓承载力 = 3.14·d_eff²·f_v/4`（单剪）
⇒ 立柱与主体：轨迹首步是 `Mul(2, 3.14) = 6.28` ⇒ **双剪**，`= 2·3.14·d_eff²·f_v/4`
（先按单剪实现得 16002.679，正好差一半，被测试逮住——这条已写进回归用例）

（此前用 π=3.14159 算得 3823.25 对不上，就是 π 被截成 3.14 所致；现已由轨迹确证。）

### 4.4 实际受力：风/地震两项组合

**横梁侧 633.889（0xA9348A–0xA938EB）**

```
风项  Mul(1.5, wk) = 0.0019275
      Pow(1100, 2) = 1210000
      Mul → 2332.275 / 4 = 583.069              ; 1.5·wk·L²/4
地震项 Mul(5, 0.16) = 0.8 ; Mul(0.8, 0.0003) = 0.00024
      Pow(1100,2) = 1210000 ; Mul → 290.4 / 4 = 72.6
      Mul(1.4, 72.6) = 101.64
      Mul(0.5, 101.64) = 50.82                  ; 0.5·1.4·地震项
受力  Add(583.069, 50.82) = 633.889
```

**立柱侧 699.598（0xA961EF–0xA96476）**：`227.7 = 0.0003×1380×1100/2`、
`296.01 = 1.3×227.7`，再与横梁侧做平方和开方：

```
Pow(633.889,2)=401815.264321 ; Pow(296.01,2)=87621.9201
Add → 489437.184421 ; Pow(·,0.5) = 699.5978733679799
```

**主体 7304.379（0xA9BC22–0xA9CA0D）**：


## 5. 扰动实验（输入→输出归因，不涉及任何数值拟合）

脚本：`connect_frida.py --stack 1 --set/--click/--combo`，改一个输入重跑一次，比对槽数组差分。

| 实验 | 改动 | 变化（槽差 + 定稿点出参差） |
|---|---|---|
| E1 | 横框角码厚度 5→7；主体角码壁厚 6→8 | slot10 5→7、slot7 6→8；**slot50 11100→15540**（=2×6×7×185）、**slot73 87840→117120**（=2×2×12×8×305） |
| E2 | 勾选「单侧角码」 | 仅 slot85 2→1；**slot73 87840→43920**（=1×2×12×6×305） |
| E3 | 主体螺栓行下拉改选 | 无变化（`CB_SETCURSEL` 对该下拉列表不生效，需真实展开后再测） |

E1/E2 是决定性的：两组独立扰动分别只改动一个乘积因子，输出按**同一算式**精确变化
（15540 / 117120 / 43920 全部逐位吻合），因此 §4.1 五条承压算式**无需再猜**。

> 记一次判据踩坑：定稿点的槽快照取在 rtcRound **入口**，发生在写槽之前，
> 所以本屏最后一个定稿点写的 slot73 在任何快照里都是空——早前据此误判「87840 与算式矛盾」。
> 已加 `rpc.exports.dumpSlots` 在预演结束后主动补读终态槽（`finalSlots` 字段），
> 现 25 个输出槽在终态快照里**全部**命中，与计算书原文逐位一致。

## 6. 未闭合项（明确登记，未凑数）

1. **槽 26 / 43 = 3 的 UI 来源未定位**：数值由实机确证、且在算式里就是「被承压板厚」，
   但它是 基本参数页 的哪个字段（立柱壁厚/横梁壁厚），尚未用扰动实验确认。
   （要动它必须回退到第一页改参数再走完四屏，本轮未做。）
2. **槽 66 / 84 的物理含义未定位**：两者都是 2，只在立柱与主体段出现；
   slot85 已由扰动实验确认是「单侧角码系数」（2→1 时 87840→43920）。
3. **槽 16 = 0.0003、槽 78 = 0.0004、槽 15 = 0.16、槽 5/1.3/1.4/0.5 等系数的语义未定位**：
   数值与所在算式已确证（见 §4.4），但没找到它们的 UI/参数库来源。
4. **主体螺栓规格下拉（`(286,378)`）无法用 `CB_SETCURSEL` 更改**，螺栓行切换的归因实验未完成。
5. 立柱页受本次「Var 操作数方向」修复影响：旧 `v31_roundpoint_expr.tsv` 的除法/幂结果方向是反的，
   已修正切片器，但立柱 93 条公式表**尚未按新切片器重跑核对**。
