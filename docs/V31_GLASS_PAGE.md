## 三、公式（全部带地址，运行期数值回代过）

```
γ(玻璃) = 2.56e-5 N/mm³        // 25.6 kN/m³，常量池 0x402818
E       = 72000 N/mm²          // VT_I4 立即数 0x11940（0xA21266）
12(1−ν²)= 11.52                // ν=0.2（0xA21D5E 的除数）

qg = round6(t·γ)                       // 0xA20BDB  6mm → 0.000154
Q  = round6(qg·5αmax)                  // 0xA20D42  0.000123
W₁ = round6(1.5·wk + 0.7·Q)            // 0xA20FC7  0.002141   ← 强度用
W₂ = round6(wk + 0.5·Q)                // 0xA210CD  0.001431   ← θ_σ 用

θ_σ = round3(W₂·a⁴/(E·t⁴))             // 0xA21359  22.453
η_σ = η表(θ_σ)  → 0.910188 → 取 3 位 0.91
σ   = round3(6·m·W₁·a²·η_σ / t²)       // 0xA216F8  24.793

θ_δ = round3(wk·a⁴/(E·t⁴))             // 0xA21A95  21.496   ← 只吃 wk，不吃 Q
η_δ = η表(θ_δ)  → 0.914017 → 0.914
D   = round3(E·t³/11.52)               // 0xA21D80  1350000
df  = round3(η_δ·μ·wk·a⁴/D)            // 0xA21F6C  8.23
lim = round3(a/60)                     // 0xA21C38  18.333
```

**两条链不同源**（最容易踩的坑）：
- θ_σ 用**标准组合 W₂**（含 0.5Q），θ_δ 用**纯 wk**；
- σ 用设计组合 W₁，df 用纯 wk。

## 四、三张表

### 4.1 折减系数 η（`0xA78E85`，θ 断点）

```
5→1.00  10→0.96  20→0.92  40→0.84  60→0.78  80→0.73  100→0.68
120→0.65  150→0.61  200→0.57  250→0.54  300→0.52  350→0.51  400→0.50
```
- θ ≤ 5 取 1.00；θ > 400 取 0.50。
- 插值（`0xA79518` 段）：`η = η上 − (η上−η下)·(θ上−θ)/(θ上−θ下)`。
- **结果取 3 位小数**：0.910188→0.91、0.914017→0.914（两点判别；不是 2 位也不是 6 位）。

### 4.2 弯矩系数 m（`0xA795D7`，a/b 断点）

```
0→0.125  0.25→0.123  0.33→0.118  0.40→0.1115  0.50→0.100  0.55→0.0934
0.60→0.0868  0.65→0.0804  0.70→0.0742  0.75→0.0683  0.80→0.0628
0.85→0.0576  0.90→0.0528  0.95→0.0483  1.00→0.0442
```
a/b = 1100/1380 = 0.7971014493 → 插值 0.06311884058 → **取 4 位 = 0.0631**（运行期乘数就是 0.0631）。

### 4.3 挠度系数 μ（`0xA79B07`）

```
0→0.01302  0.20→0.01297  0.25→0.01282  0.33→0.01223  0.50→0.01013
0.55→0.00940  0.60→0.00867  0.65→0.00796  0.70→0.00727  0.75→0.00663
```

## 五、玻璃部分 wk（1.37）的组成

玻璃屏**自己算** wk（`0xA7CE09` 起的共用风荷载函数，用 **0x1C91168** 槽数组）：

```
wk = μz · βgz · 地形系数 · μs合 · (μs内压档 + 1) · w0
   = 1.0  × 1.6929 ×   1     × 1.4983 ×   (0.2+1)   × 0.00045    = 0.00136969…  → 0.00137
```
- `0xA7CEDA`：`slot[0x45] + slot[0xb]` = 1 + 0.2 = 1.2 → 存 slot[0x35]
- `0xA7D00C…0xA7D07C`：五次连乘 → `0xA7D081` 存 wk
- 屏上显示 `玻璃部分风荷载标准值为:1.37KPa`

与横梁屏的 1.285 不同，是因为**各屏用自己面板的 μs合**（1.4983）重算，w0/βgz/μz 全部来自第一页。
→ 复刻口径：玻璃屏取第一页的 w0/βgz/μz/地形/内压档，按玻璃面板的 μs合 重算，不另立一套参数。

## 九、★ 三种玻璃配置走三段不同函数（2026-10-25 实测）

玻璃屏不是一套公式，按第一页「玻璃配置」分三个分支，**各有独立函数区与槽布局**：

| 配置 | 函数区 | 定稿点数 | 输出数字 | 片位可用性 |
|---|---|---|---|---|
| 单片玻璃 | `0xA1EBF5–0xA21F80` | 9 | 5（σ1、df1） | 只有外片可用，中片/内片 en=False，夹层块 en=False |
| 中空玻璃 | `0xA26000–0xA29200` | 17 | 7（σ外、σ内、df） | **中片 en=False**，外片+内片可用 |
| 夹层玻璃 | `0xA2DB00–0xA2FA00` | 17 | 5（σ1、df1） | 外片+内片可用，**夹层配置块解锁** |

> 中空/夹层分支**完全不走**单片那个函数——最初在 `0xA1EBF5–0xA22000` 范围挂 rtcRound 得到 0 命中，
> 换成全范围才聚出 `0xA26xxx` / `0xA2DBxx`。

### 9.1 中空玻璃（两片）

```
qg  = round6(t·γ)                     // 0xA26538  0.000154（单份）
Q   = round6(5αmax·qg)                // 0xA266B1  0.000123

w外 = round6( (1.1·wk) · t外³/(t外³+t内³) )   // 0xA26972 → 0.000754   ★ 外片乘 1.1
w内 = round6(   wk    · t内³/(t外³+t内³) )   // 0xA26A0B → 0.000685   ★ 内片不乘

W标准_i = round6(w_i + 0.5Q)          // 0xA26B43  外 0.000816 / 内 0.000746
W强度_i = round6(1.5·w_i + 0.7Q)      // 0xA26C8C  外 0.001217 / 内 0.001114
θ_i     = round3(W标准_i·a⁴/(E·t_i⁴)) // 外 12.803 / 内 11.705
σ_i     = round3(6·m·W强度_i·a²·η_i/t_i²)   // 外 14.697（0xA27D86）/ 内 13.51（0xA2866C）

t_e = round3( 0.95·(t外³+t内³)^(1/3) )      // 0xA28BA2  7.18155 → 7.182（先取整再往下用）
θ_δ = round3(wk·a⁴/(E·t_e⁴))                // 0xA28EB6  10.471 → η=0.958
D   = round3(E·t_e³/11.52)                  // 0xA28D00  2315347.704
df  = round3(η·μ·wk·a⁴/D)                   // 0xA2917B  5.029
```

### 9.2 夹层玻璃（两片 + 胶片）

```
qg  = round6((t₁+t₂)·γ)               // 0xA2DB90  0.000307  ★ 两片之和（中空只用一片）
Q   = round6(5αmax·qg)                // 0xA2DD0E  0.000246

w标准 = round6(0.5·wk + 0.25·Q)        // 0xA2DEE1  0.0007465   ★ 系数写死「每片一半」
w强度 = round6(0.75·wk + 0.35·Q)       // 0xA2E21D  0.0011136   （0.25=0.5×0.5, 0.35=0.7×0.5）
θ     = round3(w标准·a⁴/(E·t₁⁴))       // 0xA2E683  11.705 → η=0.953
σ     = round3(6·m·w强度·a²·η/t₁²)     // 0xA2EA28  13.51     ★ 只出一组，用单片厚度

t_e = round3( (t₁³+t₂³)^(1/3) )        // 0xA2F3FC  7.56      ★ 无 0.95
θ_δ = round3(wk·a⁴/(E·t_e⁴))           // 0xA2F709  8.528 → η=0.972
D   = round3(E·t_e³/11.52)             // 0xA2F553  2700507.6
df  = round3(η·μ·wk·a⁴/D)              // 0xA2F9CE  4.375
```

## 十、★ 玻璃 wk 口径（2026-10-25 三屏对比实测，未闭合）

### 10.1 实测：三屏 wk 不同源

同一次会话、同一份第一页参数（北京 w0=0.45、B 类、z=100、αmax=0.16）：

| 屏 | 屏上 wk | 槽证据 |
|---|---|---|
| 立柱 | **1.285** | `0x1C91168[47]` = **1.126**（μs合，1.0×ψ+0.2） |
| 横梁 | **1.285** | 同上（复用立柱口径） |
| 玻璃 | **1.37** | `0x1C91168[0x0a]` = **1.4983**；玻璃槽 `0x1C911BC[10]`=0.00137 |

### 10.2 两条链的结构差异

```
玻璃：  1.37  = 0.45 × 1.6929 × 1.4983 × 1.2
立柱：  1.285 = 0.45 × 1.6929 × 1.126  × 1.5
                └─ w0 ─┘   └ β ─┘  └ μs ┘  └系数┘
```

- β = 1.6929 两者相同（同 z、同地形）
- **μs 不同**：1.4983 vs 1.126
- **末尾系数不同**：玻璃 ×1.2（= 1+内压 0.2，与 ops 日志 `0xA7CEDA: 1+0.2=1.2` 一致）；立柱 ×1.5

### 10.3 推论（待验证，不作数）

若两者 A 相同（立柱从属 A = 3.3 m²，即 `BasicParamsViewModel.cs:256` 的 bayAvg×柱跨）：

```
ψ(3.3) = 1 − 0.2·lg(3.3)/1.4 = 0.9259
立柱：μs1·ψ + 0.2 = 1.0×0.9259 + 0.2 = 1.126  ✅ 与槽 [47] 完全一致
玻璃：1.4×0.9259 + 0.2 = 1.4962           ≈ 1.4983（差 0.002，需 A 精确值）
```

⇒ 猜测：**玻璃屏的 μs1 = 1.4，立柱/横梁的 μs1 = 1.0**，A 相同。
但立柱末尾那个 ×1.5 的来源未定位，不能凭此实现。

### 10.4 为什么复刻仍按「待接入」处理

`Session.GlassWindKpa` 现在取 `WindStandardKpa`（1.285），与实机 1.37 差 0.085。
**没有**用 `1.285 × (1.4983×1.2)/(1.126×1.5) = 1.368` 这种比值去凑 ——
那是用实测结果反推内部量，项目铁律明令禁止（差一个末位也不许凑数）。

要闭合必须再挖两处：
1. `0x1C91168[0x0a]`（=1.4983）的写入点 —— 确认 μs1 是否为 1.4、A 取多少
2. 立柱链末尾 ×1.5 的来源 —— 确认它是否只属于构件（不含面板）

挖出来之后 `GlassWindKpa` 就能按公式算，届时把 `GlassWindResolved` 置 true 并解除两条 `[Ignore]`。
