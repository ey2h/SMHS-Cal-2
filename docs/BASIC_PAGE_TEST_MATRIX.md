## 五、本轮结论（8 条）

1. **玻璃配置（中空/夹层）对"立柱屏"数值零影响** —— V31 实测与基准逐位相同。
   以前以为它会影响立柱，是因为把"自重"当成了轴力来源；实测说明立柱屏里没有这一项。
2. **有中横结构、雪荷载敏感对"立柱屏"数值也零影响** —— 前者只作用于横梁/中横框，后者只作用于水平构件。
3. **单元式幕墙是唯一会让立柱屏结构变化的选项**：抗弯矩预选与挠度直接为空（不再按单框预选），
   抗弯/抗剪恰为构件式的一半（双框等刚度分摊，V31 实测 79.975 = 159.95/2）。这一项复刻完全没实现。
4. **K1 / K2 都是线性乘进 wk**：1.848×0.75=1.386、×1.2=2.218、×0.8=1.478，四点四位小数全对。
5. **风荷载「人工给定」完全取代算值，且不过 1KPa 下限**：填 0.5 得 wk=0.5（若过下限会变成 1.0）。
   这条靠"填一个 <1.0 的值"才判得出来 —— 填 1.234 时两种实现结果相同，是无效实验。
6. **V31 第一页 68 个控件里没有 γ0 / 安全性能等级下拉** → γ0 无法对拍，只能靠 V35 控制树 + GB50068。
7. **地区查找对简写名不安全**：写「广州」会被下拉清成 null（参数库实名是「广东广州」），
   w0 静默回落到 0.3 下限、wk 变成 1.0078。产品侧建议补状态栏告警。
8. **6 种玻璃配置 + 抗震三档 + 雪荷载，对立柱屏全部零影响**（V31 逐位不变）。

### 两个"复位漏洞"教训（都真实踩到）

| 位置 | 现象 | 根因 | 修正 |
|---|---|---|---|
| V31 批量脚本 | 整批数据看着"合理"但基准变成 3.265 | 上一轮把外部体型停在「人工给定 1.5」，新 case 没先复位 | 每个 case 前跑全套 `$BASE` 复位；再加一条「基准_复位后」自检行 |
| 复刻扫描 `SweepBasicPage` | K2=0.8 得 1.7738（=1.8477×1.2×0.8），像是产品 bug | `Baseline()` 没重置 K1/K2/人工给定，继承了上一 case 的 K1=1.2 | `Baseline()` 补 `TerrainFactor / WindDirFactor / WindManual / WindManualKpa` |

**通用规则：批量对拍必须有"基准行"，且基准行必须是复位后再跑。基准值不对，整批都不可信。**
