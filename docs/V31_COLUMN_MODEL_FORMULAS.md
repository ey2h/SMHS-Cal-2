## 二、两条已逐指令验证的公式（示例）

### 2.1 单跨简支：`M = round3(q·L²/8)` @ `0x18CEFB7–0x18CF035`

```asm
18CEF6A  push [ebp-4F8h] ; call __vbaR8Str    ; L ← 控件文本
18CEF75  fstp  [ebp-3B0h]                     ; L
18CEFB7  fld   2.0                            ; 指数 2
18CEFC2  fld   [ebp-3B0h]                     ; 底 L
18CEFCD  call  __vbaPowerR8                   ; L²
18CEFD2  fmul  [ebp-358h]                     ; × q（内力/设计值）
18CEFE1  fdiv  8.0                            ; / 8
18CEFFA  fstp  [ebp-510h]                     ; 原始值
18CF014  push 3 ; call rtcRound               ; ★ 取 3 位
18CF035  fstp  [ebp-3E8h]                     ; M
18CF05A  push offset dword_506F70             ; "最大弯矩为：M=qL^2/8="
```

⇒ **弯矩本身要 round3**，复刻当前是 `M = qd·L²/8` 不取整，这是待修项（会影响 σ 与 W 预选）。

### 2.2 悬挑（带外伸）：`M = round3( q·a²·[1 − 2a/(3(a+L))]^1.5 / 3 )` @ `0x18D61E4–0x18D62ED`

```asm
18D615F  ...                                   ; [ebp-3B0h] = a（外伸）
18D61E4  fld 2.0 ; fld a ; call __vbaPowerR8   ; a²
18D61FF  fmul [ebp-358h]                       ; q·a²
18D620F  fstp [ebp-0E0Ch]                      ; 暂存
18D6215  fld 1.5                               ; ★ 1.5 是 **指数**，不是分项系数
18D6220  fld 2.0 ; fmul a                      ; 2a
18D622C  fld a ; fadd L                        ; a+L
18D6241  fdivp                                 ; 2a/(a+L)   （= 2α）
18D6257  fdiv 3.0                              ; 2α/3
18D6270  fsubr 1.0                             ; 1 − 2α/3
18D6285  call __vbaPowerR8                     ; ^1.5
18D628A  fmul [ebp-0E0Ch]                      ; × q·a²
18D6299  fdiv 3.0                              ; /3
18D62B2  fstp [ebp-510h]
18D62CC  push 3 ; call rtcRound                ; round3
18D6312  push offset dword_50736C              ; "最大弯矩为：M=qa^2/3*(1-2α/3)^1.5="
```

**这条同时证明**：立柱函数里 `1.5` 的唯一两处引用都是**指数**，载荷分项系数不在这里。

## 三、★ 关键结构结论：qk / qd 不在立柱函数里算

`[ebp-358h]`（内力 q）**只有一个写入点** `0x18BD40B`：

```asm
18BD389  mov  eax,[ebp+8]          ; this
18BD391  call [eax+334h]           ; 取子对象
18BD39F  call __vbaObjSet
18BD3BF  call [eax+0A0h]           ; 读属性 → 字符串
18BD406  call __vbaR8Str           ; 字符串 → double
18BD40B  fstp [ebp-358h]           ; ← q（设计值）
```

同样 `[ebp-320h]`（标准值 qk）在 `0x18BD366` 由另一子对象的属性读入。

⇒ **立柱函数的两个荷载都是「读控件文本」，qk/qd 的计算（含 ×1.5 与取整）在别的函数里，目前未定位。**

因此「B10 的 qd 取整平局」不能用立柱函数解释，也不能靠拟合定论——**记为未定位**。
