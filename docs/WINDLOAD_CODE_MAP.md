## 3. 锚点表（语义 → 块地址）

> 每一条都是「常量地址 → 引用块」的唯一命中，可用 `ida_map.py at <addr>` 复核。

### 3.1 阵风系数 βgz（四类，逐条与常量表一致）

| 场地 | 块地址 | 常量 | 值 |
|---|---|---|---|
| A | `0xA702E0` | `dbl_401F10` | I10=0.12 / α=0.12（同一常量取负得 −α） |
| B | `0xA708CF` | `dbl_401EF8` | 0.14（α=0.15 见 `dbl_401EF0`） |
| C | `0xA70EBA` | `dbl_401EE0` | 0.23（α=0.22 见 `dbl_401ED8`） |
| D | `0xA714A9` | `dbl_401EC0` | 0.39（α=0.30 见 `dbl_401EE8`） |

四个块都含 `VarPow → VarDiv → VarMul → VarAdd → rtcRound`，结果写 **slot[8]**。
峰值因子 g：国标 `dbl_401F18`=**2.5** @`0xA6FF5E`；广东 `dbl_401F68`=**3.0** @`0xA6FE6E`（写 slot[76]）。

### 3.2 风压高度变化系数 μz（四类）

| 场地 | 块地址 | 常量 |
|---|---|---|
| A | `0xA7046B` | `dbl_401F08`=1.284 / 指数 0.24=`dbl_401F00` |
| B | `0xA70A5A` | `dbl_401F30`=1.000 / 指数 0.30=`dbl_401EE8` |
| C | `0xA71045` | `dbl_401ED0`=0.544 / 指数 0.44=`dbl_401EC8` |
| D | `0xA71634` | `dbl_401EB8`=0.262 / 指数 0.60=`dbl_401EB0` |

均**不含** `VarAdd`（βgz 有 `+1`，μz 没有）—— 这是从指令序列上区分两者的硬判据。
结果写 **slot[10]**（实测 slot[10]=2.2313 与 `1.284×10^0.24` 逐位一致）。

截断/梯度高度常量：300=`dbl_401F38`、100=`dbl_401F48`、20=`dbl_401F50`、1000=`dbl_401F58`、5=`dbl_401F78`。

### 3.3 ★ β 下限（GB55001-2021 4.6.5-2）

| 地址 | 内容 |
|---|---|
| `0xA7178B` | `dbl_401EA8` = **0.7** |
| `0xA717DC` | `dbl_401EA0` = **0.5** |
| `0xA71847` | `__vbaVarPow(slot[10], 0.5)` → √μz |
| `0xA71854` 起 | `VarDiv(0.7, √μz)` → `VarAdd(1, …)` → `VarR8Var` |
| 之后 | `call 0xA582CD` = **max(a, b)**（其伪代码为 `if (a2 <= a3) v5 = a3; else v5 = a2;`） |

⇒ `β = max(βgz, 1 + 0.7/√μz)` 是**原程序自己的实现**，不是复刻按数值拟合出来的。
A 类因 `0.7/√1.284 = 0.6178 > 2×2.5×0.12 = 0.6000` 被下限接管，这就是曾经那个「0.93% 残差」的全部来源。

`0xA71819` 块的实际调用序列（逐条可查）：

```
__vbaVarPow(slot[[ebp-2E0h]], 0.5)  → √μz
__vbaVarDiv(0.7, √μz)
__vbaVarAdd(1, …)
__vbaR8Var(…)
__vbaR8Var(slot[[ebp-2DCh]])        → βgz
call sub_A582CD                     → max(两者)
```

结果先落 `[ebp-194h]`，之后另行落槽；**β 最终写哪个槽尚未确证**（两个槽索引变量 `[ebp-2D8h]`/`[ebp-2DCh]` 分别指向不同槽，
需要数据流或实测确认，见 §7 待办）。

## 4. 一条重要否定结论

**本函数里没有 `wk = w0·β·μz·(μs1·ψ + μsi)` 的最终乘积。**

- 全函数 `__vbaVarMul` 只有 **14 个块**，全部已定位：4 个 βgz + 4 个 μz + 5 个内部系数 + 1 个前置（`0xA6387B`）。
- `fmul` **0 次**，排除 x87 原生路径。
- `0xA73C00–0xA74200` 的 42 个块里没有任何乘法。

⇒ 本巨型函数的职责是「**把各分量算出来写进 VARIANT 槽**」，最终相乘发生在**调用方或另一个函数**。
下一步要做全局相乘，必须先定位调用者（对 `0xA62C07` 取 xref），或直接在 V31 里对 `slot[8]`（β）、`slot[10]`（μz）做写后读追踪。

## 6. 怎么用这份地图

```bat

python local-data\recon\ida_map.py build

:: 按语义找块
python local-data\recon\ida_map.py grep 取0.8μ

python local-data\recon\ida_blocks.py --start 0xA62C07 --end 0xA86FEE --max-blocks 4000 ^
  --out local-data\recon\ida_out\windload_full_A62C07_A86FEE.txt
```
