# 哪些参数必须保持「可配置」——V31 逐控件实机对照

> 起因（用户纠正）：不能把第一页传下来的值在后续屏里**写死/锁成只读**。
> 第一页给的是**初值**，V31 里很多参数在后续屏**仍然可改**（横梁屏的玻璃厚度就是典型）。
>
> 判据只有一个：**该控件在 V31 实机里 `en=1` 还是 `en=0`**（`dump_*.txt` 直读，不看帮助文档）。
> 数据源：`local-data/recon/v31runs/dump_*_client.txt` / `dump_*_after.txt` / `beam_glass_probe.txt`。

## 一、原则：继承 ≠ 锁死

| 情形 | 正确处理 | 错误做法 |
|---|---|---|
| 第一页算出 wk，下游**只读显示** | 显示值，但控件本身仍按 V31 的 en 处理 | 把整块区域做成灰底不可交互的 Border |
| 第一页填分格尺寸，下游**可改** | 初值取第一页，用户可改回写会话 | 写死常量、或 `IsEnabled="False"` |
| 下游屏自己的几何/材料参数 | 完全由本屏控件控制 | 从第一页硬塞，或反过来锁死 |
| V31 本来就 `en=0` 的控件 | 保持禁用 + 说明原因 | 为了"好看"擅自解锁 |

## 三、★ 案例：横梁屏「玻璃厚度」为什么必须可配置

**V31 实机**：`ComboBox 上片厚度 (54,59) en=1`，10 档候选
`['3.2','4','5','6','8','10','12','15','19','20']`，默认 `sel=3 → 6`。

**扰动实验**（`local-data/recon/beam_glass_probe.py` → `v31runs/beam_glass_probe.txt`）：
把上片从 6 依次换成其余 9 档，每次点两次「预演」取输出全文对比 ⇒

```
--- 上片 '6 ' → '3.2'：输出完全不变（848 字 vs 基线 848）
--- 上片 '6 ' → '4 '：输出完全不变
--- 上片 '6 ' → '5 '：输出完全不变
--- 上片 '6 ' → '8 '：输出完全不变
--- 上片 '6 ' → '10'：输出完全不变
--- 上片 '6 ' → '12'：输出完全不变
--- 上片 '6 ' → '15'：输出完全不变
--- 上片 '6 ' → '19'：输出完全不变
--- 上片 '6 ' → '20'：输出完全不变
```

**结论（两条都要记住）**：
1. **可配置**：V31 允许改，所以复刻版必须允许改 —— 旧版把整块做成灰 Border 显示 `"—"` 是错的。
2. **不参与计算**：改了 9/9 都不影响横梁输出。横梁自重 `g` 由**第一页的玻璃构型**决定
   （单片 300 / 中空夹层 550 N/m²），与单片厚度无关。
   ⇒ 不能因为它不参与计算就锁死，也不能假装它会影响结果。

复刻实现：
- `BeamCalcViewModel.GlassThicknessList`（10 档，文本与 V31 候选一致）；另暴露
  `GlassThicknessItems` 属性供 XAML 绑定（**Avalonia 只能绑属性，静态字段绑不上** ——
  第一版就因此两个下拉显示为空，已修）
- `BeamCalcViewModel.GlassOuterIndex` / `GlassInnerIndex`，构造时由第一页
  `GlassOuterThicknessMm` / `GlassInnerThicknessMm` 同步（`SyncGlassLayers`）
- `OnGlassOuterIndexChanged` **不**触发"输入已变化请重新预演"（它不影响结果，误报会误导）

### 3.1 ★「下片」的可用性由第一页玻璃构型决定（用户口径，已实装）

| 第一页构型 | 片数 | 下片厚度 |
|---|---|---|
| 单片（`GlassMono`） | 1 | **禁用**（V31 实测 en=0） |
| 中空 / 夹层 / 中空夹层 / 双中空 / 双夹层 | 2（或 4） | **启用**，可独立改 |

实现：`BeamCalcViewModel.GlassInnerEnabled => !Session.GlassMono`，
并监听 `GlassMono/GlassInsulated/GlassLaminated/GlassInsulLam/GlassDoubleInsul/GlassDoubleLam`
六个构型位与两个厚度位，任一变化就 `SyncGlassLayers()` 重新同步。
禁用时 `GlassInnerDisabledReason` 给出"第一页玻璃构型为「单片」…"的 ToolTip。

守卫用例：`DesktopTests/FirstPageFlowTests.玻璃厚度可配置性跟随第一页构型`
（单片 false / 中空 true / 夹层 true）与 `玻璃厚度初值取自第一页`（8 / 10 同步）。
