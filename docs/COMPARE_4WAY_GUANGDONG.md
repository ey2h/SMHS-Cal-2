## 三、V35 代码级证据（可逐条复核）

### 3.1 g 的门槛与二选一（`0xA6FDD9` → `0xA6FE6E` / `0xA6FF5E`）

```
0xA6FDD9  push [ebp-0F8h]            ; 取某控件文本（基本风压）
0xA6FDDF  call __vbaR8Str            ; 字符串 → double
0xA6FDE4  fcomp dbl_401F20           ; 与 500 比（0x401F20 = 500.0，单位 Pa）
0xA6FDED  jb  loc_A6FDFB             ; < 500 → 标志 = 0
0xA6FDEF  (>=500) [a1-2224] = 1      ; ← -2224 = -0x8B0
0xA6FDFB  (<500)  [a1-2224] = 0

0xA6FE02  cmp word [ebp-2C8h],0      ; -712 = 是否广东
          setnz al / neg eax
          mov ecx,[ebp-8B0h] / neg ecx   ; -2224 = w0>=500
          and ax,cx                        ; ★ 广东 AND w0>=500
          test eax,eax
0xA6FE68  jz  loc_A6FF23             ; 假 → 国标支
0xA6FE6E  fld [0x401F68]  (=3.0)     ; 真 → 广东支
0xA6FF5E  (国标支) ...
0xA6FF7A  fld [0x401F18]  (=2.5)
```

两支各自把值写进槽 **idx 76**（`*(DWORD*)(a1-728) = 76` + `sub_419CE8(16*76 + dword_220D178, ...)`，
`dword_220D178` 是 V35 的 VARIANT 槽数组基址），并各带一段计算书文案：

- 广东支：`unk_4DADF8` = 「，按广东荷载规范取3.0(注：本计算采用广东荷载规范，但因为广东荷载规范与国标GB50009-2012公式完全一样，只是个别系数不同，为减少与国标冲突，计算中公式条目仍按GB500…)」
- 国标支：`unk_4D4E00`

> 与 V31 交叉印证：V31 停在上海+广东低矮时 `slot[76] = 3`（见 §4.3），停在全国档时该槽不存在（=0）。
> **同一槽号 76** 说明 V31 与 V35 是同一份源码的两个版本。

## 五、复刻对齐（本轮修的三处）

### 5.1 修①：g 的 w0≥0.5 门槛（此前缺失）

`CalcSession.PeakFactorG` 原来只看「是否广东」，现在加门槛；w0 由 `ResolveWindStandard` 落到 `BasicWindW0`：

```csharp
public double PeakFactorG => IsGuangdongLoad && BasicWindW0 >= 0.5
    ? WindLoadEngine.PeakFactorGd : WindLoadEngine.PeakFactorGb;
```

判别案：北京 0.45 + 广东档 → 修前复刻把 g 也提到 3.0，wk 给 **1.755**（错），V31/V35 都是 **1.646**。

### 5.2 修②：qk 必须吃「已取 3 位的 wk」，且走 N/mm² × mm 的 double 路径

原实现 `round3(raw × bay)`。实测 V31 内部 wk（slot[15]）**已是 3 位取整值**，
且单位是 N/mm²，乘立柱宽（mm）后的 double 二进制尾巴**决定了 5 位边界往哪边倒**：

| 案 | slot[15] | `0.00xx × 1100` 的 double | round3 | V31 qk（由 W÷12500 反解） |
|---|---|---|---|---|
| G2 广东 100m | 0.002146 | 2.3606000000000003 | **2.361** | 2.361333 ✅ |
| G6 广东 60m | 0.001895 | 2.0844999999999999 | **2.084** | 2.084000 ✅ |
| 内压 0.6μs1 | 0.002505 | 2.7554999999999996 | **2.755** | 2.754667 ✅ |
| G1 全国 | 0.001848 | 2.0328000000000004 | 2.033 | 2.033333 ✅ |

若写成 `wk(kPa) × 1.1` 或先转 `decimal`，后两案会分别落到 2.085 / 2.756，
抗弯预选变成 26066.667 / 34450（V31 是 26050 / 34433.333）。

```csharp
double wk3 = WindLoadEngine.RoundLikeV35(wkMain, 3);                     // = V31 slot[15]×1000
decimal qk0 = (decimal)Math.Round(wk3 / 1000.0 * bay, 3, MidpointRounding.ToEven);
decimal qk  = WindLoadEngine.RoundDec(qk0 * (decimal)k1 * (decimal)k2, 3);   // K 仍乘在取整之后
decimal qd  = WindLoadEngine.RoundDec(qk * (decimal)WindPartialFactor, 3);   // 仍在 decimal 域（4.1325→4.132）
```

> qk 走 double 域、qd 走 decimal 域，看起来不统一，但这是实测出来的：
> qd 的三个判别点（3.0495→3.050、4.0515→4.052、4.1325→4.132）只有 decimal+银行家舍入能同时成立，
> 而 qk 的两个判别点（2.0845→2.084、2.7555→2.755）只有在 double 域里才能保留"略小于 5"的尾巴。
