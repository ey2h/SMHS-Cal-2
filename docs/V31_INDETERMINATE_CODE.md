# 多跨铰接连续【一次超静定】梁 —— V31 代码级公式复原

> 目标函数：V31 脱壳镜像 `0xD73EEF – 0xD8EF31`（约 110 KB，栈帧 `0x112C`）。
> 取证手段：Frida 进程内插桩（非调试器）+ 直读 Form 上的 Double 数组。**零计算书、零规范推测、零拟合**。

## 一、函数与页面

| 项 | 值 |
|---|---|
| 函数边界 | `0xD73EEF – 0xD8EF31` |
| 定位方式 | 挂 `__vbaVarMul(0x413714)` 统计返回地址 → 热点全在 `0xD7Bxxx–0xD7Cxxx`，且每点 ×10（按跨数循环）→ 按 `55 8B EC` 反查函数首 |
| 页面 | 立柱页「多跨铰接连续一次超静定梁」→ **必须点「下一步」** 进 `Frame '多跨数据输入'`，再「确认数据」→「预演」 |
| 输入框 | 总跨数(102,179)、跨长A₁(102,221)、**跨长A₂(102,258)**、跨长L₁(102,296) |
| 输出 | 只有 4 个量：抗弯强度 / 抗剪强度 / 折算强度 / 挠度（+ 各自设计值与限值） |

**注意**：静定版只有 3 个输入框，超静定多一个 `(102,258)`。不填它默认 600，会导致结果对不上。

## 二、六个运行期数组（`Form + 偏移`，元素为 Double，下标从 1 开始）

| 偏移 | 内容 | 实测（A₁=800 / L=2700 / n=10） |
|---|---|---|
| `+0x4C` | **A₁**（跨长A₁ 输入） | `0, 800, 800, …` |
| `+0x12C` | **A₂**（跨长A₂ 输入，默认 600） | `0, 600, 600, …` |
| `+0x110` | **L**（跨长L₁ 输入） | `0, 2700, 2700, …` |
| `+0xD8` | 支座弯矩 **−M** | `0, −667200, −2456000, …` |
| `+0xF4` | 数组弯矩 **M'**（负值，迭代收敛） | `0, −1561460, −1534360, −1534240, …` |
| `+0xA0` | 铰接力 **P** | `0, 2236, 2246, …` |
| `+0x84` | P 的 1-移位副本（`arr84[i] = arrA0[i−1]`，仅打印用） | `0, 0, 2236, 2246, …` |

> `A₁ ≠ A₂` 是**实机现象**，不是笔误：把 A₁ 填 400、A₂ 填 700，两个数组分别读出 400 / 700。

## 三、公式（全部带地址）

### 3.1 迭代（3 步收敛，n 无关）

```
M   = qd·A₁²/2 + P·A₁                                 0xD7BF3D → 0xD7BF51 → 0xD7BF5E
T   = (L³ + A₂³)·6·qd/24                              0xD7C165(L³) 0xD7C192(A₂³)
                                                      0xD7C369(×6·qd) 0xD7C391(÷24)
M'  = −(T − M·A₂/6) / 2 / (A₂ + L)                    0xD7C3C6(÷2) 0xD7C3DA(÷(A₂+L))
P   = rtcRound(qd·L/2 + M'/L, 0)   ★ 0 位整数取整       0xD7C95C(Add) 0xD7C95D(rtcRound)
```

### 3.2 控制截面（两支路）

```
if max|M'| > max M  → 跨中控制（σ 在 0xD816EC，|M'| 经 fabs ÷ slot[32]='1.00'）
else                 → 支座控制（σ 在 0xD7E8DD，M/W）
σ = M_design / W
```

### 3.3 剪力 —— 每支路都是**两候选取大**（V31 是 `If a > b Then a Else b` 的表达式）

```
q1 = qd·A₁/2 + |(−M) − M'| / A₂                       0xD7DA21 fld −M → fsub M' → fabs → fdiv A₂
支座控制：V = max(q1, P + qd·A₁)                       0xD7F6A8 处实测两候选 −3577.8 / 785.0
跨中控制：V = max(q1, |qd·L/2 + M'/L|)                 0xD8252F 处实测两候选 3267.33 / −2466.53
τ   = Sx·V/(I·t)                                      0xD7FAD4 → 0xD7FAF3 → 0xD7FB12
σeq = √(σ² + 3τ²)                                     0xD802F4 / 0xD80316 (Pow2) 0xD80344 (Pow0.5)
```

（M、M' 取**控制截面**那一跨的值：跨中控制取 argmax|M'|，支座控制取 argmax M。）

### 3.4 挠度

```
num1 = 5·qk·L⁴/384 + M'·L²/16                          0xD87752 / 0xD87608(÷16 = dbl_402F88)
num2 = P·A₁³/3 − A₁⁴·qk/8 + A₂⁴·qk/24 − M·A₂/3 + M'·A₂/6    ★ A₁ / A₂ 混用
df   = rtcRound(num1/EI, 3) − rtcRound(num2/EI, 3)/2   0xD877CE / 0xD873F8
lim  = min((A₁+L)/180, 20)
```

**`num2` 的 A₁/A₂ 混用是实机铁证**（A₁=800 / A₂=600 / L=2700 的实参）：

| 实参 | 值 | 含义 |
|---|---|---|
| `409 600 000 000 × qk / 8` | = 800⁴ | **A₁⁴** |
| `383 488 000 000` | = P·800³/3 | **P·A₁³/3** |
| `129 600 000 000 × qk / 24` | = 600⁴ | **A₂⁴** |
| `−492 960 000` | = M·600/3 | **M·A₂/3** |
| `−153 422 300` | = M'·600/6 | **M'·A₂/6** |

A₁=A₂ 时两者相等，所以只有拿 A₁≠A₂ 的样本才能分辨出来。

### 3.5 关键细节（每条都有实机反证）

1. **P 的取整位数是 0**（整数）：2236 / 2246 / 2325 …
2. **折算应力 √(σ²+3τ²)**：L=2800 时 √(σ²+τ²)=83.055，V31 打印 84.059，加 3τ² 才对
3. **挠度两分项各取 3 位再相减**：`Add(4.724, −1.224)=3.5`，全精度相加差 5e-4 量级
4. **`M'` 为负**，num2 末项是「加 M'·A₂/6」（代码 `0xD87390` 直接 Add 负值）
5. 常量：`dbl_4019A8=3`、`403C50=4`、`4018F8=2`、`4027F8=6`、`402F88=16`、`4019E0=20`

## 五、仍未闭合 / 待确认

1. **分支判据**用 `max|M'| > max M` 推断（6 组数值全吻合），但没在代码里找到显式的比较指令；
   现有证据是两支路各有一套 σ/τ/df 打印块（`0xD7E8xx` / `0xD816xx`），由 `If` 择一。
2. V 的两候选在两条支路里**不是同一个表达式**（支座：`P+qd·A₁`；跨中：`|qd·L/2+M'/L|`），
   这两个式子分别与各自支路的实测候选值吻合，但为什么这样写（物理意义）尚未定位。
3. 悬挑 A₁/A₂ 在界面上的确切标签文字未取（只知道是两个独立输入框）。

## 七、踩坑

- **`v31_py.py` 的 `multi` 必须在「上一步」回退后再填**：已经停在多跨页时再点「下一步」会翻到下一页。
- 预演**必须点两次**才稳定刷新（单次偶发读到上一组残留）。
- Frida 客户端被 `timeout` 强杀会**连带杀掉 V31**（实测死了 5 次）⇒ 脚本自带循环与正常 unload，别用 `timeout` 兜底。
- `0xD7E8xx` 只服务于 **支座控制分支**；跨中控制分支的 σ 在 `0xD816EC`、τ 在 `0xD82999`
  —— 一开始在 `0xD7E8xx` 找不到就以为「没执行」，其实是走另一条分支。
