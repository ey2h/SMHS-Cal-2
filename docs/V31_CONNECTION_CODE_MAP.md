## 4. 已闭合的算式（代码 + 实机双证）

### 4.1 抗承压能力 = 螺栓数 × 公称直径 × 被承压板厚 × 承压强度设计值

符号执行为四连乘（`__vbaVarMul` 链），以 `A95CE5 → A95D70` 为例：

```
A95CE5  push &slot[25] ; A95CF7 push &slot[29] ; A95D09..D10 __vbaVarMul  → slot[25]*slot[29]
A95D16  push &slot[26] ; A95D2F __vbaVarMul                               → ×slot[26]
A95D35  push &slot[28] ; A95D4E __vbaVarMul                               → ×slot[28]
A95D55  __vbaVarMove → [-B4h] ; A95D70 rtcRound ; A95D75 slot[30]=结果
```

| 输出 | 代码算式 | 代入 | 实机 | 扰动复核 |
|---|---|---|---|---|
| slot30 横梁壁 | slot[25]×slot[29]×slot[26]×slot[28] | 2×6×3×185 | **6660** ✓ | 改角码厚度不变 ✓ |
| slot45 立柱壁 | slot[42]×slot[44]×slot[43]×slot[77] | 2×6×3×185 | **6660** ✓ | 同上 ✓ |
| slot50 角码壁 | slot[42]×slot[44]×slot[10]×slot[49] | 2×6×5×185 | **11100** ✓ | 角码厚 5→7 ⇒ **15540** = 2×6×7×185 ✓ |
| slot68 立柱壁(主体) | slot[84]×slot[66]×slot[67]×slot[43]×slot[81] | 2×2×12×3×185 | **26640** ✓ | 改角码壁厚不变 ✓ |
| slot73 角码壁(主体) | slot[85]×slot[66]×slot[67]×slot[7]×slot[72] | 2×2×12×6×305 | **87840** ✓ | 单侧角码 ⇒ **43920** = 1×2×12×6×305 ✓；角码壁厚 6→8 ⇒ **117120** = 2×2×12×8×305 ✓ |

槽语义（由 §5 扰动实验定，非推测）：

| 槽 | 值 | 语义 | 证据 |
|---|---|---|---|
| 7 | 6→8 | 立柱与主体 角码壁厚 | 改 UI `(104,387)=8` 后 slot7 随之变 |
| 10 | 5→7 | 横框与立柱 角码厚度 | 改 UI `(230,150)=7` 后 slot10 随之变，且 slot50 11100→15540 |
| 25 / 42 | 2 | 螺栓数（横框 / 竖框） | 代入即中 |
| 26 / 43 | 3 | 被承压板厚（横梁壁 / 立柱壁） | 不随角码厚度变，代入即中 |
| 29 / 44 | 6 | 螺栓公称直径 M6 | 与 slot22=5.061833（M6 有效直径）同组 |
| 67 | 12 | 螺栓公称直径 M12 | slot63=10.35821 是 M12 有效直径 |
| 28 / 49 / 77 / 81 | 185 | 铝 6063-T5 承压强度设计值 | 见 §5 实验 |
| 72 | 305 | 钢 Q235 承压强度设计值 | 见 §5 实验 |
| 84 / 66 / 85 | 2 / 2 / 2→1 | 主体螺栓组系数（含单侧角码开关） | 勾选单侧角码后 slot85 2→1 |

|---|---|---|---|
| slot24 | slot[19]/slot[23] | 633.889/3821.544 = 0.1658724850… | **0.166** ✓ |
| slot41 | slot[36]/slot[40] | 699.598/3821.544 = 0.1830668441… | **0.183** ✓ |
| slot65 | slot[60]/slot[64] | 7304.379/32005.357 = 0.2282236376… | **0.228** ✓ |

### 4.3 受力 = 平方和开方

```
A9CA08 __vbaVarPow(底=&[-9Ch], 指数=0.5)  → 7304.378550054755
```

`699.598 = √489437.184421`、`7304.379 = √53353946.0025`，两处均为 `^(0.5)`。

## 5. 扰动实验（输入→输出归因，不涉及任何数值拟合）

脚本：`connect_frida.py --stack 1 --set/--click/--combo`，改一个输入重跑一次，比对槽数组差分。

| 实验 | 改动 | 变化（槽差 + 定稿点出参差） |
|---|---|---|
| E1 | 横框角码厚度 5→7；主体角码壁厚 6→8 | slot10 5→7、slot7 6→8；**slot50 11100→15540**（=2×6×7×185）、**slot73 87840→117120**（=2×2×12×8×305） |
| E2 | 勾选「单侧角码」 | 仅 slot85 2→1；**slot73 87840→43920**（=1×2×12×6×305） |
| E3 | 主体螺栓行下拉改选 | 无变化（`CB_SETCURSEL` 对该下拉列表不生效，需真实展开后再测） |

E1/E2 是决定性的：两组独立扰动分别只改动一个乘积因子，输出按**同一算式**精确变化
（15540 / 117120 / 43920 全部逐位吻合），因此 §4.1 五条承压算式**无需再猜**。

> 记一次判据踩坑：定稿点的槽快照取在 rtcRound **入口**，发生在写槽之前，
> 所以本屏最后一个定稿点写的 slot73 在任何快照里都是空——早前据此误判「87840 与算式矛盾」。
> 已加 `rpc.exports.dumpSlots` 在预演结束后主动补读终态槽（`finalSlots` 字段），
> 现 25 个输出槽在终态快照里**全部**命中，与计算书原文逐位一致。

## 6. 未闭合项（明确登记，未凑数）

1. **单栓承载力 3821.544 / 32005.357 的上游算式未定**：两值均由 `X/4` 得到
   （`X` 分别是 15286.176670645778、128021.4281869721），4 为 Variant 整数字面量；
   `X` 的物理构成未定位（`190 × 20.1134` 不匹配任何标准有效截面面积）。不做拟合。
2. slot14/17/33/53/54/55/56/57/58/59 共 10 个中间量（583.069、72.6、227.7、4240.5、6360.75、
   1056、1478.4、7099.95、1320、1716）物理含义未定位；数值已实机确认，算式上游未闭合。
3. 实际受力 633.889 / 699.598 / 7304.379 的**输入构成**未闭合：699.598=√489437.184421、
   7304.379=√53353946.0025 已确认是「平方和再开 0.5 次方」，但被平方的是哪几个分量未定位。
4. 立柱页受本次「Var 操作数方向」修复影响：旧 `v31_roundpoint_expr.tsv` 的除法/幂结果方向是反的，
   已修正切片器，但立柱 93 条公式表**尚未按新切片器重跑核对**。
5. 主体螺栓规格下拉（`(286,378)`）无法用 `CB_SETCURSEL` 更改，螺栓行切换的归因实验未完成。
