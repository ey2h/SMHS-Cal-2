## 二、V31 侧的采集方式（可复现）

`local-data/recon/v31_attach.ps1` 新增 `basicsweep` 动作，每案固定流程：

```
第一页全量复位（22 项） → 应用本案差异 → 回读实际状态 → 点"下一步"
→ 立柱屏复位（模型/材质/L/a/挠度规范/4 个复选框）→ 点"预演"
→ 读结果区原文 → 点"上一步"
```

三处必须的死守（本轮踩出来的）：

1. **一律走 `FindByRelStrict`**（只认可见控件）。立柱屏同时存在构件式 `Frame(15,33)` 与单元式 `Frame(9,28)`，
   两套子控件坐标会撞；`FindByRel` 末尾有"找不到可见的就回退到不可见"，会点到隐藏那一套
   （实测因此拿到单元式的 `15.261 / 3.299`，误以为构件式复位生效）。
2. **写 TextBox 必须先写剪贴板 + 回读校验**。`SetField` 只发 `EM_SETSEL + WM_PASTE`，不设剪贴板。
3. **每案立即追加落盘**。长任务随时可能被父进程杀掉，攒到最后一次性写会全丢（本轮丢过一次 37 案）。

## 四、本轮挖出的五条新事实

### 4.1 墙角边区 μs1 = **1.4**（不是 2.0，也不是 1.8）

V31 实测 B08（自动「墙角边区」）与 B09（人工给定 1.4）**六个量逐位相同**。
反解：`μs合 = 2.455/(0.55×1.4956×1.9953) = 1.496 = 1.4×0.9258 + 0.2`。
→ 墙角边区 μs1 = **1.4**。复刻已按 1.4 实现且 B08 逐位通过。

### 4.2 立柱从属宽 = **(左分格 + 右分格) / 2**

V31 槽数组实测（B38/B39）：

| 第一页输入 | slot[42] 从属宽 | slot[44] A | slot[47] μs合 | wk |
|---|---|---|---|---|
| 1350 | **1.225** | 3.675 | 1.119 | 1.837 |
| 1500 | **1.300** | 3.9 | 1.116 | 1.832 |

`(1350+1100)/2 = 1225`、`(1500+1100)/2 = 1300`（1100 是另一格的默认值）。
→ 立柱承受左右各半个分格的荷载，**从属宽是两格平均，不是输入值本身**。
复刻的 `BayColLeft/BayColRight + SyncBayWidth()` 模型本来就是对的，是我的对照 case 直接改了合成值。

### 4.3 「其它情况(人工给定)」**没有输入框**，落回 0.2

V31 B14（选中该档）六个量与 B01 基准**逐位相同**、`slot[47] = 1.126`（= 封闭式的 0.2）。
界面 dump 也证实内部体型 Frame 内**只有 5 个 OptionButton，没有 TextBox**。
→ 该档在未提供数值时等价于封闭式。这一条顺带解释了历史遗留的
「内部体型『其它情况』V31 给 1.0、复刻给 1.5195」——当时是拿它和"人工给定 0"比，前提就不成立。

### 4.4 qk 的顺序：**wk 先含 K1/K2 并取整，再 × bay**

三个判别案（V31 实测 → 反推 qk → 反推 qd → W预）：

## 十一、2026-10-25 补正：ψ(A) 分母查到代码，改为 1.4

### 11.1 结论（代码级 + 实测双证）

`ψ(A) = 1 − 0.2·round3(lg A) / **1.4**` —— **不是**规范写法的 `lg(25)=1.39794`。

**代码证据**：V31 中 `slot[46]`（= μs1·ψ）**唯一**写入点 `0x00E2CE3E`，其计算链：

```asm
; 读三个控件串 → double
18D1E?? ...
00E2CCC3  call  __vbaR8Str            ; X2
00E2CCE0  fmul  ds:dbl_401920         ; × 0.8
00E2CCFE  fsubr qword ptr [ebp-408h]  ; 0.8·X2 − X3  （= −0.2·μs1）
00E2CD1E  mov   [ebp-1B8h], 2Dh       ; 槽号 45 = lg A
00E2CD45  fld   ds:dbl_4017F8         ; ★ 该地址的值 = 1.4（全镜像唯一一处 1.4）
00E2CD84  call  __vbaVarMul           ; × slot[45]
00E2CD98  call  __vbaVarDiv           ; ÷ 1.4
00E2CDA5  call  __vbaVarAdd           ; + μs1
00E2CDB2  call  rtcRound              ; 3 位
00E2CE3E  → slot[46]
```

**实测证据**：新增 `psidisc` 动作，用 6 个「左分格」值（外部体型人工 1.0，μs1=1.0 时 slot[46]=round3(ψ)）：

| 左分格 | A | lg A | 实测 ψ | `lg25` 式 | `1.4` 式 | 判别 |
|---|---|---|---|---|---|---|
| 1100 | 3.300 | 0.519 | 0.926 | 0.926 | 0.926 | — |
| 1300 | 3.600 | 0.556 | **0.921** | 0.920 | **0.921** | ★ |
| 610 | 2.565 | 0.409 | **0.942** | 0.941 | **0.942** | ★ |
| 2210 | 4.965 | 0.696 | **0.901** | 0.900 | **0.901** | ★ |
| 1460 | 3.840 | 0.584 | **0.917** | 0.916 | **0.917** | ★ |
| 910 | 3.015 | 0.479 | **0.932** | 0.931 | **0.932** | ★ |

**6/6 全落 1.4 分支**，5 个判别点全部排除 `lg(25)`。
