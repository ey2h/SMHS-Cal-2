## 一、怎么进到横梁页（实机链路）

```
主界面菜单「玻璃幕墙 > 全隐框」          → 窗体「全隐框玻璃幕墙计算-基本参数输入」(0x212CD6)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-立柱计算」  (0x202D42)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-横梁计算」  (0x202EF2)
```

三个窗体**同时存在**，靠 `IsWindowVisible` 区分当前页；`FindForm` 必须按标题找，
不能只按 pid（同一进程里有 72 个 `ThunderRT6FormDC`）。

菜单命令：`PostMessage(mdiForm, WM_COMMAND, id, 0)`，「玻璃幕墙 > 全隐框」的 id = **2**。
主窗体是 `ThunderRT6MDIForm`（标题「汇宝幕墙门窗结构计算软件V31.0 (免费版)」）。

### 已确认的两个细节

1. **抵抗矩取 min**：选用值显示 3662 = `min(Wx1=4.1, Wx2=3.662)` cm³；

## 四、函数定位（2026-10-25 已定位）

| 项 | 结果 |

### 已用实参 + 内存直读钉住的环节

```
0x8AEB0F  1100 × 0.001285 = 1.4135   → round3 = 1.414   (qk = bay × wk/1000，与立柱同款)
0x8AEBF4  1.414 × 1.5     = 2.121                        (qd)
0x8AED5D  0.16 × 5        = 0.8                          (自重类，立柱页同款)
0x8AED7C  0.0003 × 0.8    = 0.00024
0x8AEE80  1100 × 0.00024  = 0.264                        (风荷载线荷载)
M = 0.538 × 1100² / 8 = 81372.5   ← 与 0x8AF70F 实读精确相等
预选 Wx = 81372.5 / 90 = 904.1388889 → 904.139
```

**全局 double 变量区（`mread.py` 直读进程内存，mm 制）**：

| 地址 | 值 | 含义（推定） |
|---|---|---|
| `0x1C913B0` | 1100 | 分格宽（横梁跨度） |
| `0x1C913B8` | 1100 | 另一个尺寸（受荷宽？待确认） |
| `0x1C913C0` | **1380** | 上下分格高合计或横梁实际跨度，用法待确认 |
| `0x1C913D8` | **0.16** | 自重面荷载 kPa（`0x8AEC74 fld [0x1C913D8]` 直接引用） |

## 四之二、**第一页联动实测**（用户提示项，已验证）

### 玻璃配置（第一页 `Frame 玻璃配置 (648,193)`）

6 个单选：`单片(681,208)` / `中空(681,231)` / `夹层(681,255)` / `中空+夹层(773,208)` / `双中空(773,231)` / `双夹层-中空(773,255)`。

横梁页 `Frame 玻璃配置 (12,26)` 是两个厚度下拉（3.2/4/5/6/8/10/12/15/19/20），
默认 **sel=3 → 6mm**，两层的选项相同、随第一页玻璃类型启用情况联动。

实测对比（同一型材 40/60、其余不动，仅把第一页改成「中空+夹层」）：

| 量 | 单片（默认） | 中空+夹层 | 变化 |
|---|---|---|---|
| 预选 Wx | 904.139 | **1658.708** | +83% |
| 预选 Wy | 2560.046 | **2756.111** | +7.7% |
| 预选 Ix | 25624.721 | **46978.655** | +83% |
| 预选 Iy | 39930.726 | **40330.033** | +1.0% |
| 竖向挠度 | 0.974 | **1.785** | +83% |
| 水平挠度 | 1.973 | 1.993 | +1.0% |
| 抗弯 | 62.201 | **83.807** | +35% |
| 抗剪 tx / ty | 6.006 / 1.531 | **6.466 / 2.806** | +8% / +83% |
| 允许值 | 4.4 / 6.111 | 4.4 / 6.111 | 不变 |

**结论**：玻璃配置通过**自重**进入横梁竖向荷载，竖向一组量整体 +83%；
水平方向几乎不变（只随 wk 的 1% 级波动）。所以横梁取证**必须固定第一页的玻璃配置**，
否则同一段代码会算出两组数。

## 七、环境注意（本轮踩到的）

- Bash 沙箱里 `tasklist` 看不到 V31 → `find_pid` 改用 `EnumWindows` + 类名 `ThunderRT6*` + 标题含「汇宝」。
- PowerShell 工具禁止 `Add-Type`，纯 ctypes 的 python 脚本可以直接跑；但**内联 `-c` 脚本含 `%` 会被安全策略拦**，必须写成文件。
- V31 需要点过「试用软件」才会常驻，否则超时退出；用 `v31_keep.ps1`（需 `Set-ExecutionPolicy -Scope Process Bypass`）。
- Frida 附加后如果脚本被强杀，会连带杀掉 V31，重新走「启动 → 试用 → 菜单 → 第一页 → 下一步」要 2-3 分钟。
