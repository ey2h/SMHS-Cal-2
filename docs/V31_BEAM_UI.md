## 一、怎么进到横梁页（实机链路）

```
主界面菜单「玻璃幕墙 > 全隐框」          → 窗体「全隐框玻璃幕墙计算-基本参数输入」(0x212CD6)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-立柱计算」  (0x202D42)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-横梁计算」  (0x202EF2)
```

三个窗体**同时存在**，靠 `IsWindowVisible` 区分当前页；`FindForm` 必须按标题找，
不能只按 pid（同一进程里有 72 个 `ThunderRT6FormDC`）。

菜单命令：`PostMessage(mdiForm, WM_COMMAND, id, 0)`，「玻璃幕墙 > 全隐框」的 id = **2**。
主窗体是 `ThunderRT6MDIForm`（标题「汇宝幕墙门窗结构计算软件V31.0 (免费版)」）。

### 预选 Wx / Wy 的完整算式链（**已闭合两条链**，槽数组 + 实参双证）

**槽数组必须二次解引用**：`[0x1C911A0]` 里存的是数组指针（`mov ecx, dword ptr [0x1c911a0]`），
实测指向堆地址 `0x2067A90`。VARIANT 16B/槽，vt 在 +0、double 在 +8。

**横梁槽编号（实测）**：

| 槽 | 含义 | 单片 | 中空+夹层 |
|---|---|---|---|
| `[2]` | 分格宽 B | 1100 | 1100 |
| `[3]` | 分格高 H | 1380 | 1380 |
| `[6]` | wk（N/mm²） | 0.001285 | 0.001285 |
| `[7]` | qk | 1.414 | 1.414 |
| `[8]` | qd | 2.121 | 2.121 |
| `[9]` | 自重比例常量 | 0.16 | 0.16 |
| `[10]` | **自重面荷载 g（N/mm²）** | **0.0003** | **0.00055** |
| `[11]` | g × 0.8 | 0.00024 | 0.00044 |
| `[12]` | B × [11] | 0.264 | 0.484 |
| `[13]` | round3([12]×1.4) | 0.37 | 0.678 |
| `[14]` | qd + [13]/2 | 2.306 | 2.46 |
| `[16]` | M_y = [14]·B²/12 | 232521.667 | 248050 |
| `[18]` | 抗弯设计值 f | 90 | 90 |
| `[19]` | H × g | 0.414 | 0.759 |
| `[20]` | round3([19]×1.3) | 0.538 | 0.987 |
| `[21]` | M_x = [20]·B²/8 | 81372.5 | 149283.75 |
| `[22]` | **预选 Wx = [21]/f** | **904.139** | **1658.708** |
| `[23]` | **预选 Wy = [16]/f** | **2583.574** | **2756.111** |
| `[24]` | 弹性模量 E | 70000 | 70000 |

**公式**：

```
g    = 参数库「幕墙自重参数」→ 计算横梁时自重 / 1e6      # N/mm²
B    = 分格宽 (第一页)                        H = 分格高 (第一页)

# 竖向（绕 x 轴，简支 /8，用 Wx）
q_x  = round3( H × g × 1.3 )
M_x  = q_x × B² / 8
Wx预选 = M_x / f

# 水平向（绕 y 轴，固端 /12，用 Wy）
q_y  = qd + round3( B × g×0.8 × 1.4 ) / 2
M_y  = q_y × B² / 12
Wy预选 = M_y / f
```

**自重 g 的来源就是参数库表**（这正是「材质/自重从参数库拿」的落点）：
`幕墙自重参数.csv` 的「计算横梁时自重」列 —— 单片 300、中空或夹层 400、中空夹层或双中空 **550**、
双夹层中空 650（N/m²）。切成「中空+夹层」后槽 `[10]` 实测从 0.0003 变 0.00055，与表第 3 行 550 完全对应。

实参出处：`0x8AEF65`(×1.4) `0x8AF088`(×0.5) `0x8AF095`(+qd) `0x8AF23B`(×B²) `0x8AF24F`(/12)
`0x8AF9BF`(/f) `0x8AF353`(H×g) `0x8AF599`(×1.3) `0x8AF6D9`(×B²) `0x8AF6ED`(/8) `0x8AF856`(/f)。

| 地址 | 运算 | 实值 |
|---|---|---|
| `0x8B55CA` | M_x / 1 | 81372.5 |
| `0x8B55E9` | M_x / Wx_min(**3662**) | **22.220780994** |

### 挠度计算：两个方向**系数不同**（实参钉死，重点）

| 方向 | 公式 | 实参链 | 结果 |
|---|---|---|---|
| **垂直向（自重）** | `df_v = 5 · (H·g) · B⁴ / (384 · E · Ix)` | `0x8B73DA` 0.414×**5**=2.07 → `0x8B740D` ×B⁴ → `0x8B7421` **/384** → `/E` → `0x8B745F` `/Ix` | **0.973567** → 0.974 |
| **水平向（风）** | `df_h = qk · B⁴ / (120 · E · Iy)` | `0x8B71FF` B⁴×**1.414** → `0x8B7213` **/120** → `/E` → `0x8B7251` `/Iy` | **1.993181** → 1.993 |

要点：
- 垂直向是**标准简支均布**（系数 5/384），荷载用 `H·g`（自重线荷载标准值，**不带** 1.3 分项）
- 水平向系数是 **1/120**（= 3.2/384，比简支小到 0.64 倍），荷载用 `qk`（风线荷载标准值，**不带** 1.5）
- 各自用自己的惯性矩：垂直 Ix=115810、水平 Iy=123650
- 允许值也各自不同：垂直 **B/250**、水平 **B/180**

四个「不一样」摆在一起（荷载 / 系数 / 惯性矩 / 限值），**任何一处混用都会错**。

### 预选 Ix / Iy：与挠度公式**同构**（把 I 解出来、用 lim 代替 df）

| 方向 | 公式 | 实参链 | 结果 |
|---|---|---|---|
| 水平 Iy | `I = qk·B⁴ / (120·E·lim_h)` | `0x8B36D1` B⁴×qk → `0x8B36E5` /120 → `/E` → `0x8B3723` /6.111 | **40330.033** |
| 垂直 Ix | `I = 5·(H·g)·B⁴ / (384·E·lim_v)` | `0x8B38AC` ×5 → `0x8B38DF` ×B⁴ → `0x8B38F3` /384 → `/E` → `0x8B3931` /4.4 | **25624.721** |

即「满足各自挠度限值所需的最小惯性矩」——刚度控制反算，与上一节两个 df 公式完全同构。
**注意**：两个方向的 lim 也必须各用各的（lim_v=4.4 / lim_h=6.111），混用直接错。

## 四之二、**第一页输入 → 横梁取值**（实机改值实验，2026-10-25 16:5x）

第一页 `Frame 龙骨间距 (11,138)` 里是 **6 个框**（不是 4 个），坐标为
`(123,169) (300,169)` / `(122,205) (300,205)` / `(122,248) (300,248)`，最后一行两个 `1350` 在构件式下 `enabled=False`。

**四个框互相独立**（实测能设成 1200 / 1500 / 1300 / 1380 四种不同值），
横梁用它们的组合：

| 横梁槽 | 取值规则 | 实验证据 |
|---|---|---|
| `[2]` = 跨度 B | **立柱左右两侧分格宽取大** = max((123,169), (122,205)) | 1200/1100→**1200**；1200/1300→**1300**；1600/1300→**1600**；900/1100→**1100**（四次都取大） |
| `[3]` = 分格高 H | **(两个高框) 的算术平均** = avg((300,169), (300,205)) | 1500/1380→**1440**（=1440，不等于任一输入，只能是平均）；1380/1380→**1380** |

改值后输出同步变化（改跨度 1100→1200）：
`预选Wx 904.139→1076`、`限值 4.4→4.8`（=1200/250）、`6.111→6.667`（=1200/180）、
`竖向挠度 0.974→1.379`，而复算 `0.538×1200²/8/90 = 1076` 精确吻合。

**结论：横梁跨度 = 立柱左右两侧分格宽的大值**（用户确认的物理含义，与四次实验一致）；**分格高 = 上下两格取平均**。
不是简单一一对应。这也解释了为什么基线看起来是「1100 / 1380」——两个宽框都是 1100、两个高框都是 1380。

> 复原：`set_basic.py 1100 1380 1100 1380`（改完必须复原，否则后续对拍全部偏离基线）。
