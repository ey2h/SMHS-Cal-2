# V31 双跨梁（立柱「双跨梁」模型）公式 — 代码级

> 目标函数：`0xD35D8C–0xD42762`（51,670B），V31 脱壳镜像 `unpacked_v31.exe`。
> 取证方式：Frida 运行期插桩（**不是**计算书、**不是**反推拟合）。两组实机参数逐位复现 **14/14 = 100%**。

## 一、怎么定位到这个函数

1. 挂 `rtcRound(0x41371A)`，取 `this.returnAddress` 统计：单跨简支的定稿点全在 `0xD2xxxx`，
   双跨梁的全在 `0xD3xxxx` ⇒ 两个模型走不同函数。
2. 按 `55 8B EC` 扫函数头：`0xD1E9E0`（单跨）、`0xD2A06E`、`0xD35D8C`、`0xD42762`。
   双跨梁命中点落在 `0xD35D8C–0xD42762` 内。
3. 再挂 `__vbaVar*` 系列读每次运算的实参 → 出参，把算式一条条还原（下表全部来自这些实测）。

| helper | 地址 | 语义（实测确认） |
|---|---|---|
| `__vbaVarDiv` | `0x413708` | args[2] ÷ args[1] |
| `__vbaVarMul` | `0x413714` | args[2] × args[1] |
| `__vbaVarPow` | `0x41370E` | args[2] ^ args[1] |
| `__vbaVarAdd` | `0x413552` / `0x4136BA` | 加法 |
| `__vbaVarSub` | `0x41377A` | args[2] − args[1] |
| `__vbaVarNeg` | `0x413804` | 取负 |
| `Atn` | `0x4137FE` | 实测 `Atn(1) = π/4` |
| `Cos` | `0x4137F2` | 实测 `cos(4.650604) = −0.0617454` |
| `Sqr` | `0x4137F8` | 实测 `Sqr(0.965775) = 0.9827385` |
| `rtcRound` | `0x41371A` | 逐次×10 → 半偶 → ÷10^d |

## 三、两跨的 ±1 规则（用户实机观察 + 两组数据印证）

```
a = L2 ; b = L1 − L2
若 a == b（等跨）则 a −= 1, b += 1
```

| 输入 | a | b | 说明 |
|---|---|---|---|
| L1=3000, L2=1500 | **1499** | **1501** | 等跨 → 自动错开（V31 界面会把 1500 显示成 1499） |
| L1=3000, L2=1200 | 1200 | 1800 | 不等跨 → 原样 |

## 四、公式链（每一步的取整位置都按实机定稿点还原）

```
Lc = max(a, b)

① 支座弯矩   M = round3( qd·(a³+b³) / 8 / L1 )
   代码 0xD3ADF3–0xD3AE5C：Pow(a,3) → Pow(b,3) → Add → ×qd → ÷8 → ÷L1 → rtcRound(3)

② 抗弯       σ = M / W                       （M 用 round3 值；W 为型材抗弯矩设计值）
   抗弯预选   W_req = M / [σ]

③ 挠度系数（全部在 round3 之后使用，未标注的步骤不取整）
   k1 = round3( 4M / (qd·Lc²) )              0xD3B3B9  → 等跨 0.499 / 不等跨 0.389
   k2 = k1 + 2                               0xD3B4C6  → 2.499
   k3 = k2 / 4                               0xD3B5E0  → 0.62475（**不取整**）
   k4 = round3( (k3² − k1/2)^1.5 )           0xD3B63B  → 0.053
   e1 = 1 − 2k1                              0xD3B8B0  → 等跨 0.002 / 不等跨 0.222
   A1 = k2³ − 12·k1·k2                       0xD3B82A/0xD3B86F
   A2 = A1 − 8·e1                            0xD3B8CA
   k5 = A2 / 64                              0xD3B8EB
   k6 = round3( k5 / k4 )                    0xD3B90A  → 0.185
   k7 = 1 − k6²                              0xD3B984
   k8 = −k6 / Sqr(k7)                        0xD3B9E9（Sqr = 0x4137F8）
   theta_raw = (180/3.14/3)·(2·Atn(1) + Atn(k8))   0xD3BA11–0xD3BA77（注意是 3.14）
   theta     = round3(theta_raw)             0xD3BA9E  → 26.46
   ang   = 3.1415926·(240 + theta)/180       0xD3BBCC（角度→弧度用 3.1415926）
   c1    = cos(ang)                          0xD3BBEB  → −0.06174543
   c2    = 2·k4^(1/3)                        0xD3BD1A/0xD3BD27
   k11   = round3( k3 + c1·c2 )              0xD3BD48  → 0.578

④ 挠度系数 kf（进 df 的最终系数，round4）
   p2 = k11² ; p3 = k11·p2                   0xD3C060 / 0xD3C0F2
   t1 = k11·round3(3k1) + e1                 0xD3C026/0xD3C033
   t2 = t1 − 2p2                             0xD3C07A（Sub）
   t3 = t2 − k1·p2                           0xD3C0CC
   k12 = p3 + t3                             0xD3C0FF
   kf  = round4( k12 · k11 )                 0xD3C10C  → 等跨 0.1303 / 不等跨 0.1692

⑤ 挠度       df = qk · kf · Lc⁴ / 24 / E / I            0xD41329–0xD413AE
   限值       lim = Lc / 180                             0xD3CB2B（显示 round3）
   惯性矩预选 I_req = qk · kf · Lc⁴ / 24 / E / round3(lim)  0xD3E8B3–0xD3E938

⑥ 抗剪（两跨分别算，取绝对值大者）
   V1 = a·qd/2 + M/a ; V2 = b·qd/2 + M/b
   V  = max(|V1|,|V2|)  → round3
   τ  = Sx · round3(V) / I / t                   0xD40A16–0xD40A54
```

> **注意**：`k3` 千万不能 round3 —— 0.62475 会被舍成 0.625，整条 k11 直接偏 0.00025
> （这就是复刻第一版差 0.24% 的原因）。

## 七、同时修正的第一页默认值（否则 wk 永远对不上）

复刻原先立柱屏 wk=1.848，V31 是 1.285。根因不在立柱页，而在**第一页默认值**：

| 项 | 复刻原值 | V31 实机（dump-basic） | 影响 |
|---|---|---|---|
| 地面类型 | B 类 | **C 类** | μz/βgz 全变 |
| 地区 | 上海（0.55） | **未选 → 参数库首行「北京」0.45** | w0 0.55→0.45 |

修正后复刻 wk = **1.285**，与 V31 完全一致（单跨简支 17675/1278255.685/24.047/111.231/8.14
也同时对上，第一页 40 案仍 280/280）。

> 铁律：所有测试都要**从第一页开始**，wk 等数据必须由第一页计算链产出后传到立柱页；
> 不允许在立柱页覆盖 wk 凑数。
