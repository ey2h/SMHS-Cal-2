### 气隙热阻 R_gap 的物理解算（关键，链已完整）

```
h_r（辐射）= 4σ·T³ / (1/ε₁ + 1/ε₂ − 1)
    ε=0.837 → 1/0.837=1.194743（×2）→ Add 2.389486 → Sub −1 = 1.389486
    T=273K → T³ = 20346417（链 `0x154a793` 的 op2 即此数）

h_gap = 2.678 + 3.321 = 5.999
R_gap = 1 / 5.999 = 0.166694 → round3 = **0.167**
```
