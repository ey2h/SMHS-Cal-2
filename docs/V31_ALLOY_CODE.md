# V31 钢铝结合立柱：代码级公式地图

> 目标：把「钢铝结合型材参数」页（`Frame '钢铝结合型材参数' (9,29)`）预演时算的 6 个输出，
> 还原到**指令 + 运行期实值**级别，并逐位复刻。
> 取证纪律：只认代码/参数库/运行期实值；静力学手册只用来**解释形式**，不作为取值依据。

## 一、怎么进到这一页（实机操作链）

1. 第一页照常算完（wk 由风荷载链产出，**不在测试里覆盖**）。
2. 立柱页「力学模型」区选 **单跨简支（受拉/受压）**——只有这两个模型下
   `CheckBox '钢铝结合' (463,93)` 才 `enabled`（选多跨/双跨时是灰的，实测）。
3. 勾「钢铝结合」→ 「立柱选材」「立柱选料」两个 Frame 整体被禁用（材料改由新页面给）。
4. 点「下一步」→ 进入「钢铝结合型材参数」页：
   - 铝框参数 `(15,41)`：材质单选 6061-T4/T6、6063-T5/T6、6063A-T5/T6 + 型材代号框 `(138,82)` + DataGrid `(18,107)`
   - 钢框参数 `(14,239)`：Q235/Q355 + `冷弯薄壁型钢` 复选 + 型材代号框 `(140,275)` + DataGrid `(17,302)`
5. 在两个 DataGrid 里各点一行 → 点「预演」。

> DataGrid 行高 18px、表头约 20px；第 6 行被 125px 高的表格裁掉，`(40, 20+18*(n-1))`
> 点不中，要用键盘 `VK_DOWN` 下移（`v31_alloy_pick.py` 的 `click_row` 只适用于 1–5 行）。

## 四、公式（复刻口径）

```
qk  = round3(wk[kPa]/1000 × bay)            # bay = 分格宽（本组 1100）
qd  = round3(qk × 1.5)
EaIa = Ea·Ia ,  EsIs = Es·Is ,  ΣEI = EaIa + EsIs
     Ea = 70000 N/mm²（不随牌号变：换 6061-T6 计算值不变）
     Es = 206000 N/mm²（Q355 也不变）

rAlS = qk × 1.05 × EaIa/ΣEI                 # 标准值份额
rAlD = qd × 1.05 × EaIa/ΣEI                 # 设计值份额
rStD = qd × EsIs/ΣEI                        # 钢份额（含 1.5，无 1.05）

M_铝 = round3( round3(rAlD) × L²/8 )
M_钢 = round3( round3(rStD) × L²/8 ) / 1.05

W_铝 = min(Wx1, Wx2)      W_钢 = min(Wx1, Wx2)
σ_铝 = round3(M_铝 / W_铝)
σ_钢 = round3(M_钢 / W_钢)

V_铝 = round3( round3(rAlD) × L ) / 2
V_钢 = round3( round3(rStD) × L ) / 2
τ_铝 = round3( Sx_铝·V_铝 / (Ia · t_铝) )
τ_钢 = round3( Sx_钢·V_钢 / (Is · t_钢) )

df  = round3( 5 × round3(rAlS) × L⁴ / (384 · Ea · Ia) )
lim = round3( min(L/300, 15) )    ,  L ≤ 7500
      round3( L/500 )             ,  L > 7500
```

### 与静力学手册的对应（形式一致，系数以代码为准）

| 环节 | 静力学形式 | V31 实际 | 差异 |
|---|---|---|---|
| 组合截面受弯 | 按刚度分配：M_i = M·E_iI_i/ΣEI（换算截面法） | 同 | ✓ 一致 |
| 简支梁弯矩 | M = qL²/8 | 同 | ✓ |
| 简支梁剪力 | V = qL/2 | 同 | ✓ |
| 弯曲正应力 | σ = M/W | 同 | ✓ |
| 弯曲剪应力 | τ = Sx·V/(I·t) | 同 | ✓ |
| 简支梁挠度 | f = 5qL⁴/(384EI) | 用 ΣEI 的等价写法：份额×铝刚度 | ✓ 等价（见下）|
| 强度调整 | 组合构件材料强度调整系数 | 铝×1.05、钢÷1.05 | 手册无此形式，**代码事实** |

挠度等价性（可验算）：
`5·(qk·1.05·EaIa/ΣEI)·L⁴/(384·Ea·Ia) = 5·1.05·qk·L⁴/(384·ΣEI)` —— 即「组合刚度 + 1.05 放大」。

## 八、待确认 / 未闭合（不凑数）

1. **1.05 的出处**：代码位置已钉死（铝侧 Variant 常量 1.05 @`0xCE2CD0`；钢侧 `fdiv 1.05` @`0xCE43C9`），
   但规范条文级出处未查证（疑为「钢铝组合构件材料强度调整」条款）。**不改公式，只记事实**。
2. **钢的 Wx 取 min 无法区分**：`钢铝结合钢立柱` 57 条全部 `Wx1 ≡ Wx2`；
   铝侧靠 60/200 系列区分出来了（min → 22.548，Wx1 → 21.57）。
   钢侧按同一逻辑取 min，标注为**同源推定**而非实证。
3. `0xCE2793` 的 `0.16 × 5 = 0.8`、`0xCE299B` 的 `1.4`、`0xCE2ABE` 的 `0.5` 一组自重项，
   在本模型下**全程为 0**（`0xCE28B6`/`0xCE27B2` 出参 0），未参与 6 个输出。
   是否在其它模型/开关下生效，未验证。
4. `0x850292` 是「double → Variant」辅助（在铝弯与挠度段各出现一次），未做深入。
5. 铝框 DataGrid 第 6 行（60/200）在 125px 表格内被裁切，只能键盘下移选中；已用键盘取到并验证通过。
