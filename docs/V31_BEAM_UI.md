## 一、怎么进到横梁页（实机链路）

```
主界面菜单「玻璃幕墙 > 全隐框」          → 窗体「全隐框玻璃幕墙计算-基本参数输入」(0x212CD6)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-立柱计算」  (0x202D42)
  点「下一步」                          → 窗体「全隐框玻璃幕墙计算-横梁计算」  (0x202EF2)
```

三个窗体**同时存在**，靠 `IsWindowVisible` 区分当前页；`FindForm` 必须按标题找，
不能只按 pid（同一进程里有 72 个 `ThunderRT6FormDC`）。

菜单命令：`PostMessage(mdiForm, WM_COMMAND, id, 0)`，「玻璃幕墙 > 全隐框」的 id = **2**。
主窗体是 `ThunderRT6MDIForm`（标题「汇宝幕墙门窗结构计算软件V31.0 (免费版)」）。

### 预选 Wx / Wy 的完整算式链（**已闭合两条链**，槽数组 + 实参双证）

**槽数组必须二次解引用**：`[0x1C911A0]` 里存的是数组指针（`mov ecx, dword ptr [0x1c911a0]`），
实测指向堆地址 `0x2067A90`。VARIANT 16B/槽，vt 在 +0、double 在 +8。

**横梁槽编号（实测）**：

| 槽 | 含义 | 单片 | 中空+夹层 |
|---|---|---|---|
| `[2]` | 分格宽 B | 1100 | 1100 |
| `[3]` | 分格高 H | 1380 | 1380 |
| `[6]` | wk（N/mm²） | 0.001285 | 0.001285 |
| `[7]` | qk | 1.414 | 1.414 |
| `[8]` | qd | 2.121 | 2.121 |
| `[9]` | **αmax（地区参数表）** | 0.16 | 0.16 |
| `[10]` | **自重面荷载 g（N/mm²）** | **0.0003** | **0.00055** |
| `[11]` | g × 5αmax | 0.00024 | 0.00044 |
| `[12]` | B × [11] | 0.264 | 0.484 |

| `[24]` | 弹性模量 E | 70000 | 70000 |

**公式**：

```
g    = 参数库「幕墙自重参数」→ 计算横梁时自重 / 1e6      # N/mm²
B    = 分格宽 (第一页)                        H = 分格高 (第一页)

# 竖向（绕 x 轴，简支 /8，用 Wx）
q_x  = round3( H × g × 1.3 )
M_x  = q_x × B² / 8
Wx预选 = M_x / f

# 水平向（绕 y 轴，固端 /12，用 Wy）
q_y  = qd + round3( B × g×5αmax × 1.4 ) / 2      # 5αmax：北京 0.8、上海 0.4
M_y  = q_y × B² / 12
Wy预选 = M_y / f
```

**自重 g 的来源就是参数库表**（这正是「材质/自重从参数库拿」的落点）：
`幕墙自重参数.csv` 的「计算横梁时自重」列 —— 单片 300、中空或夹层 400、中空夹层或双中空 **550**、
双夹层中空 650（N/m²）。切成「中空+夹层」后槽 `[10]` 实测从 0.0003 变 0.00055，与表第 3 行 550 完全对应。

实参出处：`0x8AEF65`(×1.4) `0x8AF088`(×0.5) `0x8AF095`(+qd) `0x8AF23B`(×B²) `0x8AF24F`(/12)
`0x8AF9BF`(/f) `0x8AF353`(H×g) `0x8AF599`(×1.3) `0x8AF6D9`(×B²) `0x8AF6ED`(/8) `0x8AF856`(/f)。

### 挠度计算：两个方向**系数不同**（实参钉死，重点）

| 方向 | 公式 | 实参链 | 结果 |
|---|---|---|---|
| **垂直向（自重）** | `df_v = 5 · (H·g) · B⁴ / (384 · E · Ix)` | `0x8B73DA` 0.414×**5**=2.07 → `0x8B740D` ×B⁴ → `0x8B7421` **/384** → `/E` → `0x8B745F` `/Ix` | **0.973567** → 0.974 |
| **水平向（风）** | `df_h = qk · B⁴ / (120 · E · Iy)` | `0x8B71FF` B⁴×**1.414** → `0x8B7213` **/120** → `/E` → `0x8B7251` `/Iy` | **1.993181** → 1.993 |

要点：
- 垂直向是**标准简支均布**（系数 5/384），荷载用 `H·g`（自重线荷载标准值，**不带** 1.3 分项）
- 水平向系数是 **1/120**（= 3.2/384，比简支小到 0.64 倍），荷载用 `qk`（风线荷载标准值，**不带** 1.5）
- 各自用自己的惯性矩：垂直 Ix=115810、水平 Iy=123650
- 允许值也各自不同：垂直 **B/250**、水平 **B/180**

四个「不一样」摆在一起（荷载 / 系数 / 惯性矩 / 限值），**任何一处混用都会错**。

### 预选 Ix / Iy：与挠度公式**同构**（把 I 解出来、用 lim 代替 df）

| 方向 | 公式 | 实参链 | 结果 |

### 水平向 B > H 的梯形分支（2026-10-25 深挖闭合）

前面所有结论都是在 **B ≤ H**（1100 ≤ 1380，三角形）状态下取的。把分格改成 **B > H** 后，
预演输出会整体换一套数（预选 Wx 904→1219、Wy 2584→5494），一开始抓不到任何实参 ——
**因为程序换了一整段代码**：`0x8AEA00–0x8AF3xx` 一条指令都没执行，全部跑到 **`0x8CDF34` 起**。

#### 一、分支的物理含义：线荷载「取多宽」

| 状态 | 线荷载取值 | 实参证据 |
|---|---|---|
| B ≤ H（竖条格，三角形） | `qk = round3(B·wk/1000)` | `0x8AEB0F` **1100**×0.001285 = 1.4135 |
| B > H（横条格，梯形） | `qk = round3(H·wk/1000)` | `0x8CDF34` **1000**×0.001264 = 1.264 |

两者统一为 **`r = min(B, H)`**：`qk = round3(r·wk/1000)`。

#### 二、水平向弯矩：系数随 B/H 连续变化

```
0x8CE8BE   r/B        = 1000/1500 = 0.666667
0x8CE8D2   (r/B)²     = 0.444444                        (args ['empty',2,'0.666667'] → Pow)
0x8CE8DF   3 − (r/B)² = 2.555556                        (args ['empty','0.444444','3'] → Sub)
0x8CE8EC   × q_y·B²   = 2.555556 × 4644000 = 11868000
0x8CE900   / 24       = 494500                          ← M_y
```

即

```math
M_y = q_y · B² · (3 − (r/B)²) / 24
```

端点自检：`r = B`（三角形）→ `2/24 = 1/12`；`r → 0`（趋近均布）→ `3/24 = 1/8`。
**之前「竖向 /8、水平 /12」的差异不是固定模型，而是同一个式子在 r 两端的取值。**

#### 三、水平向挠度：系数同样是 r 的函数

```
0x8D2DB7   H/2 = 500          (args ['empty',2,1000])
0x8D2DD6   u = (H/2)/B = 0.333333
0x8D2DF7   5u² = 0.555556
0x8D2E04   3.125 − 5u² = 2.569444
0x8D2E64   u⁴ = 0.012346
0x8D2E71   2u⁴ = 0.024691
0x8D2E7E   2.594136                       (= 3.125 − 5u² + 2u⁴)
0x8D2E9F   / 240
0x8D2EBE   / E

## 八、集中力模型分支（手册 B03 第 2 节 ↔ 实机对照）

### 8.1 手册原文（`html/B03.htm`）

> 对于常规隐框幕墙、金属板幕墙或周边金框的石材幕墙，横梁按分格宽度和高度的关系承受
> **三角形（分格宽 ≤ 分格高）或梯形（分格宽 > 分格高）**荷载，荷载分配呈 45 度角；
>
> 对于**半隐框、明框的自重方向**或**背栓、短槽连接方式的水平、垂直双向**，横梁上有
> **2 到多个集中力受力点**，软件目前支持的是**两点集中受力**情况，在这种情况下软件
> **需要输入受力点到支座的距离**。

即手册把集中力分成两种适用范围：**自重方向**（半隐框/明框）与**双向**（背栓/短槽）。

### 8.2 实机对照（开关可用性完全吻合）

| 入口 | 「玻璃自重为集中力」 | 「按集中力模型」 | 结论 |

### 8.3 自重方向集中力的公式（槽值直读，非反推）

条件：B=1100、上分格 H=1500、g=0.0003 N/mm²、a=150、αmax=0.16、型材 40/60。

| 槽 | 均布 | 集中力 | 含义 |
|---|---|---|---|
| `[19]` | 0.450 (=H·g) | **247.500** | P 标准值 = H·g·B/2 |
| `[20]` | 0.585 (=round3(H·g·1.3)) | **321.750** | P 设计值 = round3(H·g·1.3)·B/2 |
| `[21]` | 88481.250 | **48262.500** | M_x = P设计值·a |
| `[22]` | 983.125 | **536.250** | 预选 Wx = M_x / f |
| `[30]` | 27852.958 | **17779.018** | 预选 Ix |
| 竖向挠度 | 1.058 | **0.675** | 见下式 |

```
P_std = H·g·B/2
P_des = round3(H·g·1.3)·B/2
M_x   = P_des · a
df_v  = P_std·a·(3B² − 4a²)/(24·E·Ix)
Ix预选 = P_std·a·(3B² − 4a²)/(24·E·lim_v)
```

代入 a=150：`3B²−4a² = 3×1,210,000 − 90,000 = 3,540,000`；
`247.5×150×3,540,000/(24×70000×4.4) = 17779.018` ✓、`df_v = 0.675` ✓。

**水平向完全不受影响**（Wy 2583.574 / Iy 40330.033 / df_h 1.993 / τh 6.061 均不变），
与手册「自重方向」一致；竖向剪力 `V_v = H·(B·g·1.3)/2 = 321.75` 与 P 设计值数值相同，
故 τv 1.664 也不变（不是巧合，是同一个量）。

### 9.3 公式与验算（B=1100、H=1380、g=0.0003、αmax=0.16、型材 40/60）

```
