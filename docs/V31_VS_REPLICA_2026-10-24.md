# V31 实机 vs 复刻版 对比报告（2026-10-24）

## 一、对比方法（全程实机操作，无任何默认值假设）

用 `local-data/recon/v31_attach.ps1` 附着到运行中的 **汇宝 V31 免费版**（pid 由 `v31_keep.ps1` 常驻托管），
从**第一个面板**开始逐项填写，每步回读/截图核对，然后进入立柱屏、多跨屏，最后「确认数据 → 预演」，
读取右侧富文本框原文（`v31runs/v31_preview_result.txt`）。

复刻版（SMHS）用 UIA 驱动同样的字段（`unpack/uia_replica_*.ps1`），读取 Text 元素原文
（`v31runs/replica_estimate_7.txt`）。

## 三、本轮查明的关键公式事实

1. **内力与挠度按「跨长 L」计算，不是按 L+A。**
   证据：V31 第 1 跨挠度 135.0835 mm，而 `5qL⁴/(384EI)`（L=4000, q=2.425, I=88.595cm⁴, E=70000）
   = 130.34 mm，比值 1.0364；若用 L+A=5000 则得 318 mm，差 2.35 倍。
2. **挠度限值仍按 L+A**：5000 → 4500<5000≤7000 → 5000/250+7 = 27 mm ✓（与 V31 完全一致）。
3. **多跨铰接连续静定梁的输出值与总跨数 N 无关。**
   实机验证：同一组 A=1000/L=4000，N=5 与 N=7 两次预演，V31 给出的 12 项数值**逐位相同**
   （N 只影响右表段数 2N 与占位行）。此前把差异归因于 N 的建模是错的。
4. **V31 实测标定系数**（A/L=0.25 这一点）：
   - 抗弯放大 `V31MomentFactor = 1.0743` = 242.875 / 226.104
   - 抗剪放大 `V31ShearFactor = 1.1463` = 14.225 / 12.410
   - 挠度放大 `V31DeflectionFactor = 1.0364` = 135.0835 / 130.335
   已写入 `src/GlassManagement.Calc/Engines/MultiSpanStaticEngine.cs`。
5. **代表位置比例**（本次实测）：支座抗弯/第1跨 = 1.3511；第3跨抗弯/第1跨 = 0.6250；
   支座抗剪/第1跨 = 1.6000；第3跨抗剪/第1跨 = 0.1875；第2跨后挠度/第1跨 = 0.3988。

## 四、残差来源（2.6% / 4.3%）

复刻版仍用「N 插值比例」（端点取历史两样本 N=5/N=15）。
但本次实测证明 V31 结果与 N 无关，说明历史两样本的差异其实来自 **A/L 不同**，比例应是 A/L 的函数。
当前 A/L=0.25 这点上，支座抗弯比例模型给 1.2926、实测 1.3511，第3跨模型 0.6412、实测 0.6250 —— 这就是残差。

**下一步**：在 V31 上改 A/L（如 A=600/L=4000、A=1500/L=4000），各跑一次预演，
拟合「比例 = f(A/L)」，替代 N 插值。

## 五、仍未闭合的项

- **wk 公式链**：V31 在「按规范不小于 1KPa」下对上海/标高100/B类算出 1.796 KPa；
  复刻版目前只能给 `max(w0,1.0)=1.0`。μz / β / μs / 分格 的乘积组合仍多解，需要更多实机点定标。
- **A002.CAC 材料表**（各材质 抗弯/抗剪/折算 许用值）仍在 EXE 内未取出，目前 135/75/148.5 只覆盖 6063(A)-T5 系。
