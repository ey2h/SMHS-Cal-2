# 复合玻璃（中空 + 夹胶）受力流程 —— 三级分配与胶片类型

> V31 玻璃屏第四段函数区 `0xA46000–0xA49B00`（17 个 rtcRound 定稿点）。
> 实测工况：1100×1380、三片均 6mm、wk=1.37kPa、αmax=0.16、PVB。
> 证据：`v31runs/glass_insullam_rounds.json` + Frida 抓的运算 DAG。

## 零、先说一个结论：三级分配在 V31 里是「合并成一级」

用户描述的流程是「总荷载 → 按中空各层刚度分到两侧夹胶 → 每侧再细分到每片」。
V31 实际写的是**一次按 t³ 分到每片**，分母直接用**全部玻璃片的 Σt³**：

```
侧份额  = S_side / S_all          S_side = 该侧各片 t³ 之和
片份额  = t_i³ / S_side
两者相乘 = t_i³ / S_all           ← 与 V31 的一次分配完全相同
```

实测分母 **648 = 3×216**（三片 6mm 全部计入，`0xA4608D`），证明 V31 用的是合并式。
⇒ **复刻时两种写法都行，结果逐位相同**；本实现按用户要求保留三级结构（便于逐级核对），
但每级都输出中间量，最终与 V31 的合并式对齐到同一位。

## 一、胶片类型的判定依据（必须先定，决定流程走向）

| 证据 | PVB | SGP |
|---|---|---|
| 本屏「夹层配置」下拉（**ctrl id=5**，项序 0/1） | `PVB(聚乙烯醇缩丁醛)` = 0 | `SGP(离子型间层)` = 1 |
| 胶片厚度下拉（ctrl id=3）可用性 | **en=False**（不参与，无需厚度） | **en=True**（必须输入） |
| 输出文案 | `外片玻璃强度计算值:…` | `1#玻璃(夹层偏室外侧)强度计算值:…` |
| 同工况 σ | 10.345MPa | **6.392MPa** |
| 等效厚度 | 0.95×(6³+6³+6³)^(1/3) = **8.221** | 0.95×(12³+6³)^(1/3) = **11.856** |

**判定链**：类型来自**本屏下拉**（不是第一页），选择后立即切换「厚度框 en 状态 + 输出文案 + 公式分支」。
id=5 的下拉项序就是 `InterlayerKind`：0=PVB、1=SGP。

> V31 的两套算法不是"同一个公式换个系数"，而是**两段独立函数**：
> PVB 在 `0xA46xxx–0xA49Axx`，SGP 在 `0xA52xxx–0xA54Axx`。

## 二、PVB 口径的三级流程（已完全闭合）

### 输入（全部来自上游 / 本屏）

| 名称 | 来源 | 单位 | 本次值 |
|---|---|---|---|
| wk | 第一页风荷载链（玻璃屏按本面板 μs 合重算） | N/mm² | 0.00137 |
| a / b | 第一页龙骨间距 → 本屏分格尺寸下拉（短边取 min） | mm | 1100 / 1380 |
| tᵢ（3 片） | 本屏「外片/中片/内片」厚度下拉 | mm | 6 / 6 / 6 |
| αmax | 参数库「地区参数」（北京 0.16） | — | 0.16 |
| 胶片类型 | 本屏「夹层配置」下拉 id=5 | 枚举 | PVB=0 |

### 常量

```
γ = 2.56e-5 N/mm³     E = 72000 N/mm²     12(1−ν²) = 11.52
m = 弯矩系数（a/b 插值，取 4 位）          μ = 挠度系数（取 5 位）
η = 折减系数（θ 分段线性插值，取 3 位）    Q系数 = 5αmax
```

### 第 0 步：荷载（与片数无关，只算一份）

| 变量 | 公式 | 本次值 | 定稿点 |
|---|---|---|---|
| qg | `round6(t₀·γ)` | 0.000154 | `0xA46476` |
| Q | `round6(5αmax·qg)` | 0.000123 | `0xA46599` |

> ⚠ 只取**首片**厚度算一份自重/地震（不是三片之和）。夹层玻璃（单片夹胶）在 `0xA2DB90` 用的是两片之和 —— 两者不一致，登记为疑点。

### 第 1 步（第一级）：总刚度

| 变量 | 公式 | 本次值 |
|---|---|---|
| S_side,outer | Σ tᵢ³（夹胶侧 2 片） | 432 |
| S_all | Σ tᵢ³（全部 3 片） | **648** |
| **输出** | `S_all` = 648 | |

### 第 2 步（第二级）：分到每片

| 变量 | 公式 | 本次值 | 定稿点 |
|---|---|---|---|
| w₀（最外片） | `round6(1.1·wk·t₀³/S_all)` | 0.000502 | `0xA4609A` |
| wᵢ（其余片） | `round6(wk·tᵢ³/S_all)` | 0.000457 | `0xA46CCB` / `0xA47471` |

**1.1 只加在最外侧那一片**（中空玻璃同理，见 9.1）。夹胶**内侧片不加**。

### 第 3 步（第三级）：逐片组合 → θ → η → σ

对每片 i：

| 变量 | 公式 | 外片 | 夹胶内侧片 | 室内单片 |
|---|---|---|---|---|
| W标准ᵢ | `round6(wᵢ + 0.5Q)` | 0.000564 | 0.000518 | 0.000518 |
| W强度ᵢ | `round6(1.5wᵢ + 0.7Q)` | 0.000839 | 0.000772 | 0.000772 |
| θᵢ | `round3(W标准ᵢ·a⁴/(E·tᵢ⁴))` | 8.849 | 8.128 | 8.128 |
| ηᵢ | η表(θᵢ)，3 位 | 0.969 | 0.975 | 0.975 |
| **σᵢ** | `round3(6·m·W强度ᵢ·a²·ηᵢ/tᵢ²)` | **10.345** | 9.578 | 9.578 |

> 夹胶两片同厚 ⇒ 同份额 ⇒ 同 σ；V31 屏上「外片玻璃强度计算值」出现两次同值就是这个原因。

### 第 4 步：挠度（不分片，用等效厚度）

| 变量 | 公式 | 本次值 | 定稿点 |
|---|---|---|---|
| t_e | `round3(0.95·(Σ tᵢ³)^(1/3))` | **8.221** | `0xA49449` |
| θ_δ | `round3(wk·a⁴/(E·t_e⁴))` | 6.099 | `0xA4976A` |
| η_δ | η表(θ_δ) | 0.991 | — |
| D | `round3(E·t_e³/11.52)` | 3,472,593.612 | `0xA495B1` |
| **df** | `round3(η_δ·μ·wk·a⁴/D)` | **3.469** | `0xA49A3B` |
| lim | `round3(a/60)` | 18.333 | `0xA49214` |

## 三、SGP 口径（**未闭合，不臆造**）

已实测到的部分：

| 项 | 值 | 依据 |
|---|---|---|
| 函数区 | `0xA52xxx–0xA54Axx` | 定稿点聚类 |
| 夹层侧合成厚度 | 12 = 6+6，`12³ = 1728` | `0xA543C1` |
| 总刚度 | `1728 + 216 = 1944` | `0xA543F4` |
| t_e | `0.95×1944^(1/3) = 11.8565` → **11.856** | `0xA54415` |
| D | `72000×11.856³/11.52 = 10415846.94` | `0xA54576` |
| θ_δ | 1.410 | `0xA5472F` |
| σ 计算式 | `6·m·W·a²·η/t²`，η=1，**t = 11.969** | `0xA534CF`/`0xA534DC` |
| σ 结果 | **6.392** | 屏上原文 |

**未定位**：σ 里的 `t = 11.969` 从哪来（11.969² = 143.257，不等于 t_e²；也不是 11.856 的任何整次幂）。
在它没拆出来之前，`ComputeComposite(..., InterlayerKind.Sgp, ...)` 显式抛 `NotSupportedException`，
不用「近似值凑 6.392」——那会污染后续所有 SGP 工况。

> 合理猜测（**未验证，不作数**）：SGP 参与受力后夹层等效为一整块，可能存在第二套「强度用等效厚度」
> 公式（与挠度用的 11.856 不同），需要再抓一次 `0xA53000–0xA53500` 的完整 DAG 才能定。

## 四、逐级衔接自检

| 衔接点 | 校验 | 结果 |
|---|---|---|
| 第1→2级 | Σ(tᵢ³/S_all) = 1.1·t₀³/S + Σ_{i>0} tᵢ³/S | ✅ 份额和 = 0.000502+0.000457×2 |
| 第2→3级 | θᵢ ∝ W标准ᵢ；σᵢ ∝ W强度ᵢ·ηᵢ | ✅ 8.849→10.345、8.128→9.578 单调对应 |
| 第3→4级 | 各片 σ 与 df 共用同一 m/μ/η 表与同一 E | ✅ 同一份 table 实例 |
| 挠度独立 | t_e 不参与 σ，σ 的 t 不用 t_e | ✅ 实测如此（PVB） |

## 五、疑点登记

1. **自重/地震只按首片厚度算一份**（0.000154），而「夹层玻璃」分支按两片之和（0.000307）—— 两条分支口径不一致。
2. **SGP 的 σ 用 t=11.969**，与 t_e=11.856 不符，公式未拆 → 已阻断实现，不做近似。
3. 夹胶内侧片**不加 1.1**，只有最外片加 —— 若中空两侧都是夹胶（双夹层-中空），1.1 加在哪一侧/哪一片未验证。
4. 「中空+夹层」默认三片同厚；不等厚时第 0 步的 qg 取哪片未验证。
5. 胶片厚度在 PVB 下 en=False，但下拉里仍有 5 个候选值（0.38~2.28）—— 该值是否被 PVB 公式读取未验证。

## 六、SGP 深挖进展（2026-10-25 18:5x）

### 6.1 已拆出的核心公式（`0xA515F2–0xA516D4`，运行期数值逐位）

```
Γ  = 0.8967                    ← slot[22]，剪切传递系数（来源待挖）
y  = (t + t_film)/2 = 3.38     ← slot[17]；t_film=0.76（slot[15]），t=6
d  = t₁ + t₂ = 12              ← slot[23]（夹层两片合成厚度）

t_s = sqrt( d³ / (t + 2·Γ·y) )          ← 强度用等效厚度
    = sqrt( 1728 / (6 + 2×0.8967×3.38) )
    = sqrt( 1728 / 12.061692 )
    = sqrt( 143.2634824 )
    = 11.9692724 → round3 = 11.969      ← slot[24]/[25]

σ   = round3( 6·m·W·a²·η / t_s² )
    = 6×0.0631×0.001999×1100²×1 / 143.256961
    = 6.3923867 → 6.392
```

关键差异（与 PVB 比）：
| 项 | PVB | SGP |
|---|---|---|
| 强度厚度 | 逐片 t=6 | **t_s = sqrt(d³/(t+2Γy)) = 11.969** |
| 折减系数 η | 按 θ 查表（0.969/0.975）| **恒 1**（`0xA534A9` ×1）|
| 挠度 t_e | 0.95·(6³+6³+6³)^(1/3)=8.221 | 0.95·(12³+6³)^(1/3)=**11.856** |
| 强度荷载 W | 逐片分配 | **整片 W=0.001999**（slot[32]）|

### 6.2 SGP 槽布局（直读 0x1C911BC）

```
[6][7][8]=6 三片厚度   [9]=0.000307 自重(两片和)  [11]=0.000246 地震
[14]=11.3  [15]=0.76 胶片厚度  [16]=6.76=t+t_f  [17][18]=3.38=y
[19]=137.093  [22]=0.8967 Γ  [23]=12=d  [24][25]=11.969 t_s
[26]=1 η  [27]=0.00137 wk  [28]=0.001218  [29]=1.1
[30]=0.000167 [31]=0.001341 [32]=0.001999 W  [33]=0.000228 [34]=0.000337 [35]=0.002313
[39]=0.0631 m  [40]=6.392 σ1  [47]=6.392 σ1  [52]=3.577 σ2  [54]=4.288 σ3
[59]=0.00606 μ  [60]=18.333 lim  [61]=11.856 t_e  [62]=10415846.9 D  [63]=1.41 θ_δ  [65]=1.167 df
```

### 6.3 仍缺的两个中间量（不硬凑，故 SGP 仍阻断）

1. **Γ = 0.8967**（slot[22]，写入点 `0xA5113A`/`0xA51226`）—— 剪切传递系数，
   猜测与胶片厚度（0.76）或 SGP 剪切模量有关，需再反汇编一层。
2. **W = 0.001999**（slot[32]，写入点 `0xA52512` 附近）—— 强度用整片荷载，
   与标准组合（0.001341）不是简单 1.5 倍关系（1.341×1.5=2.0115≠1.999）。

在两者公式落地前，`ComputeComposite(..., Sgp, ...)` 保持抛 `NotSupportedException`；
`t_s` 与 σ 的**结构**已按上述实现路径记录，等 Γ/W 补齐即可直接接上。

## 七、SGP 闭环（2026-10-25 19:2x，Γ 与 W 已拆出）

### 7.1 Γ 剪切传递系数（`0xA5104D–0xA51118`，取 4 位）

```
Γ = 1 / ( 1 + 9.6·E·k₁₉·t_f / (k₁₄·(t+t_f)²·a²) )

实测：9.6×72000×137.093×0.76 = 72,016,598.016      ← 0xA51079
      11.3×6.76²×1100²        = 624,823,284.8       ← 0xA510F1
      比值 0.11525914569 → 1+比值 1.11525914569
      Γ = 1/1.11525914569 = 0.8966526 → round4 = 0.8967
```
- `k₁₉ = 137.093`（slot[19]）、`k₁₄ = 11.3`（slot[14]，即「夹层配置」框里的 11.3）
- 9.6 为硬编码常量

### 7.2 W 整片强度荷载（`0xA52013–0xA522A7`）

```
Σ   = d³ + t₃³ = 1728 + 216 = 1944                    ← 0xA52020
w_夹 = wk·d³/Σ = 0.00137×1728/1944 = 0.001218         ← slot[28]
W标准 = round6(w_夹 + 0.5Q) = 0.001218+0.000123 = 0.001341   ← slot[31]（0xA5215B）
W强度 = round6(1.5·w_夹 + 0.7Q) = 0.001827+0.0001722 = 0.0019992 → 0.001999  ← slot[32]（0xA522A7）
```
注意：`w_夹` **不乘 1.1**（1.1 只出现在单片薄份额 slot[30]=0.000167 = 1.1·wk·t³/Σ，用于别的量）。

### 7.3 SGP 完整链路（已实现 `ComputeCompositeSgp`，逐位对上 6.392 / 1.167）

```
qg = round6((t₁+t₂)·γ) = 0.000307      Q = round6(5αmax·qg) = 0.000246
d = t₁+t₂ = 12     y = (t+t_f)/2 = 3.38     Σ = d³+t₃³ = 1944

σ = round3(6·m·W强度·a²·**1**/t_s²) = 6.392        ← η 恒 1，不查表
t_e = round3(0.95·Σ^(1/3)) = 11.856
θ_δ = round3(wk·a⁴/(E·t_e⁴)) = 1.410   η=1   D = round3(E·t_e³/11.52) = 10,415,846.938
```

### 7.4 仍待考（不影响当前工况复现）

1. `k₁₉ = 137.093` 的物理含义（疑似与 SGP 剪切模量 G 或胶片基准厚度相关）—— 目前作为命名常量传入。
2. 胶片厚度变化时 Γ 与 t_s 已验证随动（0.76→2.28 使 t_s 11.969→11.651），但**未与实机二次对拍**（改厚度需重新跑 V31）。
3. 双中空 / 双夹层-中空 两种配置未挖。

## 八、双中空玻璃（未闭合，仅记录实测）

### 8.1 定位

| 项 | 值 |
|---|---|
| 函数区 | `0xA5Cxxx–0xA5F2xx`（17 个定稿点） |
| 屏上输出 | 外片 **11.262**MPa、中片 **9.16**MPa（内片同 9.16）、df **3.806**mm、lim 18.333mm |
| 片位 | 外片 / 中片 / 内片（3 片，槽 [6]/[11]/[12] 均为 6mm） |

### 8.2 已实测的中间量（槽 0x1C911BC）

```
[7]=0.000154 自重   [9]=0.000123 地震   [10]=0.00137 wk
[13]=0.000555 [14]=0.000617 [15]=0.000919        ← 三个份额候选
[20]=0.000433 [21]=0.000495 [22]=0.000736        ← 第二组（标准组合？）
[25]=0.000433 [26]=0.000495 [27]=0.000736
[28]=0.002313 整片强度组合
[30]=9.681 θ外  [31]=0.963 η外  [33]=11.262 σ外
[38]=7.767 θ中  [39]=0.978 η中  [40]=9.16   σ中
[45]=7.767 [46]=0.978 [47]=9.16                  ← 内片与中片同值
[54]=7.952 t_e  [55]=3142744.909 D  [56]=6.967 θ_δ  [57]=0.984 η  [58]=3.806 df
```

验算：`D = E·t_e³/11.52` → t_e³ = 3142744.909×11.52/72000 = **502.84** → t_e = 7.9513 → round3 = 7.952 ✓

### 8.3 卡住的点（不硬凑）

`t_e = 7.952` 反推 **Σt³ = 502.84**，但三片 6mm 的 Σt³ = **648**（中空+夹层就是 648 → t_e=8.221）。
502.84 既不是 648、也不是 864（4 片）、更不是 216×2=432。

可能的解释（**均为待验证假设，不作数**）：
1. 双中空的等效厚度公式带腔体折减（两个中空腔的滑移叠加），不是简单 Σt³；
2. 中间片在双中空里按"两片半厚"计（如 2×(3³)=54 之类），需实测厚度变化才能定；
3. 会先把三片之一的厚度改掉再跑一次，用两点定系数。

同理，σ 的两个值（11.262 / 9.16）对应的份额（0.000433 / 0.000495）也不符合"按 t³ 均分 = 0.000457"，
说明双中空的分配规则与单中空**不同**，需要单独拆。

> 结论：双中空**不实现**，等 Σ 与份额公式拆出来再说。当前 `ComputeComposite` 只覆盖
> 单片 / 中空 / 夹层 / 中空+夹层(PVB/SGP) 四种；双中空与双夹层-中空标记为"未支持"。

### 8.4 ★ 等效厚度已定案：逐层衰减（四点实机）

改厚度重跑（外/中/内各改一片 6→8）：

| 组合 | t_e(实测) | Σ有效 = t_e³/0.95³ | ΔΣ |
|---|---|---|---|
| 6/6/6 | 7.952 | 586.49 | — |
| 8/6/6 | 9.112 | 882.2 | +295.7（=8³−6³） |
| 6/8/6 | 8.964 | 840.11 | **+253.6**（=296×0.95³） |
| 6/6/8 | 8.964 | 840.11 | +253.6 |

→ 外片按 t³ 全额计入，中/内片按 **0.95³·t³** 计入。写成厚度形式即：

```
t_e = [ (0.95·t₁)³ + (0.95²·t₂)³ + (0.95²·t₃)³ ]^(1/3)
```

物理含义：**每穿过一层中空腔，厚度打 0.95 折**（外片 1 层、中/内片 2 层）。
四点全部落在 round3 内（7.952 / 9.112 / 8.964 / 8.964），已实现为
`GlassEngine.DoubleInsulatedThickness` + `DoubleInsulatedTests`（4 例）。

⚠ 与「中空+夹层」口径不同：后者是 `0.95·(Σt³)^(1/3)`（全体折一次 → 8.221）。
V31 两种配置的等效厚度算法不一致，各自记录，**不可混用**。

### 8.5 仍未拆：σ 的荷载分配

三点实测的 σ 与份额（槽 [13]/[14]/[15] = 0.000555 / 0.000617 / 0.000919）：

| 组合 | σ外 | σ中 | df |
|---|---|---|---|
| 6/6/6 | 11.262 | 9.16 | 3.806 |
| 8/6/6 | 8.352 | 8.511 | 2.700 |
| 6/8/6 | 8.352 | 8.511 | 2.700 |
| 6/6/8 | 8.352 | 6.818 | 2.700 |

## 九、双夹层-中空（4 片）—— 已闭合

### 9.0 手册依据（分配原则）

V31 帮助 `B01`「10 板块配置」是全手册唯一讲这几种构型的地方，原文三条：

| 位置 | 原文 |
|---|---|
| `B01:515` | **中空 + 夹层玻璃**：两片玻璃**先夹胶后**再与另一片玻璃组成中空玻璃的板块形式 |
| `B01:518` | **三玻双中空**：三片玻璃组成的具有 **2 个中空层**的结构 |
| `B01:519` | **双夹层中空**：**四片玻璃**组成的中空层的结构，安全性很高 |

由此得到本构型的**受力原则**（不是拟合）：

```
第一步  先夹胶：每侧 2 片合成一个整体，等效厚度 t_l = (t₁³+t₂³)^(1/3)   ← 夹层无 0.95
第二步  再中空：两个整体按中空分配，t_e = 0.95·(t_l1³ + t_l2³)^(1/3)   ← 中空有 0.95
合并     t_e = 0.95·((t₁³+t₂³) + (t₃³+t₄³))^(1/3) = 0.95·(Σt³)^(1/3)
```

本实现写成 `(Σ(0.95tᵢ)³)^(1/3)`，与该式**数学恒等**，即完全遵守手册原则。
荷载分配同理：夹层内部两片同厚 → 各占一半；两侧按 `D侧/ΣD`，外侧再乘 1.1。

> **手册只给原则，不给数值**：全手册 40+ 页里没有玻璃等效厚度公式、也没有分片荷载分配公式
> （`grep` 「等效厚度」「荷载分配」「各片」均无命中；`B04` 只到强度设计值表和加工说明，
> 玻璃段的 2 张图是节点构造图）。所以 0.95 这类系数只能以代码为准
> —— `0xA28B80` 就是中空等效厚度函数，0.95 是那里的常量。

同样的原则用在**双中空**（三片 2 腔）：`B01:518` 说它有 **2 个中空层**，
所以不能统一折一次（那样得 8.221，与「中空+夹层」同值），
必须按每片穿越的腔数累积折减 —— 实测 7.952 正是逐层衰减
`[(0.95t₁)³+(0.95²t₂)³+(0.95²t₃)³]^(1/3)` 的结果（见 8.4）。
