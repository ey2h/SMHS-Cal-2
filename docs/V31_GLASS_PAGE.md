## 三、公式（全部带地址，运行期数值回代过）

```
γ(玻璃) = 2.56e-5 N/mm³        // 25.6 kN/m³，常量池 0x402818
E       = 72000 N/mm²          // VT_I4 立即数 0x11940（0xA21266）
12(1−ν²)= 11.52                // ν=0.2（0xA21D5E 的除数）

qg = round6(t·γ)                       // 0xA20BDB  6mm → 0.000154
Q  = round6(qg·5αmax)                  // 0xA20D42  0.000123
W₁ = round6(1.5·wk + 0.7·Q)            // 0xA20FC7  0.002141   ← 强度用
W₂ = round6(wk + 0.5·Q)                // 0xA210CD  0.001431   ← θ_σ 用

θ_σ = round3(W₂·a⁴/(E·t⁴))             // 0xA21359  22.453
η_σ = η表(θ_σ)  → 0.910188 → 取 3 位 0.91
σ   = round3(6·m·W₁·a²·η_σ / t²)       // 0xA216F8  24.793

θ_δ = round3(wk·a⁴/(E·t⁴))             // 0xA21A95  21.496   ← 只吃 wk，不吃 Q
η_δ = η表(θ_δ)  → 0.914017 → 0.914
D   = round3(E·t³/11.52)               // 0xA21D80  1350000
df  = round3(η_δ·μ·wk·a⁴/D)            // 0xA21F6C  8.23
lim = round3(a/60)                     // 0xA21C38  18.333
```

**两条链不同源**（最容易踩的坑）：
- θ_σ 用**标准组合 W₂**（含 0.5Q），θ_δ 用**纯 wk**；
- σ 用设计组合 W₁，df 用纯 wk。

## 四、三张表

### 4.1 折减系数 η（`0xA78E85`，θ 断点）

```
5→1.00  10→0.96  20→0.92  40→0.84  60→0.78  80→0.73  100→0.68
120→0.65  150→0.61  200→0.57  250→0.54  300→0.52  350→0.51  400→0.50
```
- θ ≤ 5 取 1.00；θ > 400 取 0.50。
- 插值（`0xA79518` 段）：`η = η上 − (η上−η下)·(θ上−θ)/(θ上−θ下)`。
- **结果取 3 位小数**：0.910188→0.91、0.914017→0.914（两点判别；不是 2 位也不是 6 位）。

### 4.2 弯矩系数 m（`0xA795D7`，a/b 断点）

```
0→0.125  0.25→0.123  0.33→0.118  0.40→0.1115  0.50→0.100  0.55→0.0934
0.60→0.0868  0.65→0.0804  0.70→0.0742  0.75→0.0683  0.80→0.0628
0.85→0.0576  0.90→0.0528  0.95→0.0483  1.00→0.0442
```
a/b = 1100/1380 = 0.7971014493 → 插值 0.06311884058 → **取 4 位 = 0.0631**（运行期乘数就是 0.0631）。

### 4.3 挠度系数 μ（`0xA79B07`）

```
0→0.01302  0.20→0.01297  0.25→0.01282  0.33→0.01223  0.50→0.01013
```

> 首段从 a/b→0 起。按「段内首个断点=端点」读会整体错一行（μ 会算成 0.00667）。

## 五、玻璃部分 wk（1.37）的组成

玻璃屏**自己算** wk（`0xA7CE09` 起的共用风荷载函数，用 **0x1C91168** 槽数组）：

```
wk = μz · βgz · 地形系数 · μs合 · (μs内压档 + 1) · w0
   = 1.0  × 1.6929 ×   1     × 1.4983 ×   (0.2+1)   × 0.00045    = 0.00136969…  → 0.00137
```
- `0xA7CEDA`：`slot[0x45] + slot[0xb]` = 1 + 0.2 = 1.2 → 存 slot[0x35]
- `0xA7D00C…0xA7D07C`：五次连乘 → `0xA7D081` 存 wk
- 屏上显示 `玻璃部分风荷载标准值为:1.37KPa`

与横梁屏的 1.285 不同，是因为**各屏用自己面板的 μs合**（1.4983）重算，w0/βgz/μz 全部来自第一页。
→ 复刻口径：玻璃屏取第一页的 w0/βgz/μz/地形/内压档，按玻璃面板的 μs合 重算，不另立一套参数。
