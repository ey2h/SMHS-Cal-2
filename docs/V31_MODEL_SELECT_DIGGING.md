# V31「模型图名」选择子的追踪记录（含负面结论，防止重复走弯路）

> 目的：把 `sub_18BD010` 里那条以 `.\\PIC\\静力计算手册\\NN-MM.wmf` 为键的 45 分支 Select Case 链，
> 与界面上的 6 个「力学模型」单选对上。下面每条都标了取证方式；**未确认的写未确认，不用数值反推补齐**。

## 0. 驱动铁律：预演是总开关

- **「预演」是激活几乎所有计算的开关**。不点预演，中间量/公式分支根本不执行；
  静态挖到的分支必须靠预演去激活验证，读内存/读槽/读输出都要在预演之后。
- **多跨两个模型（多跨铰接连续静定梁 / 多跨铰接连续一次超静定梁）在立柱页点预演无效**：
  必须先「下一步」进入多跨数据输入页，在新页面点「预演」才真算。

## 1. 已确认（代码级）

| 事实 | 取证 |
|---|---|
| 立柱计算函数 `sub_18BD010` 内是字符串 Select Case，键 = `Form->[+54h]` 的图名 BSTR | `0x18BD50C push dword ptr [eax+54h]` + `off_505EFC` + `call sub_41364E`(__vbaStrCmp) + `test/jnz` |
| 共 45 个分支：01-01…01-15 / 02-01…02-21 / 03-01…03-09 | 见 `docs/V31_MODEL_CASE_MAP.md` |
| 图名是**运行期拼出来**的：`".\\PIC\\静力计算手册\\0X-"` + `Format(n,"00")` + `".wmf"` | 三个前缀常量 `0x505E0C`(01-) / `0x505E44`(02-) / `0x505E6C`(03-)，在 `sub_18BB173`、`sub_18E98D1`、`sub_18EBD91` 里与 `__vbaVarFormat` 组合 |
| 每个分支体结构固定 | `材料的抗弯矩：W=` → 弯矩式 → `挠度计算值` → `挠度设计值` |

## 2. 已排除（都做了实验，别再重复）

1. **不存在对 `[reg+54h]` 的写指令**：全镜像扫 `89/8D/C7 + modrm(disp8/disp32) + 54h` 命中 0；
   265 处 `+54h` 全是 `call dword ptr [eax+54h]`（虚表槽）。
   ⇒ `[obj+54h]` 不是普通字段赋值，可能藏在 Variant 里（VT_BSTR 的 bstrVal 在 Variant+8，
   即"字段 0x54" = "Variant 起于 0x4C"），但 `lea reg,[reg+4Ch]` 也命中 0。
   **结论：写入点仍未定位，不再靠改扫描条件硬猜。**
2. **45 个图名不是界面模型单选直接给出的**：V31 进程私有堆里常驻 8 个图名串
   `01-01…01-08`（由一个指针数组汇集，见 `v31_pic_probe.py` 的 LIVE 输出），
   切 6 个模型 + 点预演 + 多跨「下一步」填表后**均不变**。
   ⇒ 这批字符串属于另一处逻辑（很可能是"常用静力计算"那套的预载），**不能拿来当选择子**。
3. `GWL_USERDATA` = 0（`0xE2D96` 立柱窗），拿不到 VB6 Form 对象指针；
   也没有随附计算 DLL（目录里只有 `Reg.dll`、riched2x），排除"计算在别的模块里"。

### 新的锚点（强证据，待执行验证）

立柱/横梁/玻璃/连接/埋件五个面板各有一个**同构大函数**，靠"输出文案字符串"能唯一定位：

| 输出文案常量 | 引用点 | 所属函数 |
|---|---|---|
| `抗弯矩预选` `0x4D2318` | `0x8B7762` | **`sub_89EA1D`（0x89EA1D–0x8A9F7E，46,433B，72 rtcRound）** |
| 同上 | `0x8C796E` / `0x8D70FD` / `0x8E7E5B` / `0x8F8F6D` | 另外 4 个兄弟函数（IDA 未定义边界） |

`sub_89EA1D` = **立柱候选**（第一个兄弟，且是唯一被 IDA 识别成函数的）；它同时引用 `1.5` 常量与 `rtcRound`，
与"qd = qk×1.5 再取整"的取整链吻合 —— **B10 的 qd 平局应在 0x89EA1D 里查，而不是 0x18BD010**。

### 调试踩坑（必须遵守）

- 调试器进程被杀 → Windows **连带杀掉被调试进程**（本轮 V31 因此死了 3 次）。
- 单次 attach 必须 <15s、带看门狗强制 detach；不要在后台留调试器。
- `DebugActiveProcess` 后目标处于挂起态，**同步 `SendMessage` 会死锁**，必须 `PostMessage`。
- 非本断点的异常必须 `DBG_EXCEPTION_NOT_HANDLED` 交回系统，否则 VB6 首轮异常被吞 → 崩溃。
