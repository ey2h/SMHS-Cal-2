# 多跨铰接连续【一次超静定】梁 —— V31 代码级公式复原

> 目标函数：V31 脱壳镜像 `0xD73EEF – 0xD8EF31`（约 110 KB，栈帧 `0x112C`）。
> 取证手段：Frida 进程内插桩（非调试器）+ 直读 Form 上的 Double 数组。**零计算书、零规范推测、零拟合**。

## 一、函数与页面

| 项 | 值 |
|---|---|
| 函数边界 | `0xD73EEF – 0xD8EF31` |
| 定位方式 | 挂 `__vbaVarMul(0x413714)` 统计返回地址 → 热点全在 `0xD7Bxxx–0xD7Cxxx`，且每点 ×10（按跨数循环）→ 按 `55 8B EC` 反查函数首 |
| 页面 | 立柱页「多跨铰接连续一次超静定梁」→ **必须点「下一步」** 进 `Frame '多跨数据输入'`，再「确认数据」→「预演」 |
| 输入框 | 总跨数(102,179)、跨长A₁(102,221)、**跨长A₂(102,258)**、跨长L₁(102,296) |
| 输出 | 只有 4 个量：抗弯强度 / 抗剪强度 / 折算强度 / 挠度（+ 各自设计值与限值） |

**注意**：静定版只有 3 个输入框，超静定多一个 `(102,258)`。不填它默认 600，会导致结果对不上。

## 二、五个运行期数组（`Form + 偏移`，元素为 Double，下标从 1 开始）

| 偏移 | 内容 | 实测（A₁=800 / L=2700 / n=10） |
|---|---|---|
| `+0x4C` | **A₁**（跨长A₁ 输入） | `0, 800, 800, …` |
| `+0x12C` | **A₂**（跨长A₂ 输入，默认 600） | `0, 600, 600, …` |
| `+0x110` | **L**（跨长L₁ 输入） | `0, 2700, 2700, …` |
| `+0xD8` | 支座弯矩 **−M** | `0, −667200, −2456000, …` |
| `+0xF4` | 数组弯矩 **M'**（负值，迭代收敛） | `0, −1561460, −1534360, −1534240, …` |
| `+0xA0` | 铰接力 **P** | `0, 2236, 2246, …` |
| `+0x84` | P 的 1-移位副本（`arr84[i] = arrA0[i−1]`，仅打印用） | `0, 0, 2236, 2246, …` |

> `A₁ ≠ A₂` 是**实机现象**，不是笔误：把 A₁ 填 400、A₂ 填 700，两个数组分别读出 400 / 700。

## 三、公式（全部带地址）

```
M   = qd·A₁²/2 + P·A₁                                 0xD7BF3D → 0xD7BF51 → 0xD7BF5E
T   = (L³ + A₂³)·6·qd/24                              0xD7C165(L³) 0xD7C192(A₂³)
                                                      0xD7C369(×6·qd) 0xD7C391(÷24)
M'  = −(T − M·A₂/6) / 2 / (A₂ + L)                    0xD7C3C6(÷2) 0xD7C3DA(÷(A₂+L))
P   = rtcRound(qd·L/2 + M'/L, 0)   ★ 0 位整数取整       0xD7C95C(Add) 0xD7C95D(rtcRound)
V   = P + qd·A₁                                       0xD7FAD4 之前
σ   = M/W            （支座控制分支）                   0xD7E8DD
σ   = |M'|/W         （跨中控制分支）                   0xD816EC（|M'| 经 fabs → ÷slot[32]=1.00）
τ   = Sx·V/(I·t)                                      0xD7FAD4 → 0xD7FAF3 → 0xD7FB12
σeq = √(σ² + 3τ²)                                     0xD802F4 / 0xD80316 (Pow2) 0xD80344 (Pow0.5)
lim = min((A₁+L)/180, 20)
df  = rtcRound(num1/EI, 3) − rtcRound(num2/EI, 3)/2
      num1 = 5·qk·L⁴/384 + M'·L²/16                   0xD87752(5qkL⁴) 0xD87608(÷16)
      num2 = P·A₂³/3 − A₂⁴·qk/12 − M·A₂/3 + M'·A₂/6    0xD86F1F / 0xD87390
```

### 关键细节（每条都有实机反证）

1. **P 的取整位数是 0**（整数）。所以 P 永远是整数：2236 / 2246 / 2325 …
2. **折算应力是 √(σ²+3τ²)，不是 √(σ²+τ²)**：L=2800 时 √(σ²+τ²)=83.055，V31 打印 84.059；换 3τ² 得 84.059 ✓
3. **挠度是两个分项各取 3 位再相减**：`Add(4.724, −1.224) = 3.5`，全精度相加会差 5e-4 量级
4. **`M'` 本身为负**，num2 里最后一项是「加 M'·A₂/6」而不是减（代码 `0xD87390` 直接 Add 负值）
5. **A₂ 恒定出现**（L³+A₂³ / M·A₂/6 / (A₂+L) / A₂³/3 / A₂⁴/12 / M·A₂/3 / M'·A₂/6），
   只有支座弯矩 M 用 A₁ —— 这是 V31 的真实行为
6. 常量表：`dbl_4019A8 = 3`（立方指数）、`dbl_403C50 = 4`（四次指数）、`dbl_4018F8 = 2`（平方）、
   `dbl_4027F8 = 6`（÷6）、`dbl_402F88 = 16`（÷16）、`dbl_4019E0 = 20`（挠度上限）

## 五、未闭合项（如实挂账，未凑数）

1. **A₁ ≠ A₂ 时的 df**：A₁=800/A₂=600 实测 1.6645，按现公式 3.06。
   差在挠度第二项 num2 里三个 A 到底用 A₁ 还是 A₂（σ/τ/σ_eq 已全对，只有 df 差）。
2. **跨中控制分支（max|M'| > M）的 τ 与 df 第二路径**：
   σ=|M'|/W 已对上（L=3000 得 91.385 ✓），但 τ 对应 V≈3267.3，
   而 `P + qd·A₁ = 3721`，说明该分支还有一段独立的 V 计算（`0xD82936–0xD82999`，未解）。
3. 分支判定条件目前用 `max|M'| > M` 推断（数值上一致），未在代码里找到显式的比较指令。

## 七、踩坑

- **`v31_py.py` 的 `multi` 必须在「上一步」回退后再填**：已经停在多跨页时再点「下一步」会翻到下一页。
- 预演**必须点两次**才稳定刷新（单次偶发读到上一组残留）。
- Frida 客户端被 `timeout` 强杀会**连带杀掉 V31**（实测死了 5 次）⇒ 脚本自带循环与正常 unload，别用 `timeout` 兜底。
- `0xD7E8xx` 只服务于 **支座控制分支**；跨中控制分支的 σ 在 `0xD816EC`、τ 在 `0xD82999`
  —— 一开始在 `0xD7E8xx` 找不到就以为「没执行」，其实是走另一条分支。
