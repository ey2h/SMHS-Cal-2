## 三、唯一的不一致——已查明：**不是复刻错，是 V31 缺控件不可比**

| 场景 | V31 | 复刻 | 判定 |
|---|---|---|---|
| 内部体型 = 其它情况(人工给定) | **1.848**（`slot47=1.126`，与封闭式相同） | 1.5195（μsi=0） | 不可直接对拍 |

**取证过程（2026-10-24 18:40 复核）**：

1. `dump-basic` 全量列出 V31 第一页 68 个控件 —— **内部体型 Frame 内只有 5 个单选，没有输入框**
   （外部 Frame 有 `TextBox (258,110)`，内部 Frame 没有对应框）。
2. 点选「其它情况(人工给定)」后确认 `chk=1`（真的选中了），预演得 `slot47=1.126`、`wk=1.848`
   —— 与「封闭式建筑物」逐位相同 ⇒ **V31 该档退化成 0.2**。
3. 复刻有输入框（照 V35 的 68 控件做，V35 确实有 #8 输入框），填 0 得 1.5195。

**结论**：
- 复刻按 V35 实现是对的（V35 有这个框，允许"其它情况"自定义 μsi）。
- V31 没有这个框，所以"填 0"这个状态在 V31 上**不存在**，两个 1.848 / 1.5195 不可比。
- 此前把 V31 测成 1.000 是**测试脚本误把 0 写进了外部框**（`258,110` 是外部人工给定框），
  属于第 3 类测试缺陷，已修正。

⇒ **本页目前 0 个数值不一致。**

## 四、测试过程中发现并修正的问题（3 个，都在测试脚本侧）

| # | 问题 | 表现 | 根因 | 处理 |
|---|---|---|---|---|
| 1 | V31 批量脚本未复位 | 整批基准变成 3.265，数据"看着合理"其实全错 | 上一轮把外部体型停在「人工给定 1.5」 | 每个 case 前跑全套复位，并加「基准_复位后」自检行 |
| 2 | 复刻扫描 `Baseline()` 漏复位 | K2=0.8 得 1.7738（=1.8477×1.2×0.8），像产品 bug | 继承了上一 case 的 K1=1.2 | `Baseline()` 补 `TerrainFactor/WindDirFactor/WindManual/WindManualKpa/GlassMono` |
| 3 | 地区名写成简写 | 「广州」得 1.0078（w0=0→0.3 下限） | 参数库里是「广东广州」；`RegionSelected` 绑到下拉，写进不在列表里的名字会被清成 null | 用例改用全名；扫描 CSV 增列 `w0 / RegionSelected / 命中行` 便于以后立刻发现这类问题 |

> 第 3 条**不是产品 bug**：`FindRegion("广州")` 本身能包含匹配到「广东广州」（有 `--selftest=region` 诊断可证），
> 是"值绑到下拉、不在候选里就被清空"的 UI 语义。但暴露一个风险：
> **w0 取不到时会静默回落到 0.3 下限，不报错**。建议加一条状态栏提示（未做，属改进项）。

## 六、关键结论（8 条）

1. **风荷载整条链四面闭合**：w0 → β=max(βgz, 1+0.7/√μz) → μz → μs1·ψ+μsi → K1·K2 → 下限。
2. **K1、K2 是线性乘进 wk**（×0.75 → 1.386、×1.2 → 2.218、×0.8 → 1.478，四点四位小数全对）。
3. **风荷载「人工给定」完全取代算值且不过 1KPa 下限**（填 0.5 得 0.5）。
   这条必须用 <1.0 的值才判得出来，1.234 是无效实验。
4. **玻璃配置 / 有中横 / 雪荷载敏感 对立柱屏零影响**，V31 与复刻都逐位不变。
5. **单元式幕墙是唯一改变立柱屏结构的选项**：预选与挠度为空，抗弯/抗剪减半。复刻未实现（P0）。
6. **V31 第一页没有 γ0 下拉** → γ0 属"有依据（V35＋GB50068）但无实机对照"，风险已知。
7. **地区查找的静默回落有风险**：w0 取不到时落到 0.3 下限且不提示，建议补状态栏告警。
8. **批量对拍必须有"基准行"，且基准行必须复位后再跑** —— 本轮三次踩坑有两次是这个原因。
