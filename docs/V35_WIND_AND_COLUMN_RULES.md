## 2. 立柱强度公式（计算书原文，`0x4e8d00–0x4ebf00`）

符号（「下面公式中，各参数含义为：」`0x4ead08`）：

| 符号 | 含义 | 单位 |
|---|---|---|
| N | 立柱轴力设计值 | N |
| M | 立柱弯矩设计值 | N·mm |
| A | 立柱净截面面积 | mm² |
| W | 在弯矩作用方向的净截面抵抗矩 | mm³ |
| γ | 塑性发展系数 | - |
| f | 型材的抗弯强度设计值，**取 A002(19) MPa** | MPa |
| fv | 型材的抗剪强度设计值，**取 A002(20) MPa** | MPa |
| Vmax | 立柱最大剪应力 | MPa |
| V | 立柱所受剪力 | N |
| S | 立柱型材受力面对中性轴的面积矩 | mm³ |
| I | 立柱型材截面惯性矩 | mm⁴ |
| t | 型材截面垂直于X轴腹板的截面总宽度 | mm |

- 抗弯：σ = M / W（`0x4e91d4`「有地震作用效应组合时第1跨立柱抗弯强度计算值为:」）
- 抗剪：「按下面强度公式校核立柱抗剪强度」`0x4e8e74` + 「上式中:」`0x4e8ef8` → τ = V·S / (I·t)
- 折算：σ_eq = √(σ² + τ²)（V31 双样本零误差，见 `MultiSpanStaticEngine`）
- **A002 = 材料性能数据文件**（`0x4e4770`「A002.CAC」，安装目录 jss/ 下无此文件 → 数据在 EXE 内，待续挖）；
  6063A-T5 实测 f=135 / fv=75 / 折算 148.5（=135×1.1，V31/V35 一致）
