## 交叉核对：模板文字 vs 代码实际

模板是「计算书里印出来的公式」，代码是「真正执行的计算」。两者**不一定一致**，

2. **多跨连续梁用的是弯矩分配法**：`MD~i~=-[6q(B~i~&3&+D~i~&3&)/24+MA~i~*D~i~/6]/[2*(B~i~+D~i~)]`
   —— 复刻的连续梁分支尚未按此实现。
3. **挠度限值有三套规范**：`l/180`、`l/250`、`l/300`（DG/TJ08-56-2019 13.4.4-1/2/3），
   另有 `L_2/250+7`、`(L_1+A_2)/250+7` 的长跨修正项 —— 与实测「≤4500 用 /180，>4500 用 /250+7」吻合。
4. **风荷载公式串是运行时拼的**：`slot[7] = '1+2*2.5*0.14*(100/10)&-0.15&'`，
   结构 = `1 + 2·g·I10·(z/10)^(−α)`，`&...&` 是上标标记。广东档 g 变 3.0 时该串会变成 `2*3*0.14`。
