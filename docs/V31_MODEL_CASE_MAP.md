# V31 立柱：45 个模型分支 ↔ 公式对照表（代码级）

来源：V31 脱壳 `unpacked_v31.exe.i64`，函数 `sub_18BD010`（0x18BD010–0x18E9555）。

## 一、分支选择机制（非推测，逆指令得到）

函数内部是一条 **字符串 Select Case 链**：每个比较块形如

```asm
mov  eax, [ebp+arg_0]      ; Form 对象
push dword ptr [eax+54h]   ; 当前模型图名 (BSTR)
push offset off_XXXXXX     ; 候选图名常量
call sub_41364E            ; __vbaStrCmp
test eax, eax
jnz  loc_下一个比较         ; 不等 → 继续下一条
```

⇒ **选择子 = Form->[+54h] 里的「静力计算手册图名」字符串**，共 45 个分支，
命名 `01-01.wmf` … `03-09.wmf`（目录 `.\PIC\静力计算手册\`）。

每个分支体区间 = `[本比较块的失败目标, 下一个比较块)`，内部依次是：
`材料的抗弯矩：W=` → 弯矩式 → 挠度计算式 → 挠度设计值。


## 一之二、三大族 = 程序自带帮助原文（非推测）

`docs/recon/help/plain/B24.txt`（V31 帮助「常用静力计算」章）原文：

> 目前软件提供的模型包括：**悬臂梁（15种）、简支梁（21种）和带悬臂（9种）的简支梁**；
> 这部分计算不提供计算书输出功能，但是可以输出成简易文本以便用户参考。

数量与上表严格对应，因此三族归属由**程序自身说明文本**确定，不是按公式形状猜的：

| 图号前缀 | 个数 | 族 | 文字特征（分支体内印的原文）|
|---|---|---|---|
| `01-xx` | 15 | **悬臂梁** | 「**根部**弯矩为」 |
| `02-xx` | 21 | **简支梁**（含带外伸变体）| 「**最大**弯矩为」 |
| `03-xx` | 9 | **带悬臂的简支梁** | 「AB段/C点 挠度」 |

已逐指令验证的两个锚点也落在预期族里：`02-07` = 单跨简支 `M=qL²/8`（简支族）、
`02-14` = 悬挑 `M=qa²/3·(1-2α/3)^1.5`（简支族里的带悬臂变体）。

## 三、怎么用这张表

1. 实现某个力学模型时，先用「图号」找到对应行，再按行内地址逐指令读真公式，**不要从计算书/模板猜**。
2. 已逐指令验证的两行：`02-07` = 单跨简支 `M=round3(q·L²/8)`；`02-14` = 悬挑 `M=round3(q·a²[1-2a/(3(a+L))]^1.5/3)`。
3. **尚未确定**：45 个图号 ↔ 界面「力学模型」单选（单跨简支/双跨梁/连续梁/多跨铰接…）的对应关系。
   选择子 `[form+54h]` 的赋值点尚未定位（已确认不是 `mov [eax+54h],...` 形式）。
