## 三、残差的根因（已排除一项误判，仍在定位）

残差不是公式错，而是 **wk 中间值精度**：

- 复刻按 V35 公式实算：`wk = 0.55×1.4955621×1.9952623×(0.925817+0.2) = 1.84818`（显示 1.848）
- V31 由挠度反解：`qk = 5qL⁴/(384EI)` → 2.03286 N/mm → `wk = 2.03286/1.100 = 1.84787`（显示同为 1.848）
- 两者在 3 位小数上一致，第 4 位差 0.0003（0.017%），经 `q·L²/8`、`q·L⁴` 放大后表现为 0.02~0.04% 的残差。

### 已排除：wk 区的 `vb6_rtcRound` 不是残差来源

wk 计算函数体（`0xA6E000–0xA74000`）内确有 **12 处 `vb6_rtcRound`**：

| 场地类 | Round 调用地址 |
|---|---|
| A | 0xA703BC、0xA70562 |
| B | **0xA709AB、0xA70B4D** |
| C | 0xA70F96、0xA7113C |
| D | 0xA71585、0xA7172B |
| 其它 | 0xA71936、0xA73174、0xA73361、0xA73456 |

但读了 `0xA709EE` 之后的代码，可以确定**这些 Round 只服务于计算书文案**，不参与数值链：

```
0xA709AB  call vb6_rtcRound        ; 取整
0xA709EE  call vb6_vbaVarMove      ; 写全局槽 8（dword_220D178 + 8*16）
0xA70A0B  mov [ebp-21Ch], offset a1000      ; 字符串 "1.000*("
0xA70A1F  mov [ebp-22Ch], offset a10030     ; 字符串 "/10)&0.30&"
0xA70A6C  call vb6_vbaVarCat       ; ← 字符串拼接：把数值拼进公式文本
0xA70A80  call vb6_vbaVarCat
```

即：取整值被拼成 `1.000*(z/10)^0.30` 这样的**公式展示串**写进槽 8/9，属于计算书排版，
主计算仍用全精度 VARIANT。（此前把残差归因于 rtcRound 是误判，已纠正。）

### 仍在定位的部分

公式结构、常量（四类 I10/α、μz 系数、g=2.5）、ψ(A) 三处都已逐条对上 V35 地址，
残差只剩第 4 位的舍入来源，候选是 `βgz`、`μz` 或 `ψ(A)` 其中一个中间量的舍入。
消解方式见计划 M1 的 P1（计算书取中间值，无需授权）/ P2（断点，需 B3 授权）。

## 四、下一步（要“不凑数”地清零残差）

1. 静态：读 0xA709AB 之前的 VARIANT 槽编号与常量，确定 Round 的对象与位数（无需运行程序）。
2. 动态：在 0xA709AB、0xA70B4D 下断点取 `[ebp-1C4h]` 的入参与出参（属 B3，需逐次授权）。
3. 或：把 V35 的 βgz/μz 取值与复刻逐项打印到状态栏，用同一 z 多组采样交叉定位哪一步被取整。

在 1~3 完成前，**不使用任何拟合系数**去对齐这 0.03%——现有实现全部是公式直算。

## 五、1.5（强度荷载分项系数）的代码出处

复刻强度支路用 `qd = qk × 1.5`。该 1.5 **不是反算值**：

- 全镜像中 `double 1.5` 仅 1 处：`dbl_4022E8`。
- `0x1158ECC`：`fld ds:dbl_4022E8` → `fstp [ebp-0F8h]` → 构造 `vt=5(Double)` 的 VARIANT → 写入槽 `dword_220D1CC + 0x0B*16`，随后参与 `vbaVarMul`。
- 另有成对 `fld/fmul ds:dbl_4022E8` 出现在 0x1276xxx、0x12BB0E7、0x12C9DA…0x12F74F9 等强度分支。
- 0x104xxxx 区（挠度函数）内**没有**对 1.5 的引用，符合“挠度用标准值、强度用设计值”的分工。

待补：该 1.5 是否随界面「有地震作用效应组合时的分项系数」下拉变化（V35 基本参数屏 #61~#67 共 6 个组合系数控件）。
