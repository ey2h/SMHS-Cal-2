## 五、★ 关键坑（浮点顺序与钳位）

1. **r 先 round3**：r = round3(小支承点/大支承点)，再查 m 表。0.8125→0.812，m(0.812)=0.14472→round4=0.1447。
   若用未取整的 0.8125 插值会得 0.14475，差一位。
2. **背栓 m 表 ≠ 短挂件 m 表**：末 5 断点不同（背栓 0.144/0.147/0.150/0.153/0.156）。
3. **τ 的分母含「有效剪切长度 = 面板厚度 − 前端拓孔直径」**：25−15=10。拓孔直径 15→19，
   τ = 2202.3/(4·π·6·(25−D))，D 越大 τ 越大（有效剪切长度越小）。
4. **背栓抗拉设计值 = N/2.15**、**背栓抗剪设计值 = 0.8·N/2.15**，0.8 是抗剪折减。
