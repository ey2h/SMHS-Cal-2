# 第一页选项扫描：V31 vs 复刻（地面类型 A/B/C/D）

日期 2026-10-24。目的：验证第一页每个选项是否真的影响第二页结果，并与 V31 实机对拍。

## 方法

- **复刻侧**：`--selftest=sweep` 一次进程内跑完 19 个场景（基准 + 每次只改一个选项），
  输出 `local-data/recon/v31runs/sweep_basic.csv`。基准＝上海/50年/标高100/B类/墙面区/封闭式/
  按规范≥1kPa/二级(γ0=1.0)/立柱跨3000/立柱左分格1100/6063A-T5/60-80系列。
- **V31 侧**：`v31_attach.ps1` 新增 `terrain-sweep` 动作，在**同一会话**内依次 A→B→C→D，
  每组「点单选 → 下一步 → 选单跨简支受拉 → 选 6063A-T5 → 预演 → 读 RichText → 上一步」。

## 一、风荷载标准值 wk（可信：只依赖第一页）

| 地面类型 | V31 | 复刻 | 差 |
|---|---|---|---|
| A 类 | 2.029 KPa | 2.0105 KPa | **−0.91%** |
| B 类 | 1.848 KPa | 1.8477 KPa | −0.02% |
| C 类 | 1.571 KPa | 1.5706 KPa | −0.03% |
| D 类 | 1.277 KPa | 1.277 KPa | 0 |

**结论：B/C/D 吻合到 3 位小数，A 类差 0.91%。**

A 类偏差排查（已深入到 V31 运行期代码）：

1. **V35 常量表**（A 类唯一存在）：`0x401F00 = 0.24`（μz 指数）、`0x401F08 = 1.284`（μz 系数）、
   `0x401F10 = 0.12`（I10 与 α 共用）、`0x401F18 = 2.5`（g）。
   按该组系数手算：βgz = 1+2×2.5×0.12×10^(−0.12) = 1.455147，μz = 1.284×10^0.24 = 2.231337，
   wk = 0.55×1.455147×2.231337×1.125817 = **2.0097**，与复刻 2.0105 一致。
2. **V31 是 ASPack 加壳（EXE 仅 2.9MB），文件里扫不到明文常量**。
   改用运行期内存 dump：`local-data/recon/dump_v31_mem.py` → 解压后主代码段 25.9MB（`0x00401000`）。
3. **在 dump 里找到 V31 常量表 `0x401940–0x4019C0`，与 V35 逐值完全相同**
   （0.262/0.39/0.44/0.544/0.22/0.23/0.3/0.15/0.14/**0.24/1.284/0.12**/2.5）。
   → **A 类 0.92% 的差异不是系数问题。**
4. **V31 的 A 类计算块 = `0x85E200–0x85E480`**（0.12 引用 @0x85E258、0x85E282；1.284 @0x85E43E；0.24 @0x85E468）。
   反汇编显示三者均为 `fld dbl → fstp [ebp-xxx] → mov vt=5(Double) → mov 槽索引` 的 VARIANT 常量装箱，
   与 V35 的 A 类块（`0xA702E0` 起）结构相同，公式主体也一致。
5. **A 类 2.029 已单独干净复验，不是状态污染**：选 A 类 → 回读确认 A=1 且其余基准 → 下一步 →
   单跨简支受拉 → 6063A-T5 → 预演 → 2.029 / 抗弯 183.759（与批量完全一致）。

**当前结论（用内存快照直接读出 V31 中间量，非反推、非动态调试）**：

在 V31 预演完成后 dump 进程内存（`dump_v31_mem.py`），按 8 字节对齐扫描目标量：

| z | V31 实测 βgz×μz | V35 公式算得 | 比值 |
|---|---|---|---|
| 50 m | **2.857422**（0x6B74B60） | 2.823902 | +1.173% |
| 100 m | **3.280781**（0x6B3A1A0 / 0x6B3A8B8 / 0x6B7A1A8 / 0x6B7A8C0 四处重复） | 3.246921 | +1.032% |

同时测到 V31 的 **μs 组合 = 1.126975**，而 V35 公式给 1.125817（仅差 0.10%）
→ **ψ(A) 基本正确，差异几乎全部集中在 βgz×μz 这一项**。

两点独立反解、看结果是否自洽：

| 假设 | z=50 | z=100 | 判定 |
|---|---|---|---|
| μz 系数 C（固定 p=0.24 / α=0.12 / I10=0.12） | **1.29924** | **1.29739** | 两点一致 → 可信 |
| I10（固定 C=1.284 / α=0.12） | **0.12430** | **0.12400** | 两点一致 → 可信 |
| α（固定 C=1.284 / I10=0.12） | 0.06857 | 0.10576 | 两点不一致 → **排除** |

即：**V31 的 A 类等效为「μz 系数 1.298」或「I10 0.1242」，而 V35 常量表是 1.284 / 0.12。**

**这是版本参数差异，不是公式错误**：
- B/C/D 三类的两版系数完全相同（1.000/0.30、0.544/0.44、0.262/0.60），实测吻合到 0.03%；
- 只有 A 类（唯一在 GB50009-2012 中被修订的类别）差 1%；
- 复刻目标是 V35，因此**按 1.284 / 0.12 实现是正确的，不需要改动**；
- 若日后需要与 V31 逐位对齐，应做成"规范版本模式"开关（A 类 1.284↔1.298 或 I10 0.12↔0.1242 联动），
  而不是把 V31 的值硬编码进基线。

**方法沉淀**（可复用到任何一屏）：
`dump_v31_mem.py` 在 V31 算出结果后 dump 全量内存 → 8 字节对齐扫目标量；
两种参数各 dump 一次，扫「重复出现的目标值」即可把差异锁到具体因子，**不必下断点、不打断进程、不影响试用状态**。

挠度只依赖标准值 qk，强度依赖设计值 qd，说明批量驱动过程中某个**影响 qd 的状态被改动**（型材行、

→ **V31 批量驱动存在状态污染，强度类数据不能用于对拍**。后续每组必须「重启 V31 或显式复位全部选项」。

**可信的部分**：wk（第一页直接产物）与挠度（标准值支路）在 B/C/D 上完全一致。

## 四、本轮修掉的真 bug

`ResolveWindStandard()` 原先恒执行 `wk = Math.Max(raw, 1.0)`，**「按实际计算结果」单选等于未接**。
已改为：选「按实际」直接用算值不加下限。用低风压场景验证：1.0 vs 0.4795。
