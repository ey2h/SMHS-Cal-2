## 3. `jss/A0xx.CAM` 数值矩阵（11 个：A006…A275）

- 每文件 331~2706 个整数 token，值范围 **1~99991**（近似均匀），含**尾随负号**标记（如 `"14932-"` = **-14932**，经典尾随负号表示法），占比约 38%~40%。
- 文件命名（A006/A007/A014/A041…A275）疑似对应不同计算模块/工况；无表头、列数不规则。
- **推断**：带符号随机整数矩阵，疑为**荷载/可靠度随机样本**或**截面随机组合查表**；精确语义须结合程序代码确认。属②待定语义的数据资产。
