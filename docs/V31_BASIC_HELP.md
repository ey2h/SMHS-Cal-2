## 1. 重现期（Frame「重现期(?)」，rel 118,36）

> 围护结构以50年重现期计算即可，有特殊要求者除外。

→ 默认 50 年；选 100 年属「特殊要求」，只影响查参数库的基本风压列。

## 2. 地面类型（Frame「地面类型(?)」，rel 209,36）

> 按《建筑结构荷载规范》（GB50009-2012）：
> A类：指近海海面和海岛、海岸、湖岸及沙漠地区；
> B类：指田野、乡村、丛林、丘陵以及房屋比较稀疏的乡镇和城市市郊（广东规范含城市市郊，国标不含市郊，但是原理其实没有什么区别）；
> C类：指有密集建筑群的城市市区；
> D类：指有密集建筑群且房屋较高的城市市区。

## 3. 外部局部体型系数（rel 362,36；同一段也由「帮助」按钮弹出）

> 1:非广东规范时，软件自动按《建筑结构荷载规范》（GB50009-2012）计算体型系数，除特殊部位外，用户直接选&lt;大面&gt;或&lt;转角&gt;即可！
> 2:输入时不得输入正负符号，直接输入绝对值即可，软件会自行判断！
> 3:广东规范：小于45米低矮建筑墙角区体型系数取-2.0，大于45米高层建筑墙角区体型系数取-1.4，广东规范体型系数比国标更复杂，具体情况可考虑查规范后采用人工给定方式输入参数。

要点：
- 界面上的 **「墙面区」= 大面、「墙角边区」= 转角**；
- **人工给定只填绝对值**，正负由程序判（这解释了为什么我们填 1.0 / 2.0 都按正压处理）；
- 国标：大面 1.0、转角 1.8；广东规范：转角 H&lt;45m 取 2.0、H&gt;45m 取 1.4。

## 4. 内部局部体型系数（rel 640,36）

> 常规封闭建筑选默认封闭建筑选项，开敞式建筑人工给定为0。其他一些选项一般用在建筑设计单位有特别要求的情况下。

要点：**开敞式建筑应人工给定 0**（不是留空，也不是用 0.2）。

## 5. 风荷载标准值取值（rel 881,36）

> 按规范JGJ102-2003要求，幕墙风荷载标准值不应该小于1.0KN/平，如无特殊情况或要求，请按软件默认选择！室内建筑可选按实际计算结果，有风洞实验或特殊情况由设计院给定风压情况可选人工给定，但是要考虑设计院给定风压的合理性，很多时候设计院要求的风压过高并且无规范依据，可和设计院协商。

要点：默认「按规范不小于 1KPa」；「按实际计算结果」用于室内建筑；「人工给定」用于设计院给风压。

## 6. 地形修正系数 K1 / 风向影响系数 K2（rel 629,144）

> K1：地形修正系数，按规范4.6.6[GB55001-2021]取：
> 1.对山峰和山坡等地形，应根据山坡全高、坡度和建筑物计算位置离建筑物地面的高度确定地形修正系数，其值不应小于1.0；
> 2.对于山间盆地、谷地等闭塞地形，地形修正系数不应小于0.75；
> 3.对于与风向一致的谷口、山口，地形修正系数不应小于1.2；
> 4.其它情况，应取1.0。
>
> K2：风向影响系数，按规范4.6.7[GB55001-2021]取：
> 1.当有15年以上符合观测要求且可靠的风气象资料时，应按照极值理论的统计方法计算不同风向的风向影响系数，所有风向影响系数的最大值不应小于1.0，最小值不应小于0.8；
> 2.其它情况，应取1.0。
>
> 这两个系数的取值一般都是1.0，特殊情况极少，如果需要，请用户自己根据建筑设计院的要求调整。

★ **这两个系数是乘进 wk 的**（之前复刻版漏接了）。

> 此处选项需要查建筑结构设计总说明，由设计院提供！

## 对复刻版的直接结论

| 提示点 | 对实现的要求 |
|---|---|
| 重现期 | 默认 50 年，w0 查参数库 50 年列；100 年列只在用户主动选时用 |
| 地面类型 | 默认 B 类；四类的 I10/α/μz 系数已从 V35 常量表取到 |
| 外部体型 | 墙面区=大面=1.0、墙角边区=转角=1.8；人工给定**填绝对值**；广东规范另有 2.0/1.4 |
| 内部体型 | 封闭式 0.2 / 0.3 / 0.4 / 0.6 / 人工（开敞式填 0） |
| 风荷载取值 | 默认「按规范不小于 1KPa」→ wk = max(算值, 1.0) |
| K1/K2 | **wk 要再乘 K1×K2**，默认各 1.0；K1 下限 0.75，K2 允许 0.8～1.0 |
| 抗震 | 由设计院给，界面只做选择，不自动推 |
