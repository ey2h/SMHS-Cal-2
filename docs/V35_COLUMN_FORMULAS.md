## 二、挠度公式（原文逐字）

### 第 1 跨跨中（0x4EA5F4 起）

```
d~f1,mid~ = 5q~k~L~1~&4&/384EI~x~*(1-2.4(A~1~/L~1~)&2&)
d~f2,C~   = q~k~A~2~L~2~&3&/24EI~x~*(-1+4(A~2~/L~2~)&2&+3(A~2~/L~2~)&3&)
            +(P~2k~A~2~&2&L~2~/3EI~x~)*(1+A~2~/L~2~)
d~f1~     = d~f1,mid~+d~f2,C~/2
```

即：
- `df1,mid = 5·qk·L1⁴/(384·E·Ix) · (1 − 2.4·(A1/L1)²)`
- `df2,C = qk·A2·L2³/(24·E·Ix)·(−1 + 4(A2/L2)² + 3(A2/L2)³) + (P2k·A2²·L2/(3·E·Ix))·(1 + A2/L2)`
- `df1 = df1,mid + df2,C/2`

### 第 2 跨后跨中（0x4EA9A4 起）

```
d~fi,mid~   = 5q~k~L~i~&4&/384EI~x~ - q~k~A~i~&2&L~i~&2&/32EI~x~ - P~ik~A~i~L~i~&2&/16EI~x~
d~f(i+1),C~ = q~k~A~i~L~i~&3&/24EI~x~*(-1+4(A~i~/L~i~)&2&+3(A~i~/L~i~)&3&)
              +(P~i~A~i~&2&L~i~/3EI~x~)*(1+A~i~/L~i~)
d~f~        = d~fi,mid~+d~f(i+1),C~/2
```

### 挠度限值（0x4EA7C8–0x4EA82C）

```
d~f1,lim~ = (L~1~+A~2~)/250+7        0x4EA800
          = (L~1~+A~2~)/225          0x4EA828   ← 另一分支
d~f1~ = …… mm ≤ d~f1,lim~
```

即限值用 **L+A**（与实测 3000 单跨的 16.667=3000/180 一致，说明单跨走的是 1/180 分支，多跨走 /250+7 或 /225）。

## 三、多跨静定梁的内力（原文逐字）

```
P~1~   = 0 N                                    0x4EAEB8
P~i~   = R~Bi-1~ =                              0x4EAED4
MA~i~  = -[P~i~*A~i~+qA~i~&2&/2]                0x4EAF20
MD~i~  = -[6q(B~i~&3&+D~i~&3&)/24+MA~i~*D~i~/6]/[2*(B~i~+D~i~)]   0x4EAF90
M~i~   = qB~i~&2&/8+MD~i~/2                     0x4EB070
A1~    = -(P~i~+q*A~i~/2*(2+A~i~/L~i~))         0x4E9D74
A2~    = P~i~*(A~i~/L~i~+q*L~i~/2)              0x4E9DCC
R~有地震~ = *                                    0x4EB32C
R~无地震~ = K~k~R~有地震~                         0x4EB348
右~      = γ~0~K~k~V~                           0x4EC304
```

即：
- `MAi = −(Pi·Ai + q·Ai²/2)`
- `MDi = −[6q(Bi³+Di³)/24 + MAi·Di/6] / [2(Bi+Di)]`
- `Mi  = q·Bi²/8 + MDi/2`
- 支座反力 `A1 = −(Pi + q·Ai/2·(2 + Ai/Li))`、`A2 = Pi·(Ai/Li + q·Li/2)`
- 组合：`R_无地震 = Kk·R_有地震`、`V_右 = γ0·Kk·V`

判据（程序自己写的检查）：`B（i）应不小于D（i）`、`B（i）应不小于A（i）`（0x4EACB0 / 0x4EACDC）。

### 6.2 A002 材料表的列号含义
```
0x4E8E1C    f_A002(18)：型材的抗弯强度设计值，取A002(19)MPa；
0x4E9034    τ_A002(18)：型材的抗剪强度设计值，取A002(20)MPa；
0x4EC72C    f_a：型材的抗弯强度设计值，取A002(18)MPa；
0x4EC7DC    τ_a：型材的抗剪强度设计值，取A002(19)MPa；
```
→ **框架式**：抗弯取 `A002(18)`、抗剪取 `A002(19)`；**另有一版文本**写 `A002(19)`/`A002(20)`（单元式那一套），说明
A002 是一个「材料 × 列」的表，列号 18/19/20 分别对应不同强度项。具体数值表仍缺（安装目录无 A002.CAC）。

### 6.3 单元幕墙（双框）按等刚度分配（0x4EC8E8 起）
```
f~1左~ = γ~0~(N~1~/2A~1n~ + M~1~*(I~1x~/(I~1x~+I~2x~))/(γW~1nx~))
f~1右~ = γ~0~(N~1~/2A~2n~ + M~1~*(I~2x~/(I~1x~+I~2x~))/(γW~2nx~))
τ~1左~ = γ~0~V~B1~·I~1x~/(I~1x~+I~2x~)·S~1x~/I~1x~t~1~
τ~1右~ = γ~0~V~B1~·I~2x~/(I~1x~+I~2x~)·S~1x~/I~2x~t~2~
```
程序原文注释：「单元幕墙立柱由两根框插接组成，计算荷载时需按等刚度(EI)原理进行比例分配。」
「由于立柱轴力对计算影响很小，此处轴力分配按均分，水平荷载则按等刚度原则分配。」

### 6.4 挠度限值的表达式（字符串形态，0x4DE4A0–0x4DE654）
```
B/500   min(B/300,15)   min(B/180,20)   B/250   B/180
B/250+7 B/200           min(B/250,20)   min(B/250,30)  min(B/180,30)  min(B/500,3)
```
→ 程序把各规范的限值以**字符串表达式**存着（B = 计算跨度），运行时按界面「挠度限值规范」下拉选一条求值。
这解释了为什么限值会有 `/225`、`min(B/180,20)` 这类分支。

## 七、风压高度变化系数 μz —— 程序原文公式（回答「系数与 A/B/C/D 有关」）

位置：`0x511500–0x5116A0`（V35 计算书文本，逐字）

```
1.风压高度变化系数的计算：
    根据不同场地类型,按《建筑结构荷载规范》条文说明部分8.2.1提供的公式计算：

```

截断高度（0x511724–0x5118B0，原文）：

```
    对A类场地：当z>300m时，取z=300m，当z<5m时，取z=5m；
    对B类场地：当z>350m时，取z=350m，当z<10m时，取z=10m；
    对C类场地：当z>450m时，取z=450m，当z<15m时，取z=15m；

同段另有（水密性章节）：`βc：风力系数，可取1.2；`、`P=1000·μz·βc·w0`。

### 11.3 βgz 的代码形状（不是查表，是算的）
四类场地各有一段独立代码块，每块都先建 `+I10` 与 `−α` 两个 VARIANT，再做幂/除/加：

| 场地 | I10 | α | 块地址 |
|---|---|---|---|
| A | 0.12 (0x401F10) | 0.12 → `fchs` 成 −0.12 (0xA7030A) | 0xA702E0 起 |
| B | 0.14 (0x401EF8) | 0.15 → −0.15 (0xA708F9) | 0xA708CF 起 |
| C | 0.23 (0x401EE0) | 0.22 → −0.22 (0xA70EE4) | 0xA70EBA 起 |
| D | 0.39 (0x401EC0) | 0.30 → −0.30 (0xA714D3) | 0xA714A9 起 |

尾部（0xA71840 起）连成：
```
0xA71847 __vbaVarPow      →  &[ebp-164h]
0xA71854 __vbaVarDiv      →  &[ebp-174h]
0xA71861 __vbaVarAdd      →  &[ebp-184h]   ← βgz
0xA71867 __vbaR8Str / 0xA71883 __vbaR8Str →  取双精度
```
即 **βgz = 1 + (2·g·I10) ⁄ (z/10)^α**，与 GB50009-2012 式 8.6.1
`βgz = 1 + 2g·I10·(z/10)^(−α)` 同一式；`g=2.5` 在 0xA6FF7A 载入并存入全局槽 var[76]（0x4C）。

### 11.4 μz 的代码形状
同一批块里紧接着就是 μz：**系数 + 指数**成对出现，B 类的系数用 `fld1`（0xA70AB5）。
- A: 1.284 (0xA704C6) / 0.24 (0xA704F0)
- B: 1.000 (`fld1` 0xA70AB5) / 0.30 (0xA70ADB)
- C: 0.544 (0xA710A0) / 0.44 (0xA710CA)
- D: 0.262 (0xA7168F) / 0.60 (0xA716B9)

与程序内文本（0x511500–0x5118B0）给的 `μz=C·(z/10)^p` 完全一致；截断高度 A[5,300] B[10,350] C[15,450] D[30,550]。

### 11.5 内部局部体型系数的代码常量 = 界面 5 个选项
```

### 12.1 内部体型系数：写入的是「系数」槽，显示文本明确带 μs1
