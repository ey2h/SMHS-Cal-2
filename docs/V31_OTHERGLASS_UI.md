## 三、★「下一步」不是终点（本次纠正）

`otherglass_next_probe.py` 实测：点「下一步」后新出现的可见窗体是

```
'生成计算书（支持微软office及金山wps office）'   client 600×322（序号 26）
```

⇒ 该屏属于「独立计算器 → 出计算书」链路，不是流程终端。

复刻处置：
- `OtherGlassCalcView.axaml` 的「下一步」由 `IsEnabled="False"` 改为 `Click="OnNextClick"`；
- 代码后置按承载窗口分派到 `CalcBrowserWindow.ShowByTitle("生成计算书")`
  或 `CalcMainWindow.ShowByTitle(...)`（两个窗口共用同一份 `CalcFormCatalog`）；
- `CalcBrowserWindow` 为此把 `Host`/`InfoText` 从局部变量提升为字段。
- `CalcFormCatalog` 里「生成计算书」尺寸由 `603×330`（含边框）改为 `600×322`（client，
  与其余条目同口径）。

截图：`out/shots/otherglass_next.png`（状态栏显示 `屏内下一步 → 生成计算书 …`）。
