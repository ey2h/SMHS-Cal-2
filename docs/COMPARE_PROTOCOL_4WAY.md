# 四面对拍规程：V31 / V35 / 复刻 / 规范

建立日期：2026-10-24　状态：**长期有效，后续所有面板与公式一律照此执行**

---

## 〇、为什么立这条规矩（教训）

阵风系数 βgz 这一项，之前只做了「V31 结果 vs 复刻结果」两列对拍：

- A 类 wk 差 0.92%，当时定性为「V31 实现与其计算书文案不符」，就停在那里了；
- 实际上没有把**程序真正取的那个系数**拿出来和**规范公式**并排比；
- 结果复刻一直在用 `2·g·I10 = 2×2.5×0.12 = 0.600`，而 V35/V31 实际用的是 **0.6178**（等效 I10 = 0.12356）。

⇒ **教训：只看两端结果数字、不看中间取值，是挖不到位的。**
文案（计算书/帮助/公式串）会骗人——原程序自己打印 `1+2*2.5*0.12*(z/10)^-0.12`，
实算系数却是 0.6178，两版（V35/V31）一致地「文案≠实算」。

**新规矩：任何一个量，必须四列并排，缺一列不算验证完成。**

## 一、四列的定义与取证手段

| 列 | 含义 | 取证手段 | 可信度 |
|---|---|---|---|
| **V31** | V31 实机运行值 | `local-data/recon/probe_slots.py MQJSSV31.EXE 0x1C91168` 直接读 VARIANT 槽（`slot[6]`=z、`slot[8]`=βgz、`slot[10]`=μz、`slot[76]`=g）；或 `v31_attach.ps1` 驱动后读预演文本 | ★★★ 实测 |
| **V35** | V35（V53）实现 | 脱壳镜像 `unpacked_runtime.exe` 静态反汇编 + 与 V31 做**归一化事件序列同构比对**（`compare_gust_block.py`）；实机可跑时优先实机 | ★★★ 静态等价 |
| **复刻** | SMHS 计算结果 | `--selftest=sweep|preview --dump-preview=<csv>`，或界面预演 | ★★★ 实测 |
| **规范** | GB50009-2012 / JGJ102-2003 / GB55001-2021 条文 | 条文原文 + 规范表格（如 8.6.1 表 8.6.1） | ★★★ 权威 |

**优先级铁律**：`运行期实值 > 静态反汇编 > 程序文案 > 我的推测`。
文案（计算书段落、帮助文本、公式模板串）只能用来**理解意图**，不能用来**确认取值**。

## 二、判定规则

| 情形 | 结论 | 处理 |
|---|---|---|
| V31 = V35 = 复刻 = 规范 | ✅ 全一致 | 通过 |
| V31 = V35 = 复刻 ≠ 规范 | ⚠ 原程序偏离规范 | 默认跟随原程序（复刻的立身之本），并在文档登记偏离量与条文；另给严格规范档开关 |
| V31 ≠ V35 | ❌ 版本差异 | 必须逐指令比对，确认是版本演进还是分支不同，不得直接取其一 |
| 复刻 ≠ V35 | ❌ 复刻 bug | 阻断，必须修到一致（数值差 ≤ 打印末位） |
| 只有两列 | ⛔ 不算验证 | 补齐四列，缺的列标明「未取证」并说明原因 |

判定精度：与程序打印位数对齐（预演 3 位小数、槽值 4 位小数），末位容差 ±1 视为一致。
